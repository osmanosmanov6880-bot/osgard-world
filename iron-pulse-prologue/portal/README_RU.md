# IRON PULSE / INTERNATIONAL PORTAL (V9)

Это **настоящий работающий сайт на HTML/CSS/JS**, а не изображение маркетингового лендинга. Его сборка включена в CI; исходный Godot WebGL расположен в `play/`, Windows EXE и PCK упакованы вместе в `downloads/IRON_PULSE_WINDOWS.zip`.

## Как запустить

1. Получите файл `portal.zip` (или распакованный каталог `portal/`) из успешного GitHub Actions V9.
2. Распакуйте каталог. Для браузерной версии необходим локальный HTTP(S)-сервер, а не двойной клик по `index.html` (WASM в браузерах не должен загружаться через `file://`).
3. В этом каталоге выполните `python3 serve_preview.py`. На Windows может использоваться `py serve_preview.py`.
4. Откройте `http://127.0.0.1:8765/`. Кнопка **Играть / Play** запустит настоящий Godot WebGL.
5. Для Windows скачайте/извлеките **оба файла**, `IRON_PULSE_BLACKOUT.exe` и `IRON_PULSE_BLACKOUT.pck`, из одного ZIP в одну папку. Не запускайте EXE без соседнего PCK.

## Что работает

- Полностью адаптивная навигация, RU/EN, трёхрежимный переключатель GRID/HEAT/AIR.
- Настоящий кадр из зафиксированного CI Chromium, а не сгенерированное рекламное изображение.
- Самостоятельная WebGL-игра: нет подложных имитаций игровых действий в HTML.
- ZIP Windows-билда и манифест `SHA256SUMS.txt`, привязанный к исходному 40-символьному SHA.
- Проверки Chromium 1366×768 и touch 390×844, навигации, доступности кнопок, языков, отсутствия внешних запросов. Формат сохранений — локальный Godot.
- Публичные логотипы, заимствованные модели, внешние шрифты, аналитические SDK, аккаунты, реклама, платежи и запросы персональных данных **не используются**.

## Ограничения / безопасность

Этот портал **software preview**, не коммерческая публикация. Сервер намеренно принимает подключения только с `127.0.0.1` и выставляет необходимые для отдельных сборок Godot Web заголовки COOP/COEP. Если когда-либо размещать игру на публичном домене, HTTPS-хостинг/CDN должен отдавать совместимые заголовки и иметь отдельную политику безопасности. GitHub Pages может не поддержать требуемую изоляцию в конкретной конфигурации. Нужна отдельная проверка реального хостинга.

Нет подтверждений одобрения Steam, аппаратной производительности или готовности AAA. Публичную выкладку/изменение `master` выполнять только после полного QA, правовой проверки бренда и разрешения на релиз.

## Производственный процесс

`ci/package_portal.py` копирует **тот же SHA** WebGL-файлов, что прошёл браузерные испытания, создаёт проверенный Windows ZIP, добавляет исходный игровой скриншот и пишет SHA-256. `ci/portal_acceptance.py` затем открывает портал в Chromium на компьютере и телефоне, кликает RU/EN и сценарии, проверяет обе игровые ссылки и сохраняет настоящие UI-скриншоты `portal-desktop.png` / `portal-touch.png`.
