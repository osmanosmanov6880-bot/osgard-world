# IRON PULSE V8.2 — CLEAN REACTOR SIGHTLINES

## Художественный дефект, найденный на настоящем кадре

V8.1 software PASS: commit `ab65413c65baf7e7551ab8476f408db34e81eee9`, [CI #40621122025](https://github.com/osmanosmanov6880-bot/osgard-world/actions/runs/40621122025), где настоящее нажатие C включило `A7_ServiceObservationCamera` и сохранило исходный кадр `browser-evidence/cinematic-reactor-desktop.png` (SHA256 `6119babd8f9aead3e1bf666c7223822cc38f34d3cca7f30149293a07c6feb75f`).

По кадру было видно: большая часть реактора закрыта тремя старинными декоративными объектами, которые не участвуют в игровом процессе — поперечной бирюзовой полосой, массивным цилиндром и чёрной табличкой перед ядром. Отсюда плохая визуальная иерархия даже при правильной камере.

## Реально внесённые изменения в Godot

1. `IPWorldSectors.gd`: 10-метровая полоса и мост галереи сокращены примерно до 3 метров и перенесены на левую сторону. Ранее линия пересекала весь кадр, теперь сохраняет индустриальный контекст слева.
2. Правый большой цилиндр охлаждения и три обслуживающие кольцевые детали физически перемещены в дальний механический отсек шахты (x≈16.25, z≈−12.5) — из луча камера → ядро.
3. `IPReactorAtrium.gd`: информационная плита и два 3D-предупреждения размещены высоко на дальней стене шахты (x≈17.9). Сцена сохраняет diegetic signage, но она больше не перекрывает основное ядро.
4. Существующие вращающиеся элементы, PBR-текстуры, свет, физическое ограждение, две реальные камеры и программа реактора не меняют логику игры.
5. Добавлен новый нативный тест композиционных препятствий: он инспектирует реальные MeshInstance3D в Godot и проверяет положение охлаждения, световой перекладины и табличек относительно луча камеры. Изменение не может считаться принятым только потому, что `geometry_count` не уменьшился.

## Протокол проверки

- Точный HEAD CI должен импортировать Godot 4.4.1 и провести старые игровые тесты V1–V8.1 без регрессий.
- V8.2 native test проверяет физические изменения, реальные таблички/цилиндры/балки, действующую камеру, живую плазму и неизменность состояния игрока при C.
- Windows и WebGL собираются из одного SHA и получают SHA-256 контроль каждой критической части.
- Chromium экспортированной игры делает истинный кадр новой композиции — не рендер концепта. Сравнить с исходным V8.1 фото при одинаковом разрешении 1366×768 и управлении C.
- Человеческая визуальная оценка остаётся отдельным гейтом. Можно зафиксировать улучшенную композицию, но нельзя выдавать процедурный прототип за профессиональный AAA блокбастер.
