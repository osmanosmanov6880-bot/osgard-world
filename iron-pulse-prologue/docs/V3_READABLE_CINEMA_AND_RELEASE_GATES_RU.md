# IRON PULSE — V3 READABLE CINEMA / интерфейс и свет

**Назначение:** исправить реальные недостатки V2: тёмную сцену, перекрытие верхних панелей, полноэкранную полосу HUD и некорректные стрелки управления на телефоне. Успешный CI не равен AAA-сертификации.

## Фактические изменения

- Больше нейтрального заполняющего света; снижена избыточная эмиссия; металлические поверхности стали более читаемыми.
- Заголовок миссии и нижняя карточка действия ограничены по ширине; центр экрана свободен для 3D.
- На телефоне верхние карточки расположены вертикально, не дублируется правая панель.
- Сенсорный D-pad использует читаемые W/A/S/D вместо отсутствующих во встроенном шрифте символов стрелок.
- В read-only QA-маркер добавлены реальные прямоугольники HUD; Chromium блокирует релиз при перекрытии и выходе за границы.
- Новый Godot-тест test_v3_readable_cinema.gd проверяет 1366/390, свет, мобильные кнопки и целостность игрового процесса.
- Все шесть исходных терминалов, правила питания, победа/поражение и старый V2 сохранены.

## Обязательная приёмка

1. Импорт Godot 4.4.1 и native game / 3D / V2 / V3 тесты без ошибок.
2. Windows x64 и WebGL из точного HEAD SHA, SHA256 на файлы.
3. Реальный Chromium на 1366×768 и touch-эмуляции 390×844: управление, локализация, звук, пауза, G/V/M.
4. Проверка фактических прямоугольников HUD, мобильных целей 44+ CSS px и скриншоты без пустого WebGL.
5. Независимая человеческая оценка графики, читаемости и реальной сложности миссии — ещё не заменена автоматикой.
