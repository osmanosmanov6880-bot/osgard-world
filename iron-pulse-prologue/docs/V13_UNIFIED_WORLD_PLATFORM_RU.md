## BLOCK 1 — WEB / действующий глобальный клиент

- Настоящая статическая оболочка `world/index.html`, CSS и JavaScript в тёмной промышленной эстетике. Миссия GRID/HEAT/AIR выбирается в интерфейсе и запускает точный исходный Godot WebGL, не рекламный рендер.
- Отдельный CTA **ТРЁХАКТНАЯ КАМПАНИЯ** запускает реальный `IPCampaignFlow` с первой операции; solo и campaign не путаются.
- Оригинальный локальный знак SVG, RU/EN-тексты, читабельная типографика, keyboard focus, reduced motion, touch-target 48px, отдельное адаптивное правило 320px.
- Настоящий скриншот текущего GitHub SHA будет копироваться без изменения байтов из Chromium Godot `cinematic-reactor-desktop.png`, не создаётся изображение концепта.

## BLOCK 2 — GODOT / строгий контракт запуска

- Новый `IPWorldLaunch.gd` принимает только `scenario=blackout|thermal|breach`, `lang=ru|en` и `campaign=1|0` в URL длиной до 256 символов.
- `campaign=1` всегда начинает с GRID, даже если посетитель добавит `scenario=breach`. Никакие произвольные параметры не запускают игру и не меняют здоровье, время, ресурсы или исход боя.
- Рабочее `Main.tscn` получает настоящий стартовый язык и миссию, не изменяя исходные сохранения, физические терминалы, V8.6 эффекты и V9–V12 кампанию.
- Прежний сценарный выбор в меню по-прежнему действует: явное переключение на одиночную миссию отменяет предустановленный campaign deep-link.

## BLOCK 3 — REPRODUCIBLE DISTRIBUTION

- CI вначале запускает прежние V1–V12 тесты, новый `test_v13_world_launch.gd`, Godot 4.4.1 WebGL и Windows сборки.
- Chromium уже проверяет реальный FPS-independent (software-only) запуск 1366×768/390×844, сцены, HUD, ввод и исходный PNG.
- Новый workflow упаковывает `world-preview` с той же настоящей сборкой и доказательством: 11 файлов, SHA-256, исходный 40-значный SHA, статус SOFTWARE_PREVIEW, неизменённый кадр.
- Второй Chromium тест открывает портал RU/EN, проверяет все CTA и переключатель миссий, страницы 1366/390/320px, размеры сенсорных кнопок и **нажимает реальную кнопку HEAT на портале**, после чего читает показатели самого IPCrisisEngine из Godot WebGL.
- Offline shell PWA теперь использует обновляемую network-first стратегию и **не кэширует** большой движок/ресурсы игры, чтобы не оставлять старый релиз.

## BLOCK 4 — жёсткое решение GO/NO-GO

Успех кода и браузерного CI = рабочий **software preview**, но не мировая коммерческая AAA-платформа. Нужны физическая GPU/Windows производительность, реальные Android/iOS и контроллеры, профессиональные 3D/PBR и оригинальная озвучка, права на IRON PULSE, внешний accessibility QA, плейтест минимум 20 игроков, hosting/caching/security review и отдельное решение о публикации.

Прямой продакшен-деплой и merge в master не выполняются автоматически. Все ветки PR #619–#645, меняющие те же файлы Main.gd, остаются самостоятельными экспериментами. Их объединение требует явного conflict и game-design review, а не механической склейки.

**Статус документа:** результат проверять по точному HEAD текущего интеграционного PR, а не по успешному старому SHA. Не утверждать CI PASS, пока соответствующий GitHub Actions не завершится.
