# IRON PULSE — V5 worldbuilding / Three-sector World

**Цель:** превратить монотонный коридор в исследуемый 3D-комплекс с тремя визуально узнаваемыми зонами. Это процедурный прототип окружения, а не профессиональный AAA-арт.

## Реальная реализация

- REACTOR GALLERY — двойные охлаждающие барабаны, концентрические защитные кольца, обзорная перекладина с голубыми указателями.
- SERVICE SPINE — ёмкости и коллекторы теплообменника, теплоотводящие рёбра, янтарные линии давления.
- EVACUATION LOCK — силовые стойки, укреплённые порталы, предупреждающие полосы, реальный выходной шлюз.
- Три отдельные пространственные 3D-таблички, три источника аварийного света, оригинальные procedural materials.
- 108 палубных элементов выводятся через один MultiMesh, а не 108 дорогих отдельных draw-call объектов.
- Расположение персонажа действительно определяет текущий сектор и журнал из трёх посещённых зон. Переведённые названия отображаются в UI RU/EN.
- Аварийная подсветка реагирует на текущий сценарий HEAT/AIR/GRID и виртуальные показания; reduced motion ограничивает интенсивность.
- HERO/ECO реально скрывает или возвращает дополнительные конструкции, оставляя навигационные таблички и путь доступными.

## Проверяемость

1. Godot 4.4.1 загружает класс IPWorldSectors, основную сцену и прежние три аварийных сценария V4.
2. Source-bound native test проверяет минимум 40 оригинальных 3D-объектов, три визуальные зоны, три таблички, 108 инстансов, три источника света.
3. Физическое движение игрока между z=-12, -35 и -55 в тестовой сцене изменяет текущую зону, историю посещения и заголовок RU/EN.
4. Переключение G на ECO скрывает дополнительную геометрию и возвращает её без изменения условий победы; при перезапуске история исследования очищается.
5. Chromium WebGL дополнительно проверяет реальную графическую сцену, знаки и MultiMesh по read-only данным настоящего движка на ПК и touch-эмуляции.
6. Windows x64 + WebGL экспортируются из одного HEAD с SHA-256 доказательством; никакого выпуска production без реальных устройств.
