# IRON PULSE WORLD V14 — реальные локальные проверки перед запуском

База: V13, коммит `98865d7b3fc48b5278881fd31bab9c0bad70ff68`, PR #648, успешный GitHub Actions #40757193879.

## Новое
- На той же странице WORLD размещена секция локальной проверки WebGL2, WebAssembly, наличия Godot WebGL ресурсов и CI-манифеста.
- Выполняется только после явного нажатия кнопки; отсутствуют трекеры и отправка отчётов. Все запросы только на same-origin файлы игры.
- Проверка WASM/PCK использует HEAD, не загружает огромные бинарные файлы для измерения.
- Доступен загружаемый JSON-отчёт без персональных сведений; SHA — только публичный хэш исходной сборки.
- RU/EN, статусы в aria-live, минимальные цели для касания, работа при ограниченной ширине и reduced motion.
- Отсутствие сети — предупреждение; игра не кэшируется офлайн. Диагностика не заменяет тест реального GPU/телефона.

## Приёмка
CI должен проверять наличие V14-ресурсов и контракт локальной диагностики, отсутствие исходящих API/аналитики, работу реального игрового CTA и автоматизированные Chromium проверки. Производственный статус — HOLD. Не менять Godot-геймплей, локальные сохранения или ранее опубликованные артефакты.
