# IRON PULSE — V7 THE RESCUE NETWORK

## Фактический результат разработки

К прежним трём авариям, трём 3D-секторам и оригинальной истории MARA добавлен второй **необязательный** слой стратегии: три реальные 3D-станции, из которых игрок может использовать только две. Третья становится недоступна — принятые решения действительно исключают альтернативы.

| Станция | Позиция в игровом комплексе | Реальный эффект | Цена |
|---|---|---|---|
| MEDBAY | Реакторная галерея, z=-23 | +13 кислорода, +18 здоровья экипажа | 6 сек, +4 температуры |
| QUENCH | Технический сектор, z=-39.5 | -18 температуры, будущие тепловые импульсы с коэффициентом 0.55 | 6 сек, -5 кислорода |
| UPLINK | Эвакуационный шлюз, z=-53 | +40 сек эвакуации, +12 заряда двери | 6 сек, -4 здоровья экипажа |

Правила изменяют настоящий IPCrisisEngine, не картинку HUD. У каждой станции есть физический Node3D, 3D-надпись, световая полоса, изменяющая состояние после использования, и самостоятельная RU/EN реплика MARA. Рядом с консолью подсказка E; на телефоне USE / E. После двух активаций сеть закрывается. Выбор и защита от третьей активации записываются в локальный чекпойнт.

### Поддержка геймпада (программная)

В движке появились стандартные события Godot: левый стик — перемещение, правый — обзор, A — действие, X — быстрый ремонт, Y — фонарик, B — радиоархив, START — пауза, крестовина вверх/вниз — приоритет экипажа/реактора. Граница dead zone 0.18. **Реальный физический геймпад пока не сертифицирован**; только нативный тест событий.

### Принцип совместимости

- V6 и все старые V1–V5 сценарии остаются проходными без использования спасательной сети.
- Ранее сохранённые V6 checkpoint-файлы не содержат relay-полей и автоматически воспринимаются как нулевая активация.
- Подделка третьей активации, повторной активации или thermal shield без QUENCH отвергается до изменения состояния игры.
- Все координаты фиксированы и не требуют скачанных ассетов; никакого сетевого соединения.

## Жёсткая инженерная приёмка

1. Godot 4.4.1 импорт + все прежние тесты V1–V6 проходят.
2. Новый тест доказывает реально отличающиеся плюсы/минусы трёх станций, ограничение 2/3, сдерживание импульса, существующий путь победы, неповторяемые награды и защищённый чекпойнт.
3. Нативный тест 3D-сцены физически переводит персонажа к каждой консоли и взаимодействует через E/геймпад A; проверяет световой статус, локализацию, радиоархив, паузу START и полное восстановление двух выбранных станций.
4. WebGL и Windows x64 экспортируются из одного SHA, отдельные SHA-256 сходятся с манифестом.
5. Реальный Chromium проверяет 1366×768 и touch 390×844, присутствие трёх исходных 3D-станций, работу прежних миссий, русско-английского радио и управления.
6. Физические компьютеры, реальные контроллеры и мобильные устройства ещё требуют независимой ручной приёмки. До этого — SOFTWARE PREVIEW / PRODUCTION HOLD.
