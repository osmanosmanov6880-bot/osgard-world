# IRON PULSE — BLACKOUT / ГЛАВА 00

**Статус:** отдельный вертикальный срез, находящийся в разработке. Не заменяет одобренный шестимиссионный OSGARD / IRON PULSE W58. Проект автономен и не управляет реальным оборудованием.

## Что действительно реализовано

- Управляемый от первого лица персонаж в процедурном 3D-комплексе: WASD, SHIFT, мышь, E, ESC, F.
- Шесть реальных 3D-терминалов, реактор с тремя движущимися кольцами, световые сигналы, коридор и аварийная дверь.
- Сквозной маршрут: сканировать реактор → починить охлаждение → перенаправить питание → зарядить дверь → восстановить жизненно важные контуры → авторизовать выход → эвакуироваться.
- Две питающие линии на три системы: COOLANT, LIFE, DOOR; последствия неправильных решений, скачок напряжения, ограничение времени, победа/поражение, перезапуск и оценка.
- Русский и английский язык, экран цели, расстояния до консолей, состояние охлаждения/кислорода/экипажа/двери, виртуальные кнопки для сенсорных экранов.
- Локальный ограниченный журнал диагностики. Нет внешних сетевых запросов, регистрации, телеметрии, рекламных SDK, продаж, доступа к физическому оборудованию.
- Нативные тесты чистого игрового состояния и 3D-сцены; GitHub Actions импортирует проект, проверяет WebGL в Chromium с реальными клавишами и сохраняет скриншоты, формирует WebGL/Windows тестовые сборки.

## Управление

| Клавиша | Действие |
|---|---|
| W A S D | Идти |
| SHIFT | Бежать |
| Мышь | Осматриваться; ESC — снять захват |
| E | Использовать ближайший терминал (в пределах 3,15 м) |
| F | Фонарь |
| L | Сменить RU/EN |
| ESC | Пауза |
| R | Перезапуск после окончания |

На узком экране включаются сенсорные кнопки перемещения, взаимодействия и смены языка; свайп правой половины экрана вращает камеру. **Это не подтверждённая приёмка на реальных телефонах.**

## Запуск Godot 4.4.1

Откройте `iron-pulse-prologue/project.godot` в Godot 4.4.1 (standard). Нажмите F6/F5 для `Main.tscn`. Или:

```bash
godot --path iron-pulse-prologue
```

## Проверки

```bash
godot --headless --editor --path iron-pulse-prologue --import --quit
godot --headless --path iron-pulse-prologue --script res://tests/test_crisis_engine.gd
godot --headless --path iron-pulse-prologue --script res://tests/test_scene.gd
```

Для WebGL после установки экспортных шаблонов:

```bash
mkdir -p iron-pulse-prologue/build/web
(cd iron-pulse-prologue && godot --headless --path . --export-release Web build/web/index.html)
```

Для Windows:

```bash
mkdir -p iron-pulse-prologue/build/windows
(cd iron-pulse-prologue && godot --headless --path . --export-release "Windows Desktop" build/windows/IRON_PULSE_BLACKOUT.exe)
```

Публикация: test-only CI artifacts, **не продуктивный выпуск**. W58 девять проверок и исторические SHA неприменимы автоматически к новой игре. Включение этой сцены в основное меню и выпуск на Steam — отдельный review gate.

## Чего пока нет

Профессиональных уникальных персонажей/анимации, озвучки, редакторских кат-сцен, крупных уровней, подтверждённого GPU-бюджета на массовых устройствах, коммерческой лицензии саундтрека, Steam-страницы, независимых пользовательских тестов и художественного утверждения. Не следует называть это AAA или готовым блокбастером.

## Проверка в Chromium

Новый файл `ci/browser_webgl_acceptance.py` запускает реальный WebGL-экспорт через локальный HTTP в Chromium с программным видеоускорением и отслеживает **только доступную для чтения** диагностику игры. Фактические кнопки запуска, ходьбы, смены языка и паузы отправляются клавиатурой. Скриншоты сохраняются в CI-артефакте, без подмены изображений. Реальная мобильная производительность этим тестом **не сертифицируется**.

## V2 — AAA FOUNDATION (отдельная графическая и аудиоприёмка)

- Процедурная кинематографическая архитектура, крупные элементы реактора,
  направляющие, аварийный свет, 280 геометрических деталей через 2 `MultiMesh`
  и более 120 отдельных архитектурных элементов.
- Четыре оригинальных звуковых WAV, воспроизводимый генератор `tooling/generate_original_audio.py`,
  полное отсутствие сетевой телеметрии.
- Реальные шкалы четырёх жизненно важных систем, указатель пути до консоли,
  динамический свет опасности, ускорение/торможение и мягкая камера.
- `G` — HERO/ECO; `V` — уменьшение движения камеры; `M` — звук вкл/выкл.
  ECO включается по умолчанию на узких экранах.
- В исходники добавлен отдельный нативный тест `tests/test_aaa_foundation.gd`,
  а браузерная приёмка проверяет переключатели реальным вводом пользователя.

**Проверка (после установки Godot 4.4.1):**

```sh
godot --headless --editor --path iron-pulse-prologue --import --quit
godot --headless --path iron-pulse-prologue --script res://tests/test_aaa_foundation.gd
```

Это ещё не игра класса AAA по масштабу/бюджету/контенту. Слова «AAA FOUNDATION»
означают этап подготовки графики, звука и качества взаимодействия. Сохраняется
**PRODUCTION HOLD** до подписанной аппаратной, пользовательской и художественной приёмки.
Подробности: `docs/AAA_FOUNDATION_V2_RU.md`.
