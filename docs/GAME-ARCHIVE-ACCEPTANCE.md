# OSGARD PLAY — игровая предрелизная проверка архива

`scripts/verify-game-archive.py` проверяет готовый релизный ZIP **без извлечения файлов, сети и публикации**. Он подтверждает состав игровых маршрутов и ограниченный контракт декларативных ресурсов HTML/CSS. Успех этой проверки не подтверждает запуск, проходимость или готовность игр к production.

```sh
python3 scripts/verify-game-archive.py /private/osgard-release.zip
python3 -m unittest discover -s tests -p test_game_archive.py -v
python3 -m py_compile scripts/verify-game-archive.py tests/test_game_archive.py
```

Функция `verify(archive)` возвращает словарь; CLI выводит его как JSON и завершает работу с кодом `0`. Нарушение контракта вызывает исключение; CLI выводит `GAME RELEASE BLOCKED: ...` в stderr и возвращает `2`. Позиционный аргумент ZIP, существующие ключи результата и значения `status`, `zion_worlds`, `legacy_entrypoints` сохранены для `staging-release-acceptance.py`.

## Маршруты и HTML

Обязательны:

- `index.html`, `games/index.html`, `play/index.html` — три страницы каталога.
- `games/zion-9/worlds.json` — JSON-объект с ровно 11 уникальными мирами `zion-020`–`zion-030`. Каждый `route` должен точно соответствовать `/games/zion-9/queue/ZION-XXX/index.html` своего ID.
- 11 HTML-файлов этих миров.
- Восемь legacy-точек входа: `afterimage-run`, `empire-orbit`, `inherit`, `null-shift`, `remix`, `swarm`, `time-empire`, `vector-zero`.

Все 22 обязательные HTML-страницы разбираются стандартным `HTMLParser`. Нужны реальные открывающий и закрывающий теги `html`; текст `"<html>"` в комментарии или внутри скрипта не считается оболочкой. Это базовая проверка оболочки, не полная HTML-валидация. Дополнительно обходятся локальные документы из объявленных `iframe src`, HTML-объектов и соответствующих ссылок предварительной загрузки. Повторный обход одного документа не выполняется.

Парсер учитывает атрибуты без кавычек, порядок атрибутов, регистр HTML, HTML-сущности и первое значение дублирующегося атрибута. Комментарии, текст скриптов, содержимое `title`/`textarea`, неактивные `template` и `noscript` не превращаются в ложные ссылки на файлы. Контракт рассчитан на включённый JavaScript.

## Какие ресурсы обходятся

| Объявление | Проверка |
|---|---|
| `script src` классического JS или `type=module` | Наличие и содержимое локального скрипта |
| `link rel=stylesheet`, `modulepreload`, иконки, manifest | Проверка по типу ресурса |
| `link rel=preload` с поддерживаемым `as`, `prefetch` | Наличие объявленного ресурса; `as=style` запускает обход CSS |
| `img src/srcset`, `source src/srcset`, `input type=image`, image-preload `imagesrcset` | Проверка всех объявленных кандидатов, независимо от DPR/ширины экрана |
| `video`/`audio`/`track` `src`, `video poster` | Наличие и базовая проверка содержимого |
| SVG `image`/`use`/`feImage` `href` или `xlink:href` в HTML | Внешний файл; ссылка на локальный `#id` не требует файла |
| `style` и атрибут `style` | Литералы CSS `url(...)` и `@import` |
| Внешний CSS и вложенные импорты | Рекурсивный обход `@import "theme.css"` и `@import url(...)`; файлы из `url(...)`, включая изображения и шрифты |

`canonical`, обычные `<a href>`, `alternate`, `preconnect` и `dns-prefetch` не обозначают загружаемый локальный ассет и исключены. JSON/data-скрипты не считаются исполняемыми `script src`. Все объявленные варианты, включая media/alternate-stylesheet и источники изображений, проверяются консервативно; браузер может выбрать лишь часть из них.

CSS разбирается ограниченным лексическим сканером: комментарии и обычные строковые значения пропускаются, кавычки и CSS-escape-последовательности обрабатываются. Повторный CSS обрабатывается один раз по паре «путь, тип»; циклические импорты не вызывают бесконечный обход. Ошибки лексического разбора URL/строк/комментариев блокируют контракт, а не скрывают зависимость.

## Разрешение URL

- Относительные ссылки HTML разрешаются относительно страницы и первого `base href`, если он задан. Относительные ссылки внешнего CSS — относительно самого CSS-файла.
- `/assets/file.js` адресует корень ZIP. Query string и fragment не входят в имя файла. URL-кодирование пути снимается ровно один раз; HTML-сущности обрабатывает HTML-парсер.
- Относительные `../` допустимы только в пределах корня ZIP. Абсолютные пути с `.`/`..`, выход за корень, обратные слеши, управляющие символы, неправильные `%`-последовательности и закодированные разделители `%2f`/`%5c` отвергаются. Контракт не полагается на серверную нормализацию неоднозначных URL.
- Локальный документ с путём, заканчивающимся `/`, сопоставляется с `index.html` в этой папке. Для ассетов не подбираются запасные расширения и не имитируются SPA rewrites.
- Пустой URL объявленного ресурса блокируется. `script src="?v=2"` и `script src="#code"` разрешаются в текущий документ и блокируются как HTML вместо JS. CSS `url(#filter)` — локальная ссылка, она не требует отдельного файла.
- `http:`, `https:` и `//host/...` пропускаются с отдельным счётчиком; даже абсолютный URL собственного production-домена остаётся внешним для этого офлайн-контракта. При внешнем `base` относительные ресурсы также считаются внешними.
- `data:` и `blob:` учитываются как встроенные/создаваемые во время работы и не декодируются. Точное значение `about:blank` допустимо только для ресурса типа document, например пустого iframe, и учитывается как встроенный документ без чтения ZIP. В script/CSS/изображениях `about:` запрещён; другие значения `about:` и прочие схемы в загружаемых ресурсах также блокируются.

## Проверка содержимого

Наличие ZIP-записи недостаточно. Загружаемый локальный ресурс не должен быть пустым или состоять только из пробелов. HTML-подмена вместо JS, CSS, изображения или другого ассета блокируется, включая HTML после BOM, длинного пробельного префикса и комментариев.

JS и CSS должны декодироваться как UTF-8 и не содержать бинарные NUL; начало с XML/иной разметки также отвергается. Проверка не анализирует синтаксис JavaScript. Допустим обычный скрипт со строкой `"<html>...</html>"` внутри программы.

SVG должен быть UTF-8, корректным XML с корнем `svg`. DTD и объявления сущностей запрещены, чтобы проверка не обрабатывала их расширение. Для известных расширений PNG/APNG, JPEG, GIF, ICO, WebP, WOFF/WOFF2, TTF/OTF и WASM сверяется базовая сигнатура. Web manifest должен содержать JSON-объект. Эти проверки не заменяют декодер изображения, шрифта, аудио или видео и не доказывают целостность формата целиком.

## Ограничение чтения и обхода

| Ограничение | Значение |
|---|---:|
| Манифест миров или web manifest | 256 КиБ |
| Один HTML | 8 МиБ |
| Один JS или CSS | 8 МиБ |
| Прочий подключённый ресурс | 32 МиБ |
| Сумма байтов, прочитанных при проверке | 128 МиБ |
| Все обрабатываемые ссылки, включая внешние | 20 000 |

Размер проверяется до декомпрессии, а само чтение дополнительно ограничено. Глобальные лимиты сдерживают разветвление CSS/HTML-графа. Содержимое повторяющихся ресурсов не сохраняется в неограниченном кэше. ZIP не извлекается; опасные имена, шифрованные записи, симлинки, повторяющиеся и конфликтующие по регистру файловые имена блокируются.

Это не полный аудит всех записей ZIP: не связанные с контрактом файлы не распаковываются и не читаются. Центральный каталог ZIP всё равно загружает стандартная библиотека. Общую целостность релизного пакета, манифест поставки и привязку к сборке проверяют отдельные `verify-release-zip.py`, `verify-zip-manifest.py` и staging-проверки.

## Как читать результат

| Поле | Значение |
|---|---|
| `status=verified` | Указанный выше офлайн-контракт выполнен |
| `zion_worlds=11`, `legacy_entrypoints=8` | Подтверждён обязательный состав игровых точек входа |
| `catalog_entrypoints=3` | Проверены три обязательные HTML-страницы каталога |
| `local_dependencies_checked` | Число локальных ссылок, включая повторные ссылки из разных страниц и CSS; не число уникальных файлов |
| `asset_files_checked` | Число уникальных файлов, достигнутых по локальным ссылкам |
| `css_files_checked`, `html_files_checked` | Число разобранных CSS/HTML-файлов; вложенные документы могут увеличить число HTML сверх 22 |
| `external_references_skipped` | Внешние ссылки, для которых проверка доступности не выполнялась |
| `embedded_references_skipped` | `data:`, `blob:`, пустые документы `about:blank` и локальные SVG/CSS-фрагменты |
| `dependency_scope=declarative_html_and_literal_css` | Явно ограниченная область обхода |
| `runtime_execution_performed=false`, `publication_performed=false` | Скрипты не запускались, публикация не выполнялась |

## Границы приёмки

Валидатор **не строит полный граф JavaScript-зависимостей**: `import`, динамический `import()`, `fetch`, Web Workers, service workers, создаваемые через JS теги и вычисляемые URL остаются за пределами этой проверки. В частности, успешный результат сам по себе не подтверждает загрузку динамического Three.js или Unity `.data/.wasm/.framework.js.gz`.

Также не обходятся `iframe srcdoc`, ресурсы внутри внешнего SVG, иконки/скриншоты внутри web manifest, строковые URL в `image-set()` без `url()`, source maps и содержимое `data:`/`blob:`. Нет эмуляции полного HTML5 tree builder, runtime-изменений `base`, CSS cascade, медиавыражений, правил HTTP `Content-Type`/`Content-Encoding`, CSP или поведения CDN. Изменённые маршруты и новые способы объявления ресурсов требуют расширения контракта и соответствующих регрессионных тестов.

Запуск, управление, локализацию, WebGL/Canvas, сетевые API, сохранения, звук и реальные устройства необходимо проверять отдельно в браузере. Название `verified` нельзя переносить на эти неподтверждённые свойства.
