# OSGARD PLAY — игровая предрелизная проверка архива

Проверяет готовый релизный ZIP **без извлечения на сервер**: маршруты каталогов `/games/`, `/play/`, 11 ZION-миров (020–030), восемь основных игровых точек входа и наличие файлов, локально подключаемых HTML-страницами ZION.

```sh
python3 scripts/verify-game-archive.py /private/osgard-release.zip
python3 -m unittest discover -s tests -p test_game_archive.py -v
```

**Ограничения:** проверяются 19 игровых точек входа в составе архива, но не факт, что каждая игра запускается и проходима. Не выполняется JS, не проверяется WebGL/Canvas, управление, локализация, сеть и физические устройства. Некоторые игровые пути могут отличаться в конкретной сборке: изменения маршрутов требуют корректировки контракта и отдельной приёмки. Отсутствие локальной зависимости блокирует релиз; внешние URL этот валидатор не проверяет.

Статусы успеха нельзя трактовать как результаты реального браузерного тестирования. Production не изменяется.

## Ограничение памяти при проверке ZIP

Манифест миров читается только до 256 КиБ, HTML одного мира — до 8 МиБ, с проверкой размера записи до декомпрессии. Большие файлы отвергаются без загрузки в память целиком. Прочие ZIP-активы по-прежнему проверяются отдельными модулями `verify-release-zip.py` и `verify-zip-manifest.py`; поэтому валидатор игрового каталога не заменяет общую проверку архива.
