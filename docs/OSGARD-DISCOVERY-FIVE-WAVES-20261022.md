# OSGARD — пять волн разработки Discovery 2.0

**Основа:** актуальный на момент создания ветки `master` (`8556885ffb3499c9c04e7942029167689d5b5280`), в котором уже присутствуют предыдущие редизайны Play, World, Academy, Intelligence, Development и Entertainment. **Изолированная ветка:** `feature/osgard-discovery-5waves-master-20261022`. Существующие игры, API, регистрация, прогресс, платежи и production не менялись.

## WAVE 1 — Прямая навигация в игровые и учебные миры

Вместо 16 разделов навигатор индексирует **43 настоящих направления**:

- 12 существующих разделов экосистемы,
- четыре реальные страницы Development,
- 19 игровых миров из `playGameTitles.ts`,
- восемь отдельных уроков из `osaLessonRegistry.ts` с названиями из `brandNavigation.ts`.

Детали Play доступны по `/play/world/{slug}`, уроки по `/lectures/{slug}`. Реестры переиспользуют настоящие идентификаторы; статусы серверных функций не придумываются.

## WAVE 2 — Понятный поиск

- Результаты сортируются по совпадению названия.
- Добавлены поисковые синонимы по механикам: «добавь тень», «полярность», «рейд», «империя времени».
- Исправляется ввод при неверной английской раскладке (`frfltvbz` → «академия», `buhs` → «игры») **только если обычный поиск ничего не нашёл**.
- Поиск полностью локальный, не использует AI API, чужие сайты, телеметрию и не индексирует пользовательские данные.

## WAVE 3 — Премиальный визуальный навигатор

- Доступные с клавиатуры переключатели «Все / Игры / Знания / Проекты / Экосистема» с реальными количествами маршрутов.
- Настоящие самохостируемые игровые обложки `/brand/play/{id}-640.webp` и изображения четырёх публичных кейсов.
- Три быстрых перехода в контексте открытого раздела: Play → каталог/избранное/недавние; Academy → кабинет/уроки/прогресс; Development → кейсы; World → главные продукты.
- На мобильных экранах подсказки и миниатюры адаптируются к ширине; список прокручивается внутри диалога.

## WAVE 4 — Клавиатура, доступность, безопасность переходов

- Стрелки, **Home/End**, Enter, Escape, Tab и автоматическая прокрутка выбранного результата.
- Сохранены `role=dialog`, `aria-modal`, `role=combobox`, `aria-activedescendant`, `aria-selected` и удержание фокуса внутри диалога.
- Дополнительная клавиша `/` вызывает навигацию **только** вне полей ввода и интерактивных игровых миров. `Ctrl/⌘+K` сохранён.
- Все переходы продолжают использовать основной SPA-роутер и блокировку ухода при незаписанных изменениях. Недавние команды хранятся только внутри текущей вкладки.

## WAVE 5 — QA и критерии готовности

- `npm run check`, `npm run qa:unified-shell`, `npm run build`;
- `npx playwright test --config playwright.ecosystem.config.mjs`: реальные desktop/mobile сценарии для прямой игры, конкретного урока OSA, поиска с неверной раскладкой, миниатюр, фильтрации, Home/End, контекста и безопасного `/`;
- CI дополнительно проверяет, что все самохостируемые превью-файлы физически присутствуют, а все командные маршруты локальные и уникальные.
- Обязательны зелёные GitHub Actions: **frontend/browser**, **OSA visual**, **release readiness**, **REMIX launcher safety**, **Cloudflare build**.

### Проверка разработчиком

```bash
npm ci
npm run check
npm run qa:unified-shell
npm run build
npx playwright test --config playwright.ecosystem.config.mjs
```

### Что не заявляется

Тестовая ветка не подтверждает живую авторизацию, оплату, WebGL2 на устройствах пользователя, multiplayer и production CDN. Новые функции Discovery не заменяют клиентское QA ни одной из игр. Если CI падает, статус остаётся DRAFT, а ошибки исправляются в этой же ветке.

### План выпуска

Сверить head SHA с последним прошедшим CI, просмотреть desktop/mobile скриншоты, проверить совместимость с новыми изменениями `master`, наличие резервной копии и путь rollback. Слияние в `master` запускает существующий frontend deploy, поэтому **никакого автоматического слияния или публикации из этой задачи**. Развертывание требует отдельного подтверждения и post-deploy smoke.

## Совместимость с текущими релизами OSGARD

- Исходный PR #186 послужил проверяемой основой Discovery 2.0, но не переносился как устаревшая целая ветка поверх master. В новую ветку взяты только целевые навигационные, визуальные и браузерные файлы.
- **Time Omega III v0.22**, новые игровые релизы REMIX ARENA и Shadow Protocol сохранены в точности из master `8556885ffb3499c9c04e7942029167689d5b5280`; никакие игровые HTML, release manifest, сохранения, API, Auth или SSH-деплой не изменялись.
- Исправлена ошибка исходного CI: префикс `game-` также имеет команда `game-archive`, поэтому 19 реальных игровых страниц теперь проверяются по маршрутам `/play/world/`, а архив проверяется отдельно. Проверка не исключена и не ослаблена.
- Валидация выполняется именно на HEAD новой ветки, с учётом изменений в master. Production не обновляется из этого PR.
