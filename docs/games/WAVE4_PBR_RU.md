# OSGARD WORLD — WAVE 4: IMPORTED PBR ASSETS / ГРАФИЧЕСКАЯ СБОРКА

Этот выпуск переводит главные 3D-объекты двух игр с чисто процедурных GDScript-примитивов на импортируемые **оригинальные GLB-ассеты** с PBR-текстурами.

## Что входит

- **VECTOR//ZERO:** авторская магнитная установка с 12 продольными стойками, двумя медными винтовыми обмотками, 13 кольцевыми катушками, фланцами и крепежом; отдельный детализированный 12-секторный приёмник.
- **Империя времени:** 3D-хронореактор с физическими опорами, многоярусными кольцами и индукционными обмотками; уникальная 21-метровая закрученная башня с горизонтальными фасадными поясами, импортируемая в двух экземплярах.
- Два варианта геометрии: **PC Ultra** и **Web LOD**. Godot выбирает нужный вариант автоматически по `OS.has_feature("web")`.
- 4 канала PBR-данных: albedo, metalness, roughness, normal. Все материалы и геометрия созданы программно; коммерческие ассеты чужих игр не использовались.
- На настольном ПК проект использует **Godot Forward+** (при наличии совместимой графики), а Web остаётся на **Compatibility/WebGL 2**.
- Игровая логика, русские кнопки, магнитные испытания, экономика и сохранения остаются прежними.

## Сборка моделей из открытого исходного кода

Из корня репозитория:

```
python3 -m pip install trimesh==4.11.1 numpy==2.3.5 Pillow==12.3.0
python3 scripts/build_osgard_wave4_assets.py --project vector-zero
python3 scripts/build_osgard_wave4_assets.py --project time-empire
python3 scripts/validate_wave4_assets.py --project vector-zero
python3 scripts/validate_wave4_assets.py --project time-empire
```

Затем открыть соответствующую папку `godot/vector-zero` или `godot/time-empire` в Godot 4.7.2. При экспорте Web Godot сам упакует подготовленные `.glb`. GitHub Actions автоматически создаёт модели, проверяет импорт, тесты сцены, экспорт и сохраняет игровые артефакты.

## Ограничения и честная оценка качества

Это шаг от процедурных MeshInstance3D к полноценным отдельным 3D-активам, а **не доказательство уровня AAA-фотореализма**. Для такого качества дополнительно потребуются художники окружения, профессиональное UV-развёртывание, запекание текстур из high-poly, масштабные сцены, полный звуковой дизайн, анимация и тесты FPS на реальных GPU.

Не заменяйте текущие публичные игры до ручного теста Web-сборок, подтверждения мобильной производительности и согласованного переноса сохранений.
