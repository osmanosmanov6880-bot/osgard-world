# OSGARD WAVE 5 — РАЗРАБОТКА И ПРОВЕРКА

Реальный код Godot 4.7.2, новые импортированные GLB-объекты, отдельные PBR-текстуры,
анимированные механизмы, условная Forward+ постобработка, профили качества, отчёты.

`VECTOR//ZERO`: инженерные системы охлаждения, защитный шлюз, механический мост,
реалистичные металлические панели, анимированные вентиляторы и маяк.

`ИМПЕРИЯ ВРЕМЕНИ`: уникальные аркологии, солнечная подстанция, транспортный
терминал, PBR-покрытие города, приборные кольца и динамическое освещение.

CI сначала генерирует GLB / PBR, проверяет геометрию и затем запускает Godot,
тесты, Web и Windows PC Ultra экспорт. Отдельно сохраняется CI software-render
performance report, который НЕ является замером на игровой видеокарте.

См. `docs/games/OSGARD_WAVE5_RELEASE_AND_GPU_QA_RU.md` для процедуры тестирования
реального ПК, F8/F9/F10 и интерпретации 1% low. Реальные данные GPU появятся только
после запуска на устройстве.
