# OSGARD WORLD — Wave 6: cinematic material/architecture and reproducible hardware QA

Дата: 23.10.2026. Godot 4.7.2. Отдельные исходники для VECTOR//ZERO и CHRONOS CITY.

## Что действительно добавлено

- Шесть собственных 512×512 наборов PBR-материалов, каждый с независимыми картами albedo/normal/roughness/metallic; генератор воспроизводим без внешних текстур.
- VECTOR//ZERO: двусторонние детализированные сервисные башни, анимированные вентиляторы, подводы охлаждения, фоновые модули, фотонные направляющие магнитной установки, видимая маркировка.
- CHRONOS CITY: объёмный эстакадный маршрут, два уникальных общественных здания, вертикальные сады и движущиеся вагоны.
- Постобработка Wave 5 сохранена: SSAO/SSIL/SSR/volumetric fog строго при наличии Forward+; Godot Web использует Compatibility.
- Добавлен *воспроизводимый реальный тест*: фиксированные 1080p и 1440p, Ultra/Balanced, 30 секунд замеров после прогрева. Пишет FPS, p50/p95/p99, draw calls, память GPU, название GPU и метод рендера.
- CI использует Xvfb/llvmpipe и маркирует такие измерения software-only. **Это не подтверждение работы на реальной видеокарте.**

## Windows, настоящий GPU

Скачать архивы обеих Windows-игр, распаковать вместе с `TEST_GPU_WINDOWS_RU.cmd` в одну папку и запустить `.cmd`. Для стабильной оценки рекомендуется подключённая дискретная видеокарта с актуальным драйвером. Результаты будут в `GPU_REPORTS_WAVE6/`.

Режим F9 показывает live FPS, F10 сохраняет телеметрию; интерфейс остаётся на русском. Результаты Windows hardware теста не создаются автоматически на удалённой машине пользователя.

## Контроль допуска

1. CI: генерация и количественная проверка 24 текстур на каждую игровую пару, Godot import и gameplay smoke.
2. CI: Wave 6 regressions, автоматизированный Xvfb замер и подлинный кадр Godot.
3. CI: Web и Windows-экспорт (.exe + .pck), ZIP-проверка.
4. На физической Windows-машине: запустить `TEST_GPU_WINDOWS_RU.cmd` и изучить JSON. Hardware PASS требует физического GPU, Forward+ и стабильных p95 <=16.67ms при целевом профиле.
5. До успешной аппаратной проверки опубликованная игра на osgard.world не заменяется.

Ни один кадр от Godot CI не следует называть кадром с физической игровой GPU без подтверждения устройства.
