# OSGARD WORLD — WAVE 8 / инженерный и художественный проход

**Проекты:** VECTOR//ZERO BLACKFIELD и «Империя времени» / CHRONOS CITY.

## Что изменено

- VECTOR//ZERO: два CNC-профилированных резервуара высокого давления, промышленная магистраль, новые конструкционные стойки, инстансированные крепления, датчики и анимация приводов. Магнитная физика и 3 испытания не изменены.
- CHRONOS CITY: физический мост от города до материкового берега длиной ~60 игровых единиц, 14 опор, действующий монорельс с тремя вагонами, портовый терминал с мостовым краном. Экономика, строительство и сохранения не переписываются.
- 6 наборов оригинальных PBR-поверхностей, 24 карты: albedo, normal, roughness, metallic. Поверхности имеют крупномасштабные швы/технические царапины и сглаженный микрорельеф, чтобы не создавать шум на рендере.
- Раздельные профили графики: Compatibility/Web — облегчённая геометрия; Forward+/ПК — более плотные поверхности, физически корректные материалы, экранные эффекты по профилю качества.
- Два изолированных Wave 8 smoke-теста, старые Wave 6/7 тесты и Godot сборка Windows/Web.

## Запуск исходников

При разработке проекта из GitHub вручную сначала установите Python 3 + Pillow + numpy и выполните из корня репозитория:

```shell
python scripts/build_osgard_wave8_materials.py --project vector-zero
python scripts/build_osgard_wave8_materials.py --project time-empire
```

Затем импортируйте проекты `godot/vector-zero/project.godot` и `godot/time-empire/project.godot` в Godot 4.7.2. GitHub Actions выполняет это автоматически.

## Проверки (без подмены hardware сертификации)

Сборка в GitHub Actions с Mesa llvmpipe подтверждает загрузку моделей, тесты логики и экспорт файлов, **но не доказывает 60 FPS на игровой видеокарте**. Windows GPU-тест не доступен здесь: нет устройства `/dev/dri` и доступного дискретного GPU runner.

Пакеты PC Ultra включают `TEST_GPU_WAVE7_ALL.cmd` и `CERTIFY_GPU_WAVE7.ps1`. Запускать их следует на целевом компьютере с RTX/Radeon/Arc, без виртуального дисплея, при 1080p и 1440p. Дополнительная утилита `check_wave8_gpu_reports.py` требует все восемь JSON и отклоняет llvmpipe/SwiftShader и неполные профили. Цель — не менее 60 FPS в среднем и p95 кадра не более 16,67 мс. Указать факт проверки на реальном железе можно только после получения результатов от машины.

## Граница качества

Этот проход улучшает конкретные материальные объекты и читаемость сцены. Он **не является** доказательством AAA-фотореализма, ray tracing или оптимизации на пользовательском GPU. Для полноценного уровня коммерческого AAA нужны авторские artist-made высококачественные модели, продуманная компоновка уровней, специализированные текстуры и ручной арт-дирекшн.
