# OSA — единый источник правды и статус релиза

Дата аудита: 2026-10-15.

## Единый источник правды

- **Основная кодовая база:** https://github.com/osmanosmanov6880-bot/osa-global-intelligence — Next.js-приложение, интерактивное кино, Decision Lab, AI Field Guide, документы производства и медиаманифест.
- **Публичная интеграция:** https://osgard.world/ — пользовательский слой, не зеркальная копия Next.js-репозитория.
- **Репозиторий для сравнения:** https://github.com/osmanosmanov6880-bot/osa-global-intelligence-2 — reference snapshot. Переносить конкретные улучшения после сравнения; не выпускать как отдельный параллельный продукт и не удалять без отдельного решения.

## Маршрут пользователя

1. `/` — OSA Intelligence, главная точка входа.
2. `/osa-cinema` — интерактивная история, три акта, сцены и решения.
3. `/academy` — практика, самопроверка и рабочая студия; прогресс хранится в браузере.
4. `/lectures` — каталог сцен курса.
5. `/osa-library/` — единая карта курса, инвентаризация медиа и статус видеоверсии.
6. `/development/osa-intelligence/` — портфолио-кейс, не учебный плеер.

## Что подтверждено

- В OSGARD есть интерактивные сцены и пояснения; это веб-интерактив, не записанный фильм.
- В `public/interactive-cinema/media-manifest.json` перечислен 31 ресурс: 19 видео, 9 аудио, 3 изображения. У всех записей `permanentUrl: null`.
- В деревьях репозиториев нет готовых MP4/WebM/MOV/MP3/WAV/M4A-файлов, подключённых как локальные медиа курса; в проверенных компонентах Cinema и Lecture Library нет HTML `<video>` / `<audio>` плееров.
- 2026-10-15 подключение Runway проверено. Недавний список галереи содержит точные совпадения для 28 из 31 ID: 18 видео, 7 аудио и 3 изображения.
- Три ID не найдены в ответе recent-assets: `a0d3d701-8893-40a5-a064-71c934e73a8d`, `db58afba-0d6d-4ca4-946d-90eb1a7791da`, `b85171e3-8d86-47de-b65a-7f955a25dd9a`. Это не доказывает удаление. В галерее есть похожие по названию аудиоматериалы с другими ID — замена допустима только после проверки.
- Подтверждённые аудио в основном являются вступлениями, тизером и музыкальными подложками, а не полной озвучкой каждой лекции. Найденные видеофайлы по именам и brief'ам — кинематографические сцены/вставки; полноценные объясняющие видеолекции пока не подтверждены.
- Доступные ссылки Runway подписаны и временные. Их нельзя записывать как постоянные URL.
- Прогресс сохраняется локально в браузере в обеих версиях; ключи хранения различаются. Это не аккаунт и не синхронизация между устройствами.
- В проверенных package.json и маршрутах нет подтверждённой интеграции Stripe/checkout; Supabase фигурирует в `.env.example` как пустой placeholder, но клиент/серверная интеграция и API-маршруты не найдены.
- Навыки и чек-листы не являются официальными сертификатами.
- Последний опубликованный commit для OSGARD frontend: `c10b9d0bc4cb05c0a63560fad3ccbf6dd0de8d2b`; workflow развёртывания завершился успешно. Отдельный старый route-matrix прогон упал на проверке ассетов ESSENTIA, хотя OSA routes в том прогоне отвечали HTTP 200.

## Правила

- Не показывать фиктивный видеоплеер или кнопку прослушивания без рабочего постоянного источника.
- Не считать asset ID ссылкой на сам файл.
- Не записывать временные подписанные Runway URL в исходники.
- Не считать коммит доказательством production deployment.
- Не обещать аккаунты, синхронизацию прогресса, платежи или backend, пока они не реализованы и не проверены.

## План реализации

### P0 — Медиа-основа
1. Найти/разрешить три ID, отсутствующих в recent-assets; выбрать утверждённые мастер-клипы.
2. Экспортировать файлы и загрузить в постоянное HTTPS-хранилище с поддержкой byte-range.
3. Расширить манифест метаданными: title, locale, duration, media type, chapter, captions/transcript, rights, checksum, publication status.
4. Сделать один переиспользуемый доступный плеер с воспроизведением, перемоткой, скоростью, громкостью, сохранением позиции, состояниями ошибки и fallback.
5. Связать аудио/видеоресурсы с конкретными главами; не считать cinematic B-roll полной лекцией.

### P1 — Единая модель обучения
1. Свести каталог к структуре направление → курс → модуль → урок → практика → проверка → итог.
2. Создать подробную страницу урока и единые метаданные текста/аудио/видео.
3. Сохранить текущий интерактивный OSA как рабочий курс и не дублировать содержимое без необходимости.
4. Сначала оставить прогресс локальным; синхронизацию добавлять после выбора и реализации аутентификации.

### P2 — Аккаунты и монетизация
1. Для первого запуска сохранить бесплатный вводный интерактивный курс.
2. Проверить спрос на один завершённый платный мини-курс с разовой оплатой; подписку отложить до появления регулярного контента.
3. До реализации определить юрисдикцию продавца/провайдера и доступный backend.
4. Реализовать серверные заказы, подписанные вебхуки, идемпотентность, журнал платежей и права доступа на сервере. Live-оплату не включать до тестового режима и проверки безопасности.

### P3 — Надёжность и выпуск

- Сборка/типизация, контракты курсов и медиа, мобильное воспроизведение, клавиатура/доступность, маршруты, сетевые ошибки, privacy, backup и процедура отката.
- Любой релиз подтверждать командой, результатом проверки, URL и SHA коммита.

## Релизный статус

**Текущий статус:** интерактивный курс опубликован; медиа обнаружены в Runway частично по exact ID, но постоянного размещения и плеера нет. **OSA 2.1.0 не считать выпущенным** до фактической интеграции, прохождения QA и проверки production playback.
