# OSA CINEMA V43 — мобильный навигатор OBSIDIAN ARCHIVE

Инженерный выпуск 26 октября 2026 г. Поверх утверждённой V42.2 с восемью сценами.

Реализовано: селектор текущей сцены и предыдущая/следующая на экранах до 760 px; RU/EN; клавиатурная доступность; сброс completed при переключении; синхронизация ссылок и прогресса через уже существующий код OSA CINEMA. На десктопе дополнительный навигатор скрыт, существующий художественный интерфейс не меняется.

Проверки: Node-контракт читает настоящий src/OSACinema.tsx и исключает подмену медиакаталога; Playwright проверяет реальный React на 390 и 1536 px и восемь сцен; GitHub CI на Ubuntu/macOS/Windows + запрет выпуска. Коммерческие фильмы, подписки и доступ по приглашению не добавляются.

Критерии слияния: npm run check, все V43 CI, общие браузерные проверки и имеющиеся V13–V15 сценарии должны пройти; не объединять по одним статическим тестам.

Политика: V16/V18/V20 неизменны. Публикация фильма, права и платёжные функции остаются NO-GO, независимо от успешности интерфейса.

Исходный URL после одобренного слияния: /osa-cinema. Используется настоящая история OSA ORIGINAL, не фиктивная премьера.
