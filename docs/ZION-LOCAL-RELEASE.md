# PLAY: локальная публикация ZION-9 и проверка существующих игр

Дата аудита: 16 октября 2026 года. Этот документ описывает реализованный код и границы проверки. Публикация подтверждается отдельно результатом deploy workflow и проверкой живых маршрутов.

## Что изменено

Во время аудита живой `/games/` уже содержал **19 уникальных проектов**, включая все 11 ссылок на GitHub Pages ZION-9. В React-каталоге `/play` было только 6 проектов. Поэтому новые записи не добавлялись поверх существующих: оба каталога приведены к одним 19 идентификаторам, а 11 внешних запусков ZION заменены локальными.

Источник ZION: [`osmanosmanov6880-bot/zion-9-worlds`](https://github.com/osmanosmanov6880-bot/zion-9-worlds), commit `4665abe0cf2dab2486b0b5f39e9b700d1770eac9`. Исходный OSGARD: commit `2eb21985ae95117fe31e0c5e3ee2bd573374e039`. Снимок исходных каталогов до изменений: локальный commit `0b3fab0`.

В источнике найдены ровно 11 игровых входов `public/queue/ZION-020…030/index.html`. Миров 001–019 в этом дереве нет. `episodes/ZION-030.html` и JSON рядом с ним — материалы миссии, а не двенадцатая игра.

Весь `zion-9-worlds/public` перенесён в `public/games/zion-9/` с сохранением относительных путей. Сохранены каталог архива, панель передач, досье, исходные механики и собственная графика миров. Добавлены общие инструкции, метаданные, 11 самостоятельных SVG-обложек и реестр происхождения `worlds.json`. В реестре `sourceSha256` относится к исходному HTML до интеграционных правок. Всего импортированный раздел с дополнениями занимает около 0,94 МБ без сжатия; это размер файлов, а не измерение скорости загрузки.

## Запуск и зависимости

Русский язык выбран по умолчанию. Сохранённый выбор английского учитывается; `?lang=ru` и `?lang=en` позволяют явно задать язык. Переключение обновляет текст и подписи доступности, не переводит содержимое скриптов и не оставляет результат устаревшего переключения после быстрых повторных нажатий.

020–029 используют обычные HTML/CSS/JavaScript. 030 загружает локальный `../../libs/three.min.js`; лицензия лежит рядом. Удалена запасная загрузка Three.js из CDN. На страницах каталогов библиотека Three.js не загружается. Ссылки на исследовательские материалы и публичные источники в досье сохранены как обычные внешние ссылки; они не являются зависимостями запуска.

В 030 при невозможности создать WebGL-контекст появляется эквивалентное поле Canvas 2D: те же 15×15 клеток, здания, три горячие точки, занятость, лимит размещений и условия победы/поражения. Состояние рендера опубликовано атрибутом `#scene[data-renderer]`. AR доступен только при поддержке WebXR; в облегчённом режиме кнопка недоступна с объяснением. Это учебная головоломка с условными очками, а не вычислительная модель реального города.

Для 030 добавлены фокусируемое поле, координаты выбранной клетки, экранные стрелки, клавиатурное размещение и заметный фокус. Системное уменьшение движения отключает раскачивание камеры и пульсацию, а не только CSS-переходы. В скрытой вкладке рендер не выполняется.

## Исправленные ошибки

- **020/021:** устранена гонка таймера ошибочного выбора с ручным сбросом; отложенный сброс больше не разрушает следующую попытку.
- **`/games/`:** функции `$`/`$$` теперь учитывают переданный корневой элемент. Ранее изменение подписи согласия на аналитику попадало в первую жирную надпись страницы и превращало контактную кнопку в «Связаться Разрешить».
- **Каталоги:** проверяют форму необязательных данных из хранилища, используют общий ключ `osgard:play-collection:v1`, мигрируют прежние избранное/недавние и не блокируют запуск при недоступном хранилище. Миграция не создаёт аккаунт или синхронизацию между устройствами.
- **NULL//SHIFT:** реальная серверная Godot-сборка снова доступна из `/play`; HTML-версия оставлена отдельным запасным запуском. Godot не приписан архиву ZION.
- **VECTOR//ZERO:** исправлена инструкция: W/↑ — прыжок, Space — запуск ядра, Q — полярность, E — импульс.
- **INHERIT:** исправлен ранний конец HTML-документа, после которого JavaScript отображался обычным текстом и не выполнял инициализацию снимков. API мира переведён с безусловного URL `127.0.0.1` на `/api/world/quiet-reach`. Существующее локальное продолжение поколения при недоступном сервисе сохранено. Версия service worker повышена до `inherit-shell-v3`, чтобы новый HTML вытеснил прежний кеш. Отдельная аналитика для разработчика по-прежнему ограждена проверкой локального hostname и не вызывается на production-домене.

## Автоматические проверки

`node scripts/zion-local-smoke.mjs` проверяет:

- 19 уникальных записей и ровно 11 локальных миров; правильную классификацию 2 + 8 + 1;
- существование локальных зависимостей и обложек, возврат в каталог, метаданные, инструкции и сохранение;
- отсутствие CDN у 030 и компиляцию всех игровых inline-скриптов;
- фактическую игровую логику 020/021 с ошибкой, сбросом, таймером и победой;
- фактические клавиатурные события 030, размещение, занятую клетку, победу, исчерпание бюджета и восстановление после сброса;
- отсутствие исполняемого текста вне скриптов INHERIT, целостность документа и same-origin API мира.

Игровая логика исполняется в небольшом DOM/Canvas-окружении Node. Это целевая проверка состояний; она **не заменяет** настоящий браузер и не доказывает производительность WebGL.

С `ZION_BASE_URL=https://osgard.world` тот же скрипт дополнительно проверяет HTTP 200 и отличает каждый из 11 импортированных миров от ошибочной SPA-заглушки. Отдельный `scripts/games-portal-smoke.mjs` прошёл существующие контракты портала. Browser CI должен проверять desktop/mobile, раскладки, фокус и реальные загрузки после сборки.

### Стабильный сценарий 030 для browser CI

Открыть `.../ZION-030/index.html?lang=ru`, дождаться `#scene[data-renderer]`. При проверке fallback можно запретить только контексты WebGL в настройке тестового браузера, сохранив Canvas 2D. Затем сфокусировать `#scene`:

1. ArrowLeft × 4, ArrowUp × 3, Enter — размещение у (−4, −3).
2. ArrowRight × 6, ArrowDown × 5, Enter — размещение у (2, 2).
3. ArrowRight × 2, ArrowUp × 4, Enter — размещение у (4, −2), победа.
4. R — 0 размещений, возможность снова использовать клетку.

Проверяемые элементы: `#cursor-coordinate`, `#placedPill`, `#score`, `#statusTitle`, `#reset`. Экранный эквивалент: `[data-cursor="left|right|up|down"]` и `#place-keyboard`. Проверочный интерфейс `?test=1` остаётся опциональным; доступность игры не зависит от него.

## Условия публикации

Godot Web export находится на сервере и отсутствует в исходном Git-дереве. При статическом выпуске необходимо сохранить существующий шаг **Preserve Godot Web export for static-only releases** в workflow: он переносит полную рабочую сборку из active/previous. Одна карточка в каталоге не заменяет файлы `.pck`/`.wasm` и лаунчер.

Сетевые комнаты SWARM, общая история INHERIT и подтверждённые результаты REMIX нельзя объявлять рабочими только на основании загрузки клиента. Карточки содержат соответствующие оговорки. В этом выпуске сетевые сервисы этих игр не добавлялись и их работоспособность не заявляется.

После выкладки обязательна проверка `/play`, `/games/`, 11 новых локальных входов, целостности Godot и исправленного INHERIT. Зафиксировать отдельно фактический release SHA и результат browser CI. Пока этих данных нет, этот документ подтверждает подготовленное изменение и выполненные проверки исходников, а не успешную публикацию.
