# OSGARD — проход по надёжности интерфейса

## Исправлено

1. PLAY сохраняет поиск, жанр, способ игры и выбранную коллекцию в URL. Страницы игровых миров получают безопасный обратный адрес, поэтому возврат сохраняет выбор каталога. Произвольные внешние ссылки и протоколы в параметре возврата отклоняются.
2. Внутренние React-страницы получили хлебные крошки. Верхняя навигация различает текущую страницу (`aria-current=page`) и родительский продукт (`aria-current=location`).
3. Кнопка движения объясняет системную настройку reduced motion. Отключённые системой эффекты не представлены как активные.
4. Ошибка брифа связывается с полем через aria-describedby/aria-invalid; при прикладной проверке фокус возвращается к описанию. Пробелы не считаются содержательным описанием. Ошибка очищается после правки.
5. При уходе с не сохранённым в файл брифом браузер может показать стандартное предупреждение о потере несохранённого текста. Автоматическое сохранение контакта на устройстве не добавлено.
6. Журнал действий допускает только пять известных событий и ограниченный технический slug. Экспорт удаляет неизвестные поля; произвольные события и адреса электронной почты не попадают в журнал.
7. Ошибка удаления или чтения журнала показывается явно. Интерфейс не сообщает об успешном удалении после отказа хранилища. Подготовка файла журнала также имеет состояние ошибки.

## Проверено автоматически

- `npm run qa:ux`: параметры каталога, нормализация обратного адреса, запрет внешнего редиректа, навигационные состояния, бриф, лимит 200 событий, удаление лишних полей, повреждённый журнал, отказ чтения/записи/удаления.
- `npm run qa:redesign`: сохранение коллекции и серверный рендер шести страниц, главных заголовков, элементов управления и честных состояний запуска.
- `npm run qa:backup`: валидация резервных копий, конфликты и ошибки восстановления.
- TypeScript, production build, аудит зависимостей, восемь основных пар контраста и HTTP-проверки 14 маршрутов и пяти ответов 404.
- Статический пакет проверяется отдельно: 77 адресов sitemap имеют файлы сборки, размер каждого файла соответствует настроенному потолку, контрольные суммы проходят проверку.

Это проверки кода, данных и доставки файлов. Они не заменяют проверку реального фокуса, скринридера, видимой раскладки и поведения устройства.

## Оставшаяся ручная приёмка

- Desktop и мобильные размеры: 360, 390, 768, 1280 и 1440 px; масштабирование 200%.
- Tab / Shift+Tab / Enter / Space: шапка, skip link, фильтры, карточки, поле брифа, импорт и восстановление данных.
- Ошибочный бриф: поле объявляется ошибочным, сообщение доступно скринридеру, фокус виден.
- Системное reduced motion и ручное отключение анимации.
- Возврат из карточки с несколькими активными фильтрами; Back/Forward браузера.
- Переполнение и запрет localStorage на настоящем браузере.
- Запуск игровых клиентов, доступность серверов и реальные сохранения внутри игр.
- Полевые Core Web Vitals и проверка на медленном мобильном соединении.

Браузерная автоматизация в текущей среде недоступна; эти пункты не отмечены выполненными. Публикация и GitHub не изменены.
