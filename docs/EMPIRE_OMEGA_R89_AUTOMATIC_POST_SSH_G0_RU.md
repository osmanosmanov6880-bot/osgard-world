# EMPIRE Omega R89 — automatic independent Web G0 after successful Godot SSH

Дата: 25 октября 2026. Только выпускной CI/QA, без изменения Godot runtime, WASM/PCK, SSH ключей или коммерческого статуса.

## Пробел, который устраняет R89

До R89 workflow R84 запускал настоящую опубликованную WebGL проверку при изменениях его кода на master и вручную. Сам успешный SSH выпуск Godot не запускал независимый R84 автоматически. Поэтому очередную игру можно было технически опубликовать, не повторив объединённый R83 выпускной контроль.

## Реализованное условие запуска

R84 слушает workflow_run строго завершившегося официального workflow "OSGARD Omega verified Godot direct SSH deploy". Проверка реальной игры разрешена только при одновременном выполнении:

1. Исходный SSH workflow имеет conclusion = success, не failure, cancelled или skipped.
2. Запущен из master и из того же исходного GitHub репозитория.
3. По исходному release.json повторно сверены семь локальных Godot 4.4.1 файлов, исходный коммит и семь публичных HTTP SHA-256.
4. Настоящий desktop/touch Chromium проверяет Godot WebGL, не принимает заставку, запрещает повторные flaky-попытки.
5. R83 получает оригинальные R50 HTTP + Playwright JSON, подтверждает технический Web Tech Preview и оставляет status HOLD для всех пяти внешних ворот.

При изменении игры между SSH и R84 source freshness и HTTP SHA откажут. Зелёная надпись GitHub не заменяет реальные файлы и пиксели.

## Безопасность

- R84 имеет только permissions: contents read, без секретов SSH, SCP, релизных токенов или денежных операций.
- Pull request продолжает выполнять только негативные контрактные тесты; PR-ветки не аттестуют публичный сервер.
- Ручной запуск на master остаётся допустим для независимого осмотра.
- Никакой автоматический результат не выставляет production_go true или aaa_quality_certified true.
