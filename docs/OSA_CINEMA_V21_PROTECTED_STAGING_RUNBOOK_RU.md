# OSA CINEMA V21 — защищённая приватная видеоприёмка

## Что реализовано

**Рабочая локальная программа, не публичный сайт.** Сервер читает настоящий выбранный MP4 из закрытого каталога владельца, проверяет его размер, SHA-256, FFprobe-метаданные по неизменённому реестру V16 и не запускается при несовпадении. Слушает **только** `127.0.0.1`; пароль передаётся через переменную окружения, не CLI/URL. После входа браузер получает HttpOnly/SameSite=Strict cookie; у cookie есть срок действия, доступ можно закрыть. Все исходники остаются на диске владельца.

После входа доступны: плеер 16:9 с нативными кнопками на телефоне, переход по кандидатам точек склейки V18, загрузка отдельного локального черновика WebVTT в браузер, частные замечания по времени с экспортом JSON. Сервер не принимает загрузку MP4/VTT и не отправляет их во внешние сервисы. Страница закрыта CSP, запрещены внешние скрипты и соединения.

**Реальный HTTP Range:** `GET` и `HEAD /media`, `206 Partial Content`, `416 Range Not Satisfiable`, `Accept-Ranges: bytes`, `Content-Type: video/mp4`, отказ неавторизованным запросам. Тест использует синтетический видеофайл и проверяет точное число байтов, cookie, отсутствие доступа после выхода и запрет некорректных запросов.

## Запуск на компьютере владельца

```bash
# Пароль задаётся безопасно через переменную окружения, не сохраняется в репозитории
export OSA_CINEMA_PRIVATE_PASSWORD='ЗАМЕНИТЬ_НА_УНИКАЛЬНЫЙ_СЕКРЕТ_ОТ_16_СИМВОЛОВ'
node scripts/osa-cinema-v21-private-review-server.mjs --private-source-dir /safe/private/osa-v16 --source-id osa-v15-directors-ru --port 8765
```

Открыть `http://127.0.0.1:8765/` **на том же компьютере**, который запускает сервер, войти через пароль, сравнить звук/склейки, сохранить заметки. Режим не предназначен для удалённого просмотра, Wi-Fi/LAN-публикации, интернет-доставки, загрузки на GitHub, оплаты или открытого CDN. Для работы с другого устройства понадобится отдельно спроектированное защищённое staging-решение с TLS и контролем доступа; V21 его не включает.

## Что ещё закрыть для настоящего выпуска

1. Непосредственно прослушать RU и EN дорожки и официально утвердить транскрипты.
2. Проверить права на все источники, музыку, голоса, изображения и синтетические элементы с независимым юристом.
3. Сделать финальный мастер, финальные WebVTT и подтверждённые титры.
4. Развернуть публичное/закрытое production-хранилище по утверждённым правилам с CDN/TLS/кешированием и независимой проверкой Range/MIME.
5. Провести реальную ручную приёмку на iOS Safari, Android Chrome и настольных браузерах, исправить ошибки воспроизведения и доступности.
6. Получить отдельное разрешение издателя на релиз. `publicationAuthorized` в этом проекте остаётся `false`.

Интерактивная публичная V15 OSA CINEMA не меняется; в V21 нет ни права на публикацию, ни автоматической активации платных функций.
