# OSGARD R135 W26 — полностью локальная аналитика с согласия игрока

## Реализовано в настоящем Godot

Новая логика `R135PrivacyMetrics.gd` считает **только шесть общих
типов игровых событий**, без имён, идентификаторов, времени,
геолокации, сети, цифровых отпечатков и отправки данных на сервер:

| Событие | Что является фактом |
|---|---|
| `training_started` | Игрок нажал реальную команду учебной миссии |
| `training_completed` | Сервисная миссия завершилась в движке |
| `diagnosis_started` | Запущена настоящая игровая диагностика |
| `diagnosis_completed` | Пятиэтапная диагностика реально пройдена |
| `safety_blocked` | Виртуальный привод/люк отклонил опасную команду |
| `scan_accepted` | Сканирование действительно продвинуло игровой этап |

Счётчики локальны, ограничены значением 1 миллион, и
сохраняются только в `user://r135_private_learning_metrics_v1.cfg`.
Файл не имеет отношения к сохранениям W14/W19, настройкам W20,
звуку W24 или серверной статистике.

## Privacy by default

- **Первый запуск: аналитика выключена**. Игра ничего не записывает
  в этот файл без явного включения игроком.
- В настоящем меню настроек есть доступная кнопка «АНАЛИТИКА» с
  состояниями включено/выключено, честное раскрытие «только здесь»,
  суммарный счётчик, а также «УДАЛИТЬ ЛОКАЛЬНУЮ СТАТИСТИКУ».
- Отказ от согласия немедленно обнуляет все значения и сохраняет
  запрет сбора. Очистка также возможна без отзыва согласия.
- Нет любого API для загрузки этих событий, аккаунт не требуется.
  Данные не могут быть выданы за реальные продуктовые метрики
  всего мира, retention или «среднюю успеваемость».

## Контроль качества

1. Native Godot 4.4.1 W19–W26: интерфейсные сигналы,
   default OFF, явное включение, допустимые агрегаты,
   реальная блокировка люка, отсутствие двойного зачёта
   за повторную перерисовку UI, очистка/отказ,
   отдельность старых игровых рекордов и перезапуск.
2. Desktop Chromium/Pixel: реальные нажатия на видимую кнопку
   согласия, открытие/прокрутка, учебное действие,
   отклонение опасного открытия люка, opt-out purge;
   оригинальный W26 PNG в каждом профиле (всего 25 кадров
   со всеми предыдущими версиями).
3. Перед публичной активацией нужны успешные QA W24/W26,
   source-pinned независимый релиз, и защищённая живая проверка.
4. Оценка педагогической пользы и retention — **только**
   с реальными людьми W27 при отдельном добровольном согласии.

Состояние не подтверждает физические измерения W25 или
содержательно хороший образовательный результат до W27.
