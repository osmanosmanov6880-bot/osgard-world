# EMPIRE Omega R88 — оригинальные кадры опубликованного Godot в закрытый арт-аудит

Дата: 25.10.2026. **Это подготовка подлинных доказательств, НЕ AAA-сертификация.**

## Что реально доступно

Успешный независимый публичный R84: https://github.com/osmanosmanov6880-bot/osgard-world/actions/runs/40225412839

Архив оригинальных доказательств: https://github.com/osmanosmanov6880-bot/osgard-world/actions/runs/40225412839/artifacts/12610849417

Настоящий JSON репортёр Chromium содержит встроенные PNG original Godot. Два доступных viewport:

1. Desktop Chromium — фактический PNG 960x540, исходный Godot viewport 1366x768 (разрешённый исходной R83 пропорциональный CDP downsample).
2. Emulated touch Chromium — фактический PNG 390x844.

Отсутствуют два остальных необходимых кадра R83: 320x568 и 844x390. Chromium touch не подтверждает физические Android или iPhone. Исходники R84 относятся к release source d192aaab54273580324a5736622c19bb8b53ce54.

## Использование

1. По docs/EMPIRE_OMEGA_R86_PRIVATE_FIELD_KIT_RU.md создать отдельный закрытый source-pinned QA-каталог вне репозитория. Подтвердить опубликованный release.json. На POSIX каталог ограничен правами 0700.
2. Скачать R84 artifact #12610849417. Без изменения байтов поместить omega-r84-evidence/live-integrity.json в PRIVATE_ROOT/web/live-integrity.json, а omega-r84-evidence/playwright.json в PRIVATE_ROOT/web/playwright.json.
3. Из корня репозитория выполнить следующую команду, подставив ваш существующий ПОЛНЫЙ абсолютный путь:

    python3 scripts/omega_r88_original_pixel_intake.py --kit-root /private/empire-omega-qa-20261025

Для Windows использовать абсолютный путь на закрытом локальном диске (например C:/PrivateQA/EmpireOmega). Ни GitHub, ни SSH-ключи для локального разбора не требуются.

R88 ОБЯЗАТЕЛЬНО повторяет оригинальные R83/R50: точно привязанный Godot 4.4.1 source, семь исходных файлов с оригинальными SHA-256, семь опубликованных HTTP SHA-256 из неизменённого R84, оба подлинных нулевой-retry desktop/touch WebGL теста. Проверяет форму/размер оригинального JSON, PNG signature, реальную геометрию, CRC и полные scanline PNG через ранее существующий R73.

Только после успешных проверок создаёт новые файлы внутри PRIVATE_ROOT/art:

- r88-real-desktop.png — подлинный кадр опубликованного desktop Godot;
- r88-real-touch-portrait.png — подлинный кадр мобильной ориентации в эмуляторе Chromium;
- r88-frame-provenance.json — подтверждённые SHA-256 входных репортёров и кадров, source SHA;
- art-review.template.json — только НЕЗАВЕРШЁННЫЙ шаблон штатного R83;
- R88-MISSING-EVIDENCE.md — точное описание недостающих полевых материалов.

Файлы никогда не перезаписываются. Новые сохраняются с приватными правами 0600; если валидация не проходит, удаляются только новые R88 файлы. Оригинальные браузерные репорты остаются нетронутыми.

## Окончательная арт-приёмка

Независимый ревьюер должен получить ещё два ОРИГИНАЛЬНЫХ Godot скриншота 320x568 и 844x390, полный реестр лицензионных источников 3D-моделей, материалов, звуков и шрифтов и просмотреть реальную игровую сцену. Только после своей ручной проверки он заполняет art-review.json согласно docs/EMPIRE_OMEGA_R83_FINAL_ACCEPTANCE_RU.md. Нельзя копировать шаблон и объявлять художественное качество проверенным.

R88 всегда сообщает статус PARTIAL_ORIGINAL_ART_EVIDENCE_ONLY и production_go=false. Реальные 40 миссий, Android, iPhone, 20 игроков и независимый финальный GO остаются отдельными воротами.

**Если новая версия R87 будет действительно опубликована, старые кадры R84 относятся только к прежнему source SHA. Нельзя переносить их для новой версии.**
