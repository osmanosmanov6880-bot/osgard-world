## Реально опубликовано

Технически игра — полный Web экспорт **исходной игровой сцены** `res://scenes/main.tscn` из `godot/empire-omega`: `index.html`, `index.js`, `index.wasm`, `index.pck`, сопутствующие ресурсы. Снимки экрана и рекламные картинки не заменяют рантайм. Публичный `release.json` хранит точный Git SHA, SHA256 каждого файла и статус `native_tests=passed`.

Предварительная проверка кандидата: **47/47 зеленых GitHub checks**. Во время отдельного SSH релиза заново выполнены строгий импорт Godot 4.4.1, экономическая транзакция городского проекта, физическое строительство, движение NPC, F-осмотр, сохранения, родственные тесты. Финальная HTTPS SHA256-сверка доказала подлинность каждого публичного файла, а Chromium на 1366×768 и 390×844 проверил настоящий WebGL2-кадр, не сплэш/HTML-заглушку. До и после релиза исходная R87 была проверена отдельно.

## Публикация без риска для соседних проектов

1. Изолированный адрес: `/games/city-reign-preview/`, отдельный от `/games/omega-3d-preview/`.
2. Исходники релиза пинятся точным SHA, операция запрещает 9 отсутствующих/неуспешных обязательных проверок и любые изменения исходной ветки.
3. GitHub Secrets `OSGARD_DEPLOY_HOST`, `OSGARD_DEPLOY_USER`, `OSGARD_DEPLOY_KEY` используются только внутри SSH CI. Никогда не печатать ключи в лог.
4. До SCP — проверка свободного места VPS; никаких `docker system prune` или удаления данных.
5. Общий лок `/run/lock/osgard-frontend-activation.lock`, отдельная staging папка в `/tmp`, верификация tar и SHA256, атомарное `mv` строго только в изолированный игровой маршрут.
6. Проверки после активации: публичный HTTPS байтов, неизменность R87, реальные кадры Chromium. При неудаче выполняется **изолированный rollback** маршрута Preview.
7. Основной фронтенд OSgard использует `scripts/preserve-omega-native.sh` для **обоих независимо проверенных** путей. Полный сайтообновляющий деплой сначала SHA256-копирует текущий Preview в кандидатную html-структуру, после root swap повторно сверяет SHA256. Это защищает игру от исчезновения при обновлениях другого сайта.

- Референс **The Matrix Awakens × GTA VI × Forza Horizon 5** остаётся производственной целью, не достигнутым визуальным качеством. Наиболее очевидны недоработки оригинальных моделей города/машин, лицевой анимации, PBR-материалов и кинематографического света.
- Тесты Mesa/SwiftShader — **не** показатели реальных GPU на ПК, Android/iPhone. Не заявлять 60 FPS на телефонах.
- Не выдавать CI за три независимых 15–20-минутных человеческих прохождения, 40 отдельных миссий людьми или пользовательскую художественную подпись.
- PR #500 и #627 остаются **DRAFT**, не вливаются в мастер: публичный Preview запускается на собственном URL без изменения действующей R87 и без снятия R138 production hold.
- Нельзя заявлять, что будущие релизы игры автоматически безопасны: новый Git SHA должен заново пройти все обязательные тесты; нельзя тихо менять пин source commit.

## Приёмка после любых обновлений фронтенда

Проверять три адреса: `/`, `/games/`, `/games/city-reign-preview/`. Запускать источник-проверку опубликованной версии по `scripts/omega-live-integrity.py` с ожидаемым сохранённым манифестом кандидата, затем реальный браузерный `scripts/city-reign-preview-live-check.mjs`. Дополнительно убеждаться, что `/games/omega-3d-preview/release.json` и все семь исходных R87 SHA не менялись. Любое расхождение — инцидент, а не автоматически одобренный релиз.
