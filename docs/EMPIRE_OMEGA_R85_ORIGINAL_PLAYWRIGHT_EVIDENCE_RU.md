# EMPIRE Ω R85 — исправление обработки оригинального Playwright JSON

**Дата:** 25 октября 2026. **Цель:** закрыть реальный сбой R84, не заменяя первичные доказательства поддельным сокращённым отчётом.

## Наблюдаемый дефект

Независимый R84 [run #40224816664](https://github.com/osmanosmanov6880-bot/osgard-world/actions/runs/40224816664) сделал всё важное до R83:

- Источник опубликованной игры точно d192aaab54273580324a5736622c19bb8b53ce54.
- Оригинальные локальные WASM/PCK и 7/7 HTTP SHA-256 — PASS.
- Настоящий Playwright desktop + touch — 2 успешно, 0 сбоев, 0 повторов.
- Однако исходный Playwright JSON содержит ~3,8 МБ оригинальных материалов и вложенных отчётов.
- R83 применял общий 1-МиБ лимит из приватных полевых JSON и возвращал HOLD, включая неверный вывод, что техническая Web-сборка не доказана.

Исходное доказательство R84 из [GitHub artifact #12610602876](https://github.com/osmanosmanov6880-bot/osgard-world/actions/runs/40224816664/artifacts/12610602876). Дефект не связан с Game Engine или опубликованным WebGL.

## Исправление

R85 добавляет отдельный загрузчик только для оригинального отчёта браузера:

- Максимум 16 МиБ, никаких символических ссылок; проверяется форма JSON (stats и suites).
- Не меняется общий **1 МиБ** для приватных материалов пользователя, телефона, видеосессий и художественных отчётов.
- Не меняются R50.validate_browser, проверка двух проектов, запрет flaky-повторов, HTTP SHA, source_commit или реальная сцена Godot.
- 5 дополнительных негативных/положительных регрессионных случаев проверяют настоящий объём отчёта, поддельные проекты, симлинк, отсутствие suites и прежний лимит приватных форм.
- R84 автоматически запускает новый реальный публичный G0-аудит после изменения исходного R83 на master, не требует повторного SSH.

## Строгое решение

Успешный последующий R84 обязан вернуть technical_web_ready=true и при этом status=HOLD с **пятью** незакрытыми внешними условиями: 40 миссий живого игрока, Android, iPhone, 20 пользовательских сессий, арт и лицензии.

Никакие результаты R85 не аттестуют реальную модель телефона, личность игроков, художественный AAA-уровень или полный Production GO.
