# OSA CINEMA V22 — локальные RU/EN-кандидаты, аудиопотоки без перекодирования и независимая проверка

Дата подготовки: 25 октября 2026. Статус: **приватная техническая сборка; публикация записанного фильма запрещена до отдельного утверждения**.

## Что реально изменено

- Новый скрипт `scripts/osa-cinema-v22-private-language-export.mjs` работает с настоящим V18 четырёхдорожечным MP4 (239,018 с, 1080p H.264, четыре AAC). Он сначала проверяет SHA-256, размер, длительность, пять потоков, кодеки и идентичность видеопотока и обеих исходных дорожек V18.
- Отдельно создаются **две приватные MP4-версии** RU/EN для сравнения: режим `original` использует звуковые дорожки 0 и 1, режим `draft` — дорожки 2 и 3. Видео и выбранный AAC копируются **без перекодирования**.
- Для каждого экспорта скрипт проверяет длительность, полный декодинг, SHA-256 файла, видеопоток и именно выбранный аудиопоток. FFmpeg измеряет LUFS и true peak. Техническая громкость не означает утверждённую озвучку.
- Атомарный приватный пакет содержит два MP4 и `private-v22-qa.json`; перезапись существующего пакета запрещена. Проверка `verify` пересчитывает все контрольные суммы и обязательно сравнивает каждую языковую дорожку с оригинальным четырехдорожечным источником.
- Скрипт не записывает исходники в репозиторий, не обращается к сети, не публикует адреса, не меняет публичный медиакаталог, checkout или `chatgpt.site`.

## Порядок для владельца настоящих файлов

Предполагается, что приватный оригинал действительно называется `OSA_CINEMA_V18_PRIVATE_FOUR_TRACK_EDITORIAL_239S.mp4` и SHA-256 совпадает с неизменным V18 QA. Рабочие исходники хранятся вне публичной папки сайта.

```bash
mkdir -p "$HOME/osa-private/output"
node scripts/osa-cinema-v22-private-language-export.mjs --mode check --private-source-dir "$HOME/osa-private/source" --private-output-dir "$HOME/osa-private/output"
node scripts/osa-cinema-v22-private-language-export.mjs --mode render --edition original --private-source-dir "$HOME/osa-private/source" --private-output-dir "$HOME/osa-private/output"
node scripts/osa-cinema-v22-private-language-export.mjs --mode render --edition draft --private-source-dir "$HOME/osa-private/source" --private-output-dir "$HOME/osa-private/output"
node scripts/osa-cinema-v22-private-language-export.mjs --mode verify --edition draft --private-source-dir "$HOME/osa-private/source" --private-output-dir "$HOME/osa-private/output"
node scripts/osa-cinema-v22-private-language-export.mjs --mode verify --edition original --private-source-dir "$HOME/osa-private/source" --private-output-dir "$HOME/osa-private/output"
```

Итоговые каталоги: `output/osa-v22-original/` и `output/osa-v22-draft/`. Это **не** финальные лицензированные видео и не файлы для публичного сайта. Путь `--baseline` предназначен для тестов с синтетическими записями; для реального проекта используйте неизменный реестр `docs/OSA_CINEMA_V18_PRIVATE_FOUR_TRACK_QA.json`.

## Что проверяет CI

GitHub Actions не содержит ни оригинальных MP4, ни синтезированных пользовательских голосов. Система генерирует маленький искусственный видеофайл с четырьмя AAC-дорожками, реально делает четыре отдельных MP4-экспорта (по два в каждом режиме), сравнивает пакеты видеоданных и звука, пересчитывает SHA, тестирует защиту от подмен, попыток публикации, символических ссылок, неправильного порядка дорожек и перезаписи исходного пакета. Параллельно проверяется официально зафиксированная SHA V18.

## Следующие крупные блоки и критерии

1. **V23 — художественная и лингвистическая приёмка.** Два редактора/носителя языка прослушивают речь по трем актам и сверяют текст с видеорядом; специалист по звуку утверждает LUFS/TP в контексте выбранных платформ. Машинная проверка не может расписаться вместо них.
2. **V24 — правовая матрица.** Для каждого исходника, изображения, музыки, модели голоса и согласия человека должен существовать документ на коммерческое распространение именно данной версии фильма. Частная инженерная сборка не создает лицензий.
3. **V25 — финальные субтитры и доступность.** Настоящие RU/EN WebVTT синхронизируются с прослушанной финальной речью; проводится проверка на экране телефона и ПК. Только после этого фиксируются финальные SHA master/preview/captions.
4. **V26 — защищённое production-хранилище.** Постоянные HTTPS-адреса, корректные MIME и Range, ограничения доступа, fallback и восстановление, браузерные Chrome/Safari/Android-проверки на реальных версиях фильма; не считать локальный V21 сервер публичным CDN.
5. **V27 — решение о публикации.** Независимая проверка прав, языков, монтажа, финальных мастеров, субтитров, тестов и письменное решение правообладателя/издателя. Только после всех отметок разрешена отдельная публикационная операция и возможный запуск платной модели.

**Вывод:** V22 предоставляет проверяемые двухдорожечные технические заготовки и способы их воспроизведения, но `publicationAuthorized = false`, `rightsCleared = false`, `spokenLanguageVerified = false`. Автоматическое снятие этих блокировок запрещено.
