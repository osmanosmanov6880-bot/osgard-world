# OSA paid practice — независимая проверка доступа

Дата: 2026-10-16. Область: платная программа OSA, её личная практика и экспорт собственных работ.

**Результат независимого прогона: 4 проверки, 4 passed, 0 failures, 0 errors.** Перед прогоном выполнен read-only review `server/core_programs.py`, `server/core_commerce.py` и соответствующих маршрутов `server/core_server.py`. Подтверждённых блокеров в указанной области не найдено.

## Что проверено

1. **Повтор операций после отключения Learning.** Ранее успешные `activity`, `save_work` и `submit` сначала действительно возвращают `replayed: true`. После отзыва согласия прежние и новые ключи получают `403 learning_consent_required`. Собственные работы остаются доступны для экспорта.
2. **Повтор операций после полного подтверждённого возврата.** Те же три вида запросов с прежними и новыми ключами получают `403 payment_required`. Обычное чтение больше не выдаёт curriculum и платную практику; экспорт собственных работ полностью совпадает с экспортом до возврата.
3. **Изоляция платной работы от редактора общего проекта.** Редактор получает обычный экспорт проекта с HTTP 200, но без `programWork` и приватного текста платных заданий. Прямое чтение, экспорт и изменение платной программы возвращают 404. Покупатель продолжает получать собственные работы.
4. **Разделение бесплатного и платного прогресса.** Восемь бесплатных практик дают восемь завершённых бесплатных уроков, оставляя платный прогресс нулевым и его версию неизменной. Платная сдача возвращает `409 not_ready`. Одна отдельная платная практика меняет только платный прогресс.

## Источник и воспроизведение

Тип доказательства: **исполняемые локальные интеграционные проверки HTTP/SQLite**, дополненные чтением исходного кода. Прогон выполнен временным независимым harness; проверенная логика сохранена в `scripts/core-program-access-smoke.py` без изменения сценариев. При переносе изменён только способ определения корня репозитория и добавлен shebang; синтаксис проверен.

```sh
python scripts/core-program-access-smoke.py
```

Скрипт повторно использует fixture из `scripts/core-program-commerce-smoke.py` и запускает только четыре перечисленные проверки. Сервер слушает временный порт на `127.0.0.1`, база и аккаунты создаются во временном каталоге и удаляются после завершения. Все платёжные события синтетические; используется внедрённый `FakeProvider`, а создание `StripeProvider` дополнительно запрещено тестовым mock.

Каждый прогон выводит результат и SHA-256 четырёх проверяемых исходников, сравнивает хеши до и после и завершает процесс с ненулевым кодом при провале проверки или изменении этих файлов во время прогона.

Эта проверка не подтверждает реальный Checkout, реальные возвраты, выручку, качество учебной работы или независимую оценку навыка. Реальные аккаунты покупателей, платёжные реквизиты и сеть Stripe не использовались. UI и более широкая безопасность сервера в область этих четырёх регрессий не входят.
