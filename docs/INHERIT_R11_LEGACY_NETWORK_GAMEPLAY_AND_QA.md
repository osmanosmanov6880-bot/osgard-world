# INHERIT R11 — «Сеть наследия» и реальный мостик между следами

**Версия:** R11 · 21 октября 2026  
**Включено:** движок совместимых пар, карта острова, кратчайшие цепочки, одношаговый план соединения двух разобщённых групп, RU/EN/简体中文, мобильный режим и реальная интеграция с инспектором следов R9.  
**Зависимости:** существующие игровые объекты и \`InheritLegacyEngine.rules\` — шесть действующих правил R2/R10.

## Игровая проблема и решение

INHERIT уже позволяет оставлять следы, читать историю отдельных предметов, сравнивать поколения и получать совет о следующем ходе. Но игроку трудно увидеть **общую структуру** созданного мира: как далеко друг от друга реальные сочетания и как превратить несколько разрозненных уголков в одну связанную сеть.

«Сеть наследия» работает только по фактически находящимся на острове предметам. Игрок выбирает любой существующий след как старт и другой как цель. Движок перебирает **дополняющие пары**, удовлетворяющие настоящим ограничениям расстояния. Если есть связанная цепочка, показывается кратчайший маршрут **по совместимости**, а не утверждение о физическом перемещении персонажа.

Если следы разобщены, движок ищет, можно ли одним новым размещением одновременно дополнить предмет из первой и второй группы. Для варианта, который действительно удовлетворяет обоим правилам, показывается **один** инструмент и координата. Игрок нажимает кнопку выбора инструмента и отдельно нажимает остров, после чего существующий игровой движок самостоятельно проверяет ход, бюджет и права.

**Никакого автоматического размещения, покупок, телеметрии или дополнительной записи в сохранение.**

## Архитектура

- \`legacy-network-core.js\`: чистая функция \`analyze(world,legacy)\`, строгая валидация десяти типов и координат, применение точных радиусов шести правил, компоненты графа, детерминированный BFS, \`route(graph,start,end)\`, \`suggestBridge(graph,start,end)\`.
- \`legacy-network.js\`: настоящий \`<dialog>\`, выбор двух сохранённых объектов, масштабируемая SVG-сеть, численность связей и групп, выделение кратчайшей цепочки, условная подсказка по соединению, переключение трёх языков и доступ с клавиатуры.
- \`legacy-network.css\`: контрастный глубоко-синий интерфейс, золотая подсветка настоящей цепочки, красные акценты для отдельной группы, адаптивная мобильная сетка, уменьшение движения.
- \`trace-inspector.js\`: кнопка **«Просмотреть сеть связей»** из карточки одного реального следа. В сети именно этот предмет автоматически выбирается отправной точкой.
- \`interface.js\`: синхронизация подписи при RU → EN → 中文; \`sw.js\`: offline shell v23 для нового движка, интерфейса и CSS.
- \`scripts/inherit-legacy-network-smoke.mjs\`: инженерные тесты, \`scripts/ecosystem-browser.spec.mjs\`: мобильные и настольные пользовательские сценарии; \`scripts/ecosystem-production-smoke.mjs\`: проверка точного соответствия опубликованных файлов релизу.

## Истина о связях

Шесть существующих правил: дерево + мох (16), тропа + фонарь (17), цветы + колокольчик (15), арка + камень (17), указатель + тропа (15), каменная насыпь + фонарь (14). Радиусы — **условные игровые координаты**, а не реальные метры.

Сеть **показывает все проверенные совместимые пары**. Это может быть больше, чем число открытий в «Наследии»: его движок для каждого первого объекта выбирает ближайший подходящий второй объект. Поэтому R11 принципиально называет связи *совместимыми парами*, а не уже записанными открытиями сервера.

Если один фонарь находится между тропой и насыпью, он может дополнить **оба** объекта, даже когда до его установки две группы были разобщены. Факт успеха определяется только **после** обычного реального размещения; прогноз не считается сохранённым действием.

Движок не утверждает, что кто-то путешествовал между объектами, что маршрут проложен дорожной системой, что сервер зафиксировал отдельное событие, или что известны авторы.

## Строгие ограничения

| Ограничение | Поведение |
|---|---|
| Невалидный тип/координата/поколение/бюджет | Выдаёт недоступное состояние, не подменяет данные |
| Более 600 объектов | Не строит неполную сеть под видом полной |
| Более 12 000 совместимых пар | Останавливается и объясняет ограничение |
| Крупные группы | Поиск моста ограничивается первыми 70 объектами каждой группы, поэтому отсутствие предложения не доказывает математическую невозможность моста |
| Прогноз моста | Точка должна находиться внутри доступного диапазона острова и в радиусе совместимости двух реальных предметов |
| Нулевой бюджет | Просмотр работает; инструмент для нового хода не выбирается |
| Режим просмотра прошлого | Граф показывает текущее сохранение, а подсказка нового действия отключена |
| Аккаунтный режим | Действует штатная авторизация сервера; граф и предложение не обходят права |
| Изменившееся сохранение | Перед выбором инструмента сверяется поколение, бюджет и список объектов; устаревшую подсказку нельзя применить автоматически |
| Переполненный список видимых точек | SVG рисует до 160 объектов и 220 линий; точные статистики считают весь проверенный граф |

Движок не вызывает сервер, не использует хранилище согласия, не изменяет объекты, поколение и бюджет. Работает над копией \`InheritGame.snapshot()\`.

## Как проверить в игре

1. Открыть \`https://osgard.world/games/inherit/\`. На пустом острове «Сеть наследия» честно покажет отсутствие предметов.
2. Поставить **тропу** и отдельно **каменную насыпь** недалеко друг от друга. Пока они не являются совместимой парой — в сети будут две раздельные группы.
3. Выбрать стартом тропу, а целью насыпь. При подходящих координатах должна появиться подсказка поставить **фонарь** между ними.
4. Нажать «Выбрать инструмент и показать точку». Бюджет, массив объектов и поколение **не должны измениться**.
5. Отдельно нажать остров возле золотой отметки. Только теперь происходит настоящий игровой ход и бюджет уменьшается на единицу.
6. Открыть сеть снова. Тропа → фонарь → насыпь становятся проверенной цепочкой длиной две совместимые пары. В «Наследии» действительно должны появиться сочетания с фонарём.
7. Через «Исследовать следы» выбрать любой реальный предмет → «Просмотреть сеть связей»; убедиться, что именно выбранный след является отправной точкой.
8. Проверить английский, китайский, мобильное управление, Escape, нулевой бюджет и отсутствие вставленных фальшивых предметов.

## QA

\`\`\`sh
npm run qa:inherit-network
npm run qa:inherit-compass
npm run qa:inherit-traces
npm run qa:inherit-legacy
npm run qa:inherit-world-cycle
npm run build
\`\`\`

CI включает проверки всех шести реальных правил, кратчайших цепочек, повторяющихся объектов, одношагового моста, подтверждённых Legacy-сочетаний после размещения, пустого острова, нулевого бюджета, невалидных миров, верхних лимитов и отсутствия мутаций. Chromium выполняет реальные переходы между R9 → R11, выбор инструмента и отдельное размещение на десктопе и телефоне.

После принятия PR производство возможно только через \`deploy-frontend.yml\` с проверенным архивом, откатом и побайтовой проверкой трёх ресурсов R11 на сервере.

## Честные границы

R11 не является серверным мультиплеером, картографией реального мира, AAA-рендерером или источником доказанного авторства. Настоящие D1/D7/D30, коммерческий спрос и платёжная конверсия не появляются от добавления ещё одной игровой функции. Они требуют добровольных людей и времени, а не синтетических QA-событий.
