## Main milestone B — actual safe local session persistence

**New original source** `A7SessionCheckpoint.gd`: explicit **F5 / Save Shift** and **F9 / Restore Session** plus actual on-screen native accessible controls.

- Writes **only locally** via `FileAccess` to `user://last_frontier_a7_w73_checkpoint.json`. Does not upload gameplay, capture real equipment or depend on external APIs. Browser storage persistence across different browsers/devices is NOT assumed or certified.
- Saves the bounded journal of at most **160 already-accepted original gameplay and in-world mechanics events** (mission start, 12 original A7 decisions, physical E inspections, valve detents, individual relay switch activations, final ordered sync), including source-derived SHA-256 proof after every real event.
- Saves restored physical player position/aim, locale, quality and reduced motion; validates bounded world coordinates and rejects corrupted or out-of-schema content.
- Stores one checksum over the raw serialized payload. **This catches incidental file corruption only**; SHA-256 without a secret is not cryptographic anti-tamper protection.
- To load, a wholly separate hidden **real native Godot `A7CascadeScreen`** replays every event and compares each resulting original engine state. If any event/step's core/mission/field consequence disagrees, the live session is untouched. Only after preflight passes is the actual UI reconstructed with the original A7 `choose()` method rather than directly setting arbitrary money/health/win values.
- Saves both an intermediate real shift and a genuinely won original six-cycle full field mission. A completed save must restore the exact same original metrics, 12 accepted decisions, phase 5, valve/matrix/sync states and player's physical position. A wrong SHA or forged but rehashed event proof is explicitly rejected before modifying gameplay.
- `R`/restart clears current in-memory journal but does not secretly delete files. Save/Load is explicit, never automatic. No multi-device synchronization is implied.
