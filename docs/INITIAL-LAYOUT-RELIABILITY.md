# Стабильность первоначальной загрузки

## Обнаружение

В CI PR 99 от 16 октября 2026 года все функциональные сценарии выполнились, но отдельная лабораторная запись показала большой первоначальный сдвиг разметки. Успешное открытие страницы не считалось выполнением цели CLS.

Источник: [OSGARD frontend validation, run 38981987598](https://github.com/osmanosmanov6880-bot/osgard-world/actions/runs/38981987598), head `bfcca4feb73d472e45ea56cae368286c641e88f3`; временный merge commit проверки `779c96a7ebcba078bd5ad57240dfdfdd9af1de6d`.

Профиль: Chromium, viewport 390×844, задержка 150 мс, входящий трафик 1,6 Мбит/с, исходящий 750 Кбит/с, CPU 4×, HTTP-кэш отключён. Каждое значение относится к одному запуску до первого пользовательского ввода.

| Поверхность | LCP | CLS | Основное действие видно | Шрифты и видимая графика готовы |
| --- | ---: | ---: | ---: | ---: |
| WORLD | 1,744 с | 0,213365 | 1,932 с | 3,261 с |
| Intelligence | 1,712 с | 0,164786 | 1,920 с | 4,508 с |
| PLAY | 1,776 с | 0,763128 | 1,990 с | 3,888 с |

Крупные сдвиги зарегистрированы около 1,70–1,73 с. Сдвиги при поздней готовности шрифтов существенно меньше. Эти цифры не являются полевыми Core Web Vitals, INP или 75-м процентилем.

## Исправление

Общая оболочка показывает шапку, загрузочное содержимое и подвал до загрузки выбранной страницы. Прежняя минимальная высота загрузочного содержимого составляла 55vh: часть подвала была видна, а большой основной контент затем перемещал её за пределы экрана.

Загрузочное содержимое теперь резервирует минимум 100svh, с 100vh для совместимости. Подвал остаётся за первым экраном на этапе ожидания. Высота готовых страниц этим правилом не ограничивается.

Для `#product-main` установлен `display: flow-root`. Верхний отступ PLAY остаётся внутри своего контейнера и не схлопывается через него при замене загрузочного содержимого. Готовая композиция и пользовательские действия сохраняются; скрытие контента и задержка запуска не добавляются.

## Проверка после изменения

Мобильный лабораторный тест теперь требует **CLS не более 0,1** в заданном окне первоначальной загрузки. При нарушении проверка завершается ошибкой и сохраняет источники смещений: DOM-узлы, прежние и новые прямоугольники. Дополнительно записаны времена появления оболочки, загрузочного содержимого и hero. Это события DOM, а не доказательство момента показа пикселей.

Предел относится только к воспроизводимой лабораторной проверке. `fieldMeasurement: false`, `p75: null` и отсутствие полевого вердикта остаются в каждом отчёте. Фактические значения после изменения нужно читать в артефакте последнего успешного CI; исходные значения выше сохранены как свидетельство найденной проблемы.
