# Studio — приёмка конкретного выпуска

Реализовано локально, без публикации сайта, платежей, рассылки и сетевой проверки внешних URL. Нужен полный серверный комплект и аккаунты участников на одном сервере. Статический ZIP содержит интерфейс, но не запускает Python API.

## Маршрут

1. В `/workspace` создайте проект. Заполните контракт, включите Studio и локальные проверки, задайте критерии и артефакт. Для HTML-прототипа также разрешите его создание.
2. Сохраните условия, примите контракт, выполните проверки и зафиксируйте внутренний выпуск во вкладке Studio. Выпуск сохраняет номер исходной версии; его создание само по себе не является приёмкой.
3. Владелец добавляет уже зарегистрированного участника как редактора через вкладку «История». Приглашения и сообщения автоматически не отправляются.
4. Другой участник входит в свой аккаунт, открывает проект → «Приёмка» → «Открыть материалы выпуска». Доступны исходный контракт, критерии, источники, сохранённый HTML и история разборов.
5. Для каждого критерия выберите «Выполнен» или «Требует доработки» и опишите проверку минимум в 20 символах. Общий вывод тоже требует 20 символов. Все критерии выполнены — «Принят участником»; иначе — «Есть замечания».
6. Новый разбор дополняет историю. После исправлений создайте новый выпуск: старые разборы не переходят на него. При необходимости повторный разбор того же выпуска сохраняется отдельной записью.

Автор выпуска не может принять собственный выпуск, даже если он владелец проекта. Владелец может принять выпуск другого редактора. Наблюдатель только читает и скачивает материалы. Отзыв доступа закрывает чтение и повтор ранее сохранённой операции.

## Версии и доказательства

Материалы читаются из неизменяемого снимка исходной версии, а не из текущего редактора. Каждая запись содержит выпуск, исходную версию, проверяющего, результат каждого критерия, пояснения и время. Итог не подтверждает последующие изменения проекта, запуск сайта или независимую сертификацию.

Для сохранённого HTML сервер заново вычисляет SHA-256 и сравнивает с файлом и контрактом выпуска. При несовпадении положительная приёмка запрещена; замечания можно сохранить. Совпадение хеша доказывает целостность этих байтов, а не корректность продукта. Предпросмотр открывается в iframe с пустым sandbox, без выполнения скриптов.

Внешние ссылки не открываются сервером. Их содержимое могло измениться; участник вручную указывает, что именно проверял. Для старых выпусков без исходной версии приёмка недоступна: создайте новый выпуск.

## Надёжность и переносимость

Разбор записывается в общей транзакции с версией проекта, журналом и ключом операции. Одновременные отправки одной исходной версии дают один успешный запрос и конфликт второго. Повтор с тем же ключом возвращает исходный результат без дубликата; изменённое тело с прежним ключом отклоняется. При обрыве связи используйте общий блок незавершённого запроса.

Форма сохраняет номер проекта при открытии материалов. После изменения проекта её отправка блокируется; заново откройте выпуск и проверьте условия. Перед закрытием несохранённого разбора предусмотрено подтверждение. Текст не сохраняется автоматически в постоянное браузерное хранилище.

Кнопка JSON скачивает материалы выпуска с исходным контрактом, HTML (если он есть), результатом сверки и историей разборов на момент открытия. Это личные данные проекта: перед передачей проверьте источники и условия. Выгрузка не содержит пароли, сессии и резервные коды. Полный экспорт проекта и согласованная копия SQLite сохраняют все разборы. Восстановление обычной версии проекта не удаляет историю разборов.

## Проверки и ограничения

58 HTTP/SQLite тестов: 48 прежних регрессий и 10 сценариев Studio. Проверены снимок версии, изоляция проекта, роли, запрет самооценки, пояснения, конфликт версий, повтор операции, отзыв доступа, целостность HTML, история, новый выпуск, экспорт, резервная копия и выключенное согласие Studio. Серверный рендеринг и сборка проверены отдельно. Браузерная приёмка и реальные пользовательские разборы пока не выполнены; сертификаты и достигнутые показатели эффективности не заявляются.
