# INHERIT R9 — Компас следов

**Статус:** разработка в PR; production лишь после зелёного CI и deployment.
**Область:** существующая INHERIT. Core API, права, серверная история, платежи и сохранения не изменяются.

## Игровая цель

В «Наследии» есть шесть настоящих правил: дерево + мох, тропа + фонарь, цветы + колокольчик, арка + камень, указатель + тропа, насыпь + фонарь. До R9 игроку было трудно понять, где новый предмет создаст сочетание.

**Компас следов** показывает тип рекомендуемого предмета, проверенную прогнозную точку на острове, название сочетания и сколько новых связей появилось бы при таком ходе. Предложение не является фактически совершённым игровым событием.

Игрок нажимает «Выбрать инструмент и подсветить место». Компас активирует существующую кнопку инструмента и ставит только золотую подсказку. **Отдельный щелчок по самому острову** инициирует обычный игровой ход через существующий движок. Метка не является кликабельным игровым предметом.

При пустом мире предлагается дерево с нулём новых связей. При исчерпанном бюджете, некорректном сохранении и просмотре прошлого планирование не инициирует действий. В аккаунтном режиме существующая авторизация и правила сервера остаются неизменными.

## Инженерия и достоверность

Новый чистый модуль trace-compass-core.js сравнивает связь до и после пробного добавления **в временную копию** с помощью существующего InheritLegacyEngine.derive. Это те же фактические правила, что использует «Наследие».

- 10 известных типов предметов, 6 настоящих рецептов.
- Координаты рекомендованных точек строго внутри игрового диапазона острова.
- Не более 600 предметов в одном расчёте, 72 проверок кандидата, 5 разных типов предложений.
- Состояние проверяется повторно до выбора инструмента; устаревшие рекомендации не применяются.
- Золотая метка имеет pointer-events:none и не блокирует обычное нажатие на остров.
- Любая перерисовка острова удаляет метку. Никакого чтения или изменения исследования, статистики, покупок, прав или бюджета.
- Полный RU/EN/简体中文 интерфейс, Escape, клавиатура, мобильная компоновка, reduced-motion.

## Приёмочный сценарий

1. Открой чистый локальный INHERIT и затем Компас. Он предлагает дерево, не обещая готовую связь.
2. Нажми выбор инструмента — число объектов и бюджет должны оставаться прежними.
3. Нажми остров возле золотой метки — настоящий движок создаст дерево и изменит бюджет.
4. Снова открой Компас. После появления дерева среди предложений должен быть мох и возможность «Тихой рощи».
5. Выбери мох и отдельно поставь его у метки. Теперь журнал «Наследие» должен действительно показывать связь.
6. Проверь RU/EN/中文, Escape, мобильное расположение, нулевой бюджет и режим аккаунта.

## Проверка кода

Команды:

    npm run qa:inherit-compass
    npm run qa:inherit-legacy
    npm run qa:inherit-atlas
    npm run qa:inherit-timelapse
    npm run qa:inherit-handoff-moment
    npm run build

Новые unit-smoke тесты проверяют шесть правил, оба направления каждой пары, точное +2 для двух троп и фонаря, пустой мир, строгие координаты, неверное состояние, отсутствие мутаций, предельные размеры мира, локализацию и offline.

Playwright desktop и mobile проверяет реальные ходы дерева и мха, совпадение прогнозируемого и реально возникшего сочетания, работу Escape и состояние аккаунта. PWA v21 добавляет три ресурса компаса. Production проверяет точные байты опубликованных файлов.

## Граница результата

Это инструмент грамотного размещения в существующей игре, а не симуляция NPC, не доказательство появления нового хранителя, не настоящие покупки и не фотореалистичный AAA-мир. Прогноз зависит от того, поставит ли игрок нужный предмет в рекомендуемом месте и изменится ли мир до хода. Настоящее согласие пользователей на исследование и реальные D1/D7/D30 остаются отдельной задачей.
