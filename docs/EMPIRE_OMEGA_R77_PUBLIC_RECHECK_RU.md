# EMPIRE Ω R77 — независимая повторная проверка опубликованной Godot Web-игры

Дата: 25 октября 2026. Предназначено для настоящего Web-кандидата, не является перепубликацией.

## Зачем

После R72–R75 настоящие desktop/touch Chromium-тесты прошли, но первоначальный post-SSH R50 запуск на прежнем QA-коде упал. Чтобы повторить полную цепочку проверок уже опубликованной версии, теперь не требуется создавать новый пакет игры и заново выполнять SSH-деплой.

## Запуск

1. Убедитесь, что изменения R77 объединены с веткой `master`.
2. Откройте [GitHub Actions: EMPIRE Omega R50](https://github.com/osmanosmanov6880-bot/osgard-world/actions/workflows/omega-r50-release-evidence-qa.yml).
3. Нажмите **Run workflow** и выберите строго **master**. Запуск из иной ветки выполнит контрактные тесты, но не получит право объявлять проверку публичной игры.
4. Скрипт на отдельном GitHub runner повторно сверит исходный commit и проверит **семь настоящих публичных SHA-256** по HTTP.
5. После этого запустит реальный Chromium с Mesa/OpenGL в Xvfb, проверит desktop 1366×768 и touch 390×844, захват реальных кадров, посадку в автомобиль и управляемое движение. Не допускаются незамеченные повторы/ложные PASS.
6. Скачайте архив `omega-r50-exact-public-game-evidence-<run_id>` — оригинальные хэши, журнал браузера и трассировки. Временный архив хранится 14 дней; сохраните его для независимого ревью.

## Безопасность

- `workflow_dispatch` на `master` разрешает только независимую проверку, **не запускает SSH и не меняет WASM/PCK**.
- Старый путь запуска после успешного SSH остаётся; его source SHA и branch должны соответствовать `master`.
- `pull_request` не может запустить релизную приёмку даже при подмене ветки или CI-результатов.
- Отсутствие физических Android/iPhone обязательно фиксируется: даже при `7/7` и двух PASS браузерах результат `HOLD`, пока не завершена аппаратная приёмка.
- Никакой workflow не аттестует художественное качество, 40 миссий человека, 20 пользовательских сессий и коммерческий GO.
