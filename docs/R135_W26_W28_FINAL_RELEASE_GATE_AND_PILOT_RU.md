## W26 — абсолютная локализация и privacy-first показатели

**Definition of Done (реальная игра):**
1. Все фактические надписи GUI, титров, правил безопасности, текущих целей,
   кейсов и отрицательных состояний сопоставлены с RU и EN; тестируются
   строки длиннее 45 символов в 360×780, 390×844, 932×430 и 1366×768.
2. Выбор языка в URL не перезаписывает локальные предпочтения без
   отдельного действия игрока. Игра загружается по-русски.
3. Никаких скрытых SDK аналитики, ID пользователя, геолокации, отпечатка
   устройства или содержимого W14/W19 сейвов в сетевом запросе.
4. Метрики учебного поведения — *только при добровольном согласии*;
   минимум: начало учебного кейса, безопасное завершение, количество
   ошибок и повторная попытка. Результаты представлены агрегатами;
   можно отказаться и удалить локальные данные.
5. Native Godot, desktop+mobile WebGL, независимый переводческий review
   2 языков и экранов с длинными строками. Любой пропущенный перевод
   безопасности = **NO-GO**.

## W27 — пилот реального продукта

**Минимум 20–50 добровольных пользователей, а не ботов.** Формируется
согласованный протокол на 3 сценария:
- первый запуск; сколько секунд до осмысленной команды;
- ошибка блокировки; человек может сам объяснить причину и нужное действие;
- завершение 3 реальных кейсов; повтор сложного кейса и локальный рекорд;
- повторное посещение с сохранённым RU/EN и ECO/HERO;
- Android/iPhone/ПК с конкретным браузером, разрешением и способом записи.

**Предварительные критерии:**
- не менее 8 из 10 тестируемых могут объяснить опасную ошибку и верное
  действие без подсказки тестировщика (цель W21);
- 0 воспроизводимых обходов симулированной блокировки;
- 0 миграций с потерей существующих рекордов W14 или курса W19;
- 0 блокирующих ошибок открытия/сканирования/отката на поддерживаемой
  платформе;
- определённые до испытаний device-tier бюджеты FPS/нагрева/памяти,
  измеренные **на физическом железе**. Chromium SwiftShader и rAF — не
  независимая оценка реального GPU.

Без оригинальных записей и подписанных карточек проблем никакой
«95% успешности пилота» не выдумывается. Если три кейса не дают причинно
разных стратегий, запуск следует задержать и усилить механику W22.

## W28 — окончательная production v1

**Разрешение на переключение возможно только после W26+W27+W25:**
1. Frozen SHA исходного кода, точный `release.json`, хеш архива
   Godot WebGL/WASM/PCK, результаты реальных native+browser+phone тестов.
2. Independent review неизменённых оригинальных кадров экрана каждого
   ключевого этапа; проверка 44px touch, RU/EN и безопасных ошибок.
3. Лицензии на PBR, звук и шрифты; правила обработки локальных данных,
   пояснение «учебная симуляция, не инструкция реального обслуживания».
4. Неизменяемый GitHub Release, fail-closed release pin, SSH с проверкой
   актуального master и предварительно проверенной точкой возврата W20/W21.
5. На живом `https://osgard.world/games/r135-service/` сравнить точные
   SHA манифеста и WebAssembly, открыть RU/EN и пройти полный кейс.
   Проверить сохранность остальных `/games/*` и same-origin API.
6. В случае несовпадения хеша, недоступности сайта, потери сейва или
   небезопасного поведения — **автоматический HOLD/ROLLBACK**, а не
   выпуск «для галочки».

## Последовательность без потери реального релиза

**1.** W21 protected SSH **действительно выполнен**, см. #40219491086,
выпуск подтверждён точным публичным HTTP SHA и Godot WebGL. Сохранять его
как откат для W27. Повторное переключение W21 не требуется.

**2.** Довести W22 Chromium, исходные 19 PNG, независимую приёмку;
затем отдельно внедрить новые кейсы.

**3.** Проверить W23 art+PBR в реальном WebGL на ПК/телефоне; при
низкой производительности заменить HERO доп. геометрию на простые
батчи, не меняя физику.

**4.** Довести W24 audio/captions и W25 аппаратную матрицу; выполнить
W26 localization/privacy, W27 бета, затем W28 защищённый GO/NO-GO.

**Жёсткая граница правды:** пройденный CI ≠ физический тест. PR ≠
публичная игра. Проверенный GitHub Release ≠ опубликованный VPS.
Без человеческой приёмки и устройств W28 не объявляется завершённым.

## Фактический этап W27/W28 — программный выпуск не равен человеческой бете

- Нативная интеграция **W27** с W19–W26, PBR и приватностью:
  [Actions #40221692223](https://github.com/osmanosmanov6880-bot/osgard-world/actions/runs/40221692223)
  SUCCESS на точной версии источников. Полный desktop+Pixel WebGL должен
  пройти независимо; никакой green native не заменяет эту проверку.
- WebGL W27 генерирует **12 оригинальных source-derived Web-only PBR PNG**,
  сохраняя в Godot native оригинальные 1024px карты и облегчённый ECO.
  Качество графики подтверждается только source PNG, реальным WebGL
  и сравнением производительности, не словами «AAA».
- W25 безопасный локальный запуск аппаратной записи:
  `node scripts/r135-w25-physical-capture.mjs`, только авторизованный Android
  Chrome через локальный CDP; iPhone Safari требует отдельного реального
  подключения Web Inspector. Программный Chromium не выдаёт физические FPS.
- Машиночитаемый **NO-GO W28**:
  `node scripts/r135-w28-launch-decision.mjs --pin EXACT_W27.json
  --selector scripts/r135-active-release.json --software INDEPENDENT.json
  --phone-matrix 16_REAL_SESSIONS.json --pilot 20_REAL_VOLUNTEERS.json
  --licenses REVIEWED_LICENSES.json --operations SIGNED_LIVE_REVIEW.json`.
  Результат включает проверяемые блокеры и
  `automatic_deploy_authorized=false` даже если структурные условия
  выдержаны: подпись ответственного за выпуск и реальные устройства
  не могут быть заменены скриптом.
