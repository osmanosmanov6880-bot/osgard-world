# EMPIRE Ω R76 — подлинный HUD портретного Godot Web

## Исходная визуальная приёмка

Снимки настоящей опубликованной игры, полученные без подмены кадров в [R53 №40211668095](https://github.com/osmanosmanov6880-bot/osgard-world/actions/runs/40211668095), [архив изображений №12605852071](https://github.com/osmanosmanov6880-bot/osgard-world/actions/runs/40211668095/artifacts/12605852071).

Оригинальные портретные кадры: **390×844**. Плашки статуса, цели и сообщения перекрывают участок сверху приблизительно до 250-го пикселя. Тест desktop — оригинальная игра в Chromium; захваченный для проверки кадр 960×540, а не 8K.

## Реализация R76

- Для портретных экранов с шириной менее 520 и высотой от 620 px уплотнены только три верхние панели. Расчётная нижняя граница временной плашки теперь **219 px** вместо 250 px. Это геометрическое значение из Godot, не ещё одна фактическая запись нового браузера.
- Цель и прогресс главы сохранены, отдельные сенсорные кнопки остаются доступны. Плашка быстрого меню перенесена ниже сообщения, без перекрытия.
- Высота текста цели и уведомления адаптирована; при смене ориентации шрифты и межстрочные промежутки явно возвращаются к desktop-настройкам.
- Для малых 320×568 сохранена уже проверенная раскладка, поскольку агрессивное уменьшение на коротких экранах может ухудшить читаемость.

## Ворота выпуска

1. **Godot 4.4.1 native**: v29 responsive layout + реальный запуск 3D игры при 390×844 и 1600×900.
2. **Chromium Web**: записать оригинальные кадры при 390×844 и 320×568, подтвердить, что миссия, уведомление и все нажатия доступны.
3. **Физические устройства**: проверить Android/iPhone, смену ориентации, длинные русские строки, 20-секундный FPS/p95/p99.
4. **AAA art HOLD**: данная доработка не меняет низкополигональные модели города, автомобиля и деревьев, не заявляет AAA-графику.

Никакой успешный нативный тест не считается заменой опубликованному WASM/PCK и независимому браузерному QA.
