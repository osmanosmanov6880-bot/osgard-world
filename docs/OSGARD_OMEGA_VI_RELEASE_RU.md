# OSGARD Ω VI — NASA 4K Earth: инструкция и критерии релиза

## Что действительно реализовано

- Настоящие спутниковые карты поверхности Земли NASA Blue Marble (дневная) и NASA Earth at Night (исторические данные об освещении), локально в `public/brand`, без вызовов внешних CDN с устройства посетителя.
- 1K, 2K и **4096 × 2048** WebP-версии; исходные две половины Земли объединяются в корректную эквиректангулярную проекцию. Каждая обработанная текстура имеет SHA-256 и источник в `omega-nasa-manifest.json`.
- Текстура ночных огней учитывает линию дня и ночи. Солнце освещает Землю в мировых координатах, вращение планеты действительно меняет видимую ночную сторону. Атмосфера приближена шейдером голубого рассеяния и оранжевой сумеречной зоны.
- Облака — художественная многооболочечная процедурная система, в режиме 4K дополнена **8-шаговым GPU ray-marching облачной оболочки**. Это НЕ метеоданные, не физически валидированная объёмная симуляция.
- Режимы «Кино / 3D-мир / Гибрид» сохраняются. Новое управление качеством «Авто / Эконом / 4K / Макс.» хранится локально и имеет подписи, понятные посетителю.
- На смартфонах «4K / Макс.» использует 2K-текстуры, чтобы не перегружать GPU. При сниженной анимации/отсутствии WebGL показывается отдельная 1024 × 1024 фотографическая проекция Земли, не CSS-кляксы.
- Предыдущий процедурный WebGL-глобус сохраняется как резерв при ошибках NASA-текстур.
- Нет изменений в платёжных, игровых, персональных, серверных API или аккаунтных функциях.

## Авторские данные / источники

NASA/Goddard Space Flight Center Scientific Visualization Studio.

- Дневная поверхность Blue Marble: https://svs.gsfc.nasa.gov/2915 — данные Reto Stöckli (NASA/GSFC), NASA Earth Observatory.
- Ночная поверхность: https://svs.gsfc.nasa.gov/2916 — данные Marc Imhoff (NASA/GSFC), Christopher Elvidge (NOAA/NGDC); изображения Craig Mayhew и Robert Simmon (NASA/GSFC).
- `scripts/omega-nasa-assets.py` воспроизводимо собирает семь выходных файлов, сохраняет источники и контрольные суммы.
- Эти изображения — историческая мозаика и художественная обработка; не спутниковый поток в реальном времени.

## Приёмочные критерии

1. `npm ci && npm run check && npm run build`.
2. Релизные проверки существующих продуктов OSA, PLAY, Development и игровых/аккаунтных сценариев.
3. Browser QA: семи ассетам возвращается HTTP 200, формат WebP и размеры подтверждены; на десктопе максимальный режим использует day/night 4K, на мобильном — 2K; переключение сохраняется.
4. WebGL-шейдеры не дают ошибок компиляции, канвас отображается; при отключённом WebGL/анимации основной интерфейс остаётся видимым.
5. Отсутствуют горизонтальный скролл и перекрытие управляющих элементов на мобильном.
6. После merge: штатная безопасная SSH-публикация на VPS с откатом, затем публичная проверка `osgard.world`.

## Границы технологии

Используются реальные 4K спутниковые **текстуры**, а не 4K видеопоток. Это серьёзный шаг к фотореализму, но не подтверждённый офлайн-рендер Unreal Engine или физически точная атмосфера уровня дорогого AAA-кинопроизводства.

**Не заявлять окончательный релиз до успешного CI, SSH-активации и публичного браузерного QA.**
