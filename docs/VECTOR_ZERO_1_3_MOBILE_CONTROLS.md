# VECTOR//ZERO 1.3 — полный сенсорный контроль

Игра: `/games/vector-zero/`; исходник: `public/games/vector-zero/index.html`.

## Что реализовано

1. На телефоне/планшете доступны все игровые действия: движение, прыжок, запуск, полярность, **импульс** и **пауза/продолжить**.
2. Русские подписи и `aria-label` для каждой сенсорной кнопки. Кнопка паузы отражает состояние через `aria-pressed`.
3. Сетка сенсорных кнопок рассчитана на четыре колонки с целями не меньше 48px на узких экранах; на планшетах с грубым указателем отображается самостоятельная раскладка 50px.
4. При двух одновременных пальцах на кнопке движения отпускание одного больше не сбрасывает удержание другого.
5. Клавиатура и сенсорное управление имеют независимые состояния: отпускание одной кнопки не снимает удержание другой. При потере фокуса, паузе и сбросе игровой ввод безопасно очищается.
6. Space, нажатый при фокусе на обычной HTML-кнопке, не запускает одновременно глобальное игровое действие.
7. Изменения целей игры объявляются экранным диктором через `aria-live="polite"`.

## Проверка

- `node scripts/vector-zero-runtime-smoke.mjs` запускает реальную встроенную реализацию игры и проверяет физику, управление, мультитач и паузу.
- `scripts/vector-zero-ghost-browser.spec.mjs` дополнен настоящим Chromium-испытанием с мобильным viewport: видимость, семь сенсорных кнопок, размер цели, импульс, пауза и возобновление.
- Проверка `node scripts/vector-zero-production-smoke.mjs osgard-release/html` сравнивает SHA-256 опубликованного игрового JavaScript с релизом после SSH-публикации.

Это реальное улучшение существующего Canvas-платформера, **не переход на фотореалистичный Unreal Engine**. Испытание на конкретном физическом смартфоне и оценка кадров/сек в нём остаются отдельной задачей. Stripe и реальные платежи не затрагиваются.
