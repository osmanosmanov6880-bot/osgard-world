# OSGARD cinematic intro — графические слои

Дата подготовки и проверки: **21 октября 2026 года**.

Набор создан встроенным **Imagegen** на основе предоставленного пользователем визуального референса. Два окружения являются самостоятельными фоновыми слоями без надписей и логотипов. Металлический знак получен отдельным запросом редактирования и извлечения знака из пользовательского референса с сохранением кругового силуэта, диагонального разреза и верхнего правого сектора. Это художественные ресурсы заставки сайта; они не являются скриншотами работающего интерфейса, игр или игрового процесса.

Типографика OSGARD / DIGITAL UNIVERSE, анимация орбит, частицы и интерактивные элементы реализуются компонентами приложения поверх этих изображений. Завершённый постер с вмонтированным интерфейсом не используется.

Все шесть WebP занимают **744 374 байта**. Это фактические размеры результатов генерации; увеличения разрешения до 4K не выполнялось.

Исходники находятся в наборе оригинальной графики по относительным путям `osgard-art/intro/<id>.png`. PNG не добавляются в публичные файлы приложения. Рабочие файлы размещены в `public/brand/intro/`:

- `energy-platform.webp` и `energy-platform-1280.webp`;
- `energy-platform-mobile.webp` и `energy-platform-mobile-780.webp`;
- `osgard-emblem.webp` и `osgard-emblem-640.webp`.

Мобильное окружение создано отдельным запросом в вертикальной композиции. Варианты 1280 / 780 / 640 являются только пропорционально уменьшенными версиями соответствующих оригиналов, без изменения художественного содержания.

## Применение

Фоны рассчитаны на центрированную многослойную композицию: тёмная верхняя область предназначена для отдельного знака и живого текста, физическая энергетическая платформа находится в нижней части изображения. Для узких экранов предусмотрен отдельный портретный фон.

Знак следует показывать целиком, без обрезания. Подложка вокруг него и отверстия внутри силуэта имеют настоящий альфа-канал, поэтому поверх фона не возникает чёрного прямоугольника. Мягкое свечение сохранено. Плотная часть силуэта оригинала при alpha ≥ 128 занимает прямоугольник `(64, 68)–(1192, 1183)` внутри холста 1254 × 1254. Очень слабые полупрозрачные детали выходят за этот прямоугольник; специально обрезать их не нужно.

## Подготовка и проверка

Фоны закодированы в WebP с качеством 85 для основных файлов и 82 для уменьшенных. Знак закодирован с качеством 92 и 90 соответственно. Применены `method=6`, сохранение прозрачности и пропорциональное уменьшение Lanczos. Содержимое и геометрия не ретушировались программно.

Все три PNG и шесть WebP полностью декодированы. Альфа-канал основного `osgard-emblem.webp` побитно совпадает с альфа-каналом исходного PNG; диапазон — 0–255. Проверено наличие всех шести ожидаемых WebP. Изображения визуально проверены после генерации: на фонах нет текста или знака, а изолированный знак не содержит слов, планет или орбит.

`asset-inventory.json` содержит фактические размеры, вес, режим цвета, SHA-256 каждого файла и результаты технических проверок. `prompts.json` сохраняет точные исходные запросы, режим прозрачности и SHA-256 пользовательского референса. Сам пользовательский референс в набор не включён. Во всех метаданных использованы переносимые относительные пути без локальных путей окружения.

Процент визуального совпадения с референсом не измерялся и не заявляется. Проверку композиции работающей заставки необходимо проводить по скриншотам реального приложения с HTML, SVG и анимацией.
