# OSGARD WORLD — программа развития 22 игр до коммерческого качества

Статус документа: **дорожная карта разработки**, а не утверждение о готовом AAA-релизе. Ведущий источник статусов: [`public/games/aaa-roadmap.v1.json`](../public/games/aaa-roadmap.v1.json). Дата первой версии: **24.10.2026**.

## Правила отслеживания результатов

- **COMPLETED**: выполнена и проверена конкретная поставка. Для изменений публичного сайта требуются успешные CI, выпуск, публичные проверки и ссылка на доказательства. Инвентаризация `00` не является игровым релизом.
- **IN REVIEW**: код готовится к проверке либо открыт PR, но публикация ещё не подтверждена.
- **PLANNED**: работа не выполнена. Задачи и тесты нельзя показывать как готовые только потому, что они описаны в документации.
- Каждый крупный проход завершается записью вида: `WAVE N — что реально изменено; файлы; PR/commit; пройденные тесты; статус сервера; что осталось`.
- Состояние каталога — снимок данных, а не автоматически обновляемая оценка из CI. После merge и проверки публикации его необходимо обновлять новым коммитом.

## Художественное направление и технические условия

Референсы — **планка исполнения**, а не объекты для копирования. Собственные персонажи, модели, сюжеты, названия и эмблемы обязательны.

- **EMPIRE Ω:** ориентир по дороге, погоде, управляемости и материалам — Forza Horizon 5; локальная архитектура и автомобили под собственный художественный контекст; Godot Web и дальнейшая PC-сборка могут иметь разные графические профили.
- **NULL//SHIFT:** Control для архитектуры/света, Escape from Tarkov для читаемости тактического пространства, но оригинальная механика рейда.
- **NEBULA:** Everspace 2 для ясности боевого пространства, Star Citizen как дальний ориентир масштаба, с реалистичным бюджетом WebGL/GPU.
- **SWARM:** Helldivers 2 / The Division 2 для роли, целей и кооперативного фидбэка.
- **VECTOR//ZERO:** Portal 2 / The Talos Principle 2 для физической причинности и композиции пространственных задач.
- **R136 Precision:** Satisfactory / Hardspace: Shipbreaker для технической читаемости, без ложного заявления о реальном промышленном управлении.
- **ZION:** атмосферные 3D/2.5D-вариации на базе текстовых прототипов, общий framework, но 11 разных задач и окружений.

### Практический порядок повышения качества

1. Сначала закончить **один качественный игровой цикл**, измерить его, а затем масштабировать уровень; не называть исходную 3D-сцену AAA.
2. Сделать управление и интерфейс работоспособными на клавиатуре и сенсорном экране до дорогостоящей постобработки.
3. Каждый материал, модель и анимация должны иметь происхождение и права использования; не переносить ассеты из игр-референсов.
4. Для браузера использовать реальные бюджеты GPU и WebGL. PC-версии на Unreal/Godot могут быть отдельными сборками; одинаковое качество с AAA PC на любом телефоне недостижимо.
5. Окна, карты, геймплей, сеть и платежи — разные контуры QA; успешное выполнение одного не подтверждает остальные.

## Журнал проходов

### WAVE 00 — проверка данных каталога

- Источник: `public/games/index.html`, 22 `data-game`, 22 записи JSON-LD, 11 основных игр и 11 ZION.
- Выполнено: зафиксированы художественные направления и связи игры → референс → самостоятельная будущая эмблема.
- **Что не выполнено:** реализация AAA-графики, физики и игровых механик по этой волне не утверждается.

### WAVE 01 — иммерсивный PLAY и приложение-трекер

- PR #248 объединён в `master` после успешного frontend/browser CI. Публикация остаётся отдельным критерием завершения; успешный merge не равен подтверждённому live SSH.
- Проверки: корректный путь `/games/roadmap/`, 22 уникальные записи, переключаемые фильтры и сценарии отсутствия данных; полноразмерное игровое окно, кнопки close/direct/fullscreen; отсутствие регрессий каталогов и lifecycle.

**Следующий запись в журнал** добавляется только при настоящем переходе статуса с доказательствами.

### WAVE 02 — самостоятельная художественная система 22 миров

Фактический исходный материал (нужно отличать от результата публичной публикации):

- **22/22 уникальных эмблемы:** `public/games/icons/{game-id}.svg`, SVG 128×128 с разными геометрическими мотивами и игровыми цветовыми акцентами.
- **22/22 обложки подключены к карточкам `/games/`:** 19 индивидуальных WebP-обложек `/brand/play/` уже имелись в репозитории и имеют превью 640w; ещё три мира используют собственные SVG-обложки `/brand/world-*.svg`.
- **Картинки в карточках:** `public/games/world-artwork.css` + `public/games/index.html`, живые оригинальные изображения, lazy loading, responsive srcset, явная маркировка «КОНЦЕПТ-АРТ», оригинальная маленькая эмблема рядом с названием.
- **Интерактивный трекер:** `/games/roadmap/` теперь отображает обложку и эмблему каждого мира, фильтрует по группам и статусам.
- **Честные формулировки:** визуализации не называются кадрами настоящего 3D-движка, уровнем Forza Horizon 5 или AAA-геймплеем.
- **CI-доказательства:** `scripts/games-aaa-wave02-smoke.mjs` проверяет количество, уникальность файлов и обязательные пути; интегрирован в `npm run qa:games-portal`.
- **Live-доказательства:** `scripts/games-aaa-wave02-production.mjs` проверяет реальный HTTPS-каталог, публичный трекер, JSON и 44 медиафайла с ограничением параллельности. Добавлен после SSH-активации в `deploy-frontend.yml`.

**Статус WAVE 02:** PR #250 объединён, frontend/browser QA пройден. Независимый публичный GitHub Actions run #40062693538 проверил на `https://osgard.world` **22 мира и 44 из 44 реальных медиафайлов**: `PASS`, ошибок 0. В рамках художественного каталога этап `completed`. Отдельный полный SSH-конвейер ранее падал на устаревшей проверке HTML NEBULA (исправлено PR #255), так что результат арт-гейта не является доказательством состояния всех остальных сервисов. Эта поставка не изменяет материалы, модели, физику и сюжет внутри игр.

### Как появятся подтверждённые отметки

После прохождения соответствующего CI, объединения PR и успешного SSH-выпуска обновляется JSON-реестр: `state: completed`, evidence с конкретными ссылками на PR и workflow run. Нет доказательства публикации — нет «completed». Игровые флагманы требуют отдельного runtime QA, не только красивые карточки.

### WAVE 03 — единый интерфейс запуска и возвращения в игровой мир

**Реально реализованный объём в исходном коде:**

- `public/games/player-session-core.mjs` — валидируемая запись последней открытой игры: версия, id из 22 известных карточек и временная метка. Истекает через 45 дней. Не сохраняет токены, адреса сторонних сайтов, игровой прогресс или историю действий.
- `public/games/player-experience.mjs` — быстрая кнопка возвращения в последнюю игру, безопасное вычисление адреса из *текущей карточки каталога*, удаление истории, синхронизация между вкладками, защита от порчи localStorage.
- Из настоящих `launch-facts` в карточках каталога вытащены **22 набора фактических сведений**: управление, сохранение и сетевая доступность. Все внесены в `aaa-roadmap.v1.json` и доступны в интерактивной карточке на `/games/roadmap/`.
- Подсказка управления в интерфейсе встроенного запуска: кнопка, доступная с клавиатуры/тача, открывает контекстную панель с описанием текущей игры и честным указанием возможностей сохранения.
- Состояние offline в портале предупреждает, что онлайн-режим может быть недоступен, и не отключает локальные игры.
- `public/games/player-experience.css` — адаптивный интерфейс этих функций под мобильный/десктопный viewport, без перехвата клавиш непосредственно внутри игры.

**Автоматизированная проверка:**

- `scripts/games-aaa-wave03-session.test.mjs` тестирует TTL, неверные/чужие ссылки, испорченный JSON, отсутствие подмены сохранений и 22 дословно согласованные карточки.
- `scripts/games-aaa-session-browser.spec.mjs` проверяет реальный запуск, открытие панели помощи, сохранение/очистку последнего мира, невозможность перехода по поддельной записи и offline-уведомление на desktop/mobile.
- `scripts/games-aaa-wave03-production.mjs` и дополнительный шаг SSH workflow проверяют уже опубликованный HTTPS интерфейс и все 22 сведений.
- Все тесты подключены к общим CI: `qa:games-portal` и Playwright браузерному набору.

**Что WAVE 03 НЕ подтверждает:** наличие cloud-save для игр, кроссплатформенную синхронизацию аккаунта, поддержку геймпада внутри каждой игры и работоспособность всех 22 локальных сохранений. Эти функции требуют отдельных контрактов и QA по каждому движку и будут выполняться последующими игровыми проходами.

**Текущий статус:** `in_review` — код создан, результаты CI/SSH/HTTPS не подтверждены. Статус меняется только по реальным GitHub Actions и публичной проверке.

### WAVE 04 — EMPIRE Ω, подтверждённые игровые изменения R5/R6 (часть большого этапа)

- **R5:** в реальных `godot/empire-omega/scripts` внедрены детерминированные помощники тяги/руления при боковом сносе и снижении сцепления, без отмены торможения и ручника. PR #253 вошёл в `master`, подлинный Godot Web экспорт run #40061008272 успешен.
- **R6:** PR #256 вошёл в `master`: 8 `TouchScreenButton` для реальных действий Godot InputMap, управление автомобилем и пешком двумя пальцами, RU/EN/ZH, скрытие при открытых диалогах, отдельное нативное тестирование.
- Нативный Godot 4.4.1 CI run #40062765088: V21 **14**, V25 **34**, V27 **20**, V28 **70**, всего **138/138**. Важное ограничение: нативные тесты подтверждают игровую интеграцию и UI-узлы, но не измеряют реальные смартфоны и FPS.
- Полный WAVE 04 пока `in_review`: требуется новый Web экспорт именно R6, публичная активация, проверка touch на настоящих браузерах, показатели производительности и более богатые игровая сцена/миссии/окружение.
- Не считать эти изменения полноценной AAA-физикой, ABS или фотограмметрией.
