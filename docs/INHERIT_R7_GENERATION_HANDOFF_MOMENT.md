# INHERIT R7 — «Момент наследования», фактический результат передачи

**Дата:** 21 октября 2026  
**Область:** только INHERIT; игровое подтверждение реально завершённого поколения.  
**Выпуск:** установленный производственный workflow должен закончиться \`success\` на точном SHA, прежде чем R7 можно назвать опубликованным.

## Проблема

До R7 игрок действительно оставлял след и передавал поколение, но кульминация состояла в коротком текстовом уведомлении. Более того, **локально сохранённый** исход запроса к общему миру и **проверенная сервером** передача могли визуально казаться одинаковыми. Это вводит пользователя в заблуждение: сетевой тайм-аут не доказывает ни удалённого подтверждения, ни отсутствие коммита.

R7 добавляет читаемое завершение игрового цикла и сохраняет правильную границу между локальной памятью и серверными доказательствами.

## Что реализовано

- Сразу **после действительного успешного сохранения** текущего поколения появляется компактная ненавязчивая карточка «След остался. Мир продолжается». Она не закрывает весь экран и не мешает следующему ходу.
- Показаны номер передаваемого поколения, следующий номер, реальное число новых следов, перечень их видов и мини-карта расположения; максимум 32 точки на карте, но счётчики учитывают все переданные следы (до 100).
- Локальная и серверная семантика различаются отдельными текстами:
  - **Shared server confirmed** — POST завершился и ответ соответствует ожидаемому поколению; это не означает, что след уже кто-то увидел.
  - **Local saved / server unverified** — данные записаны локально после недостоверного ответа сервера; никакой гарантии удалённой публикации.
  - **Account server confirmed** — аккаунтный контроллер проверил подпись операции на уровне протокола, содержимое/ревизию и повторно загрузил актуальный мир до отображения результата; само по себе не означает принятие хранительства другим игроком.
- После нулевого хода, неверного поколения, конфликта (409), отклонённой или неопределённой аккаунтной операции карточка **не появляется**. Случай восстановления успешно подтверждённой операции использует тот же контроллер \`complete\`, поэтому может показать правдивый результат с запозданием.
- Кнопка продолжения возвращает фокус на остров. В локальном режиме кнопка истории открывает **Атлас поколений**. В аккаунтном режиме — существующую серверную историю мира без выдуманных локальных архивов.
- Доступны RU / EN / 简体中文, клавиатура, Escape при фокусе внутри карточки, \`role=status\`, адаптивная вёрстка, отключение декоративной анимации при \`prefers-reduced-motion\`.
- Вся сцена — только клиентское оформление подтверждённого события. **Нет** новых запросов, хранилища, телеметрии, платежей, касаний игрового бюджета, генераций, права хранителя или серверного API.

## Техническая модель

\`handoff-moment-core.js\` — чистая функция \`create(payload)\`, строго проверяющая:
- режим \`local/account\`, исход \`confirmed/local\` с запретом «локально подтверждённого аккаунтного мира»;
- последовательные безопасные номера поколений \`from → from+1\`;
- от 1 до 100 настоящих следов десяти поддерживаемых видов, конечные координаты 0–100;
- для локальной версии — целевой \`after.generation\`, отсутствие \`pending\` и точное совпадение хвоста сохранённых объектов с переданными;
- правильное суммирование повторяющихся одинаковых следов.

Только окончательная локальная функция \`#pass\` может отправить событие в \`InheritHandoffMomentUI.committed\` после \`persist(); render();\`. Аккаунтный контроллер вызывает этот же метод исключительно из \`complete(saved,result,context)\` **после** \`operationProof\`, повторной загрузки текущего мира и удаления восстановленного operation journal.

Дополнительная клиентская карточка не является криптографическим сертификатом удалённой операции. Достоверность обеспечивают существующие проверки в вызывающем коде, а не изображение, анимация или текст интерфейса.

## Проверка в игре

1. Открыть \`https://osgard.world/games/inherit/\`, сначала нажать «Завершить поколение» без размещений: **никакой карточки не должно появиться**.
2. Выбрать дерево и поместить его на остров через реальное игровое действие.
3. Нажать «Завершить поколение». Карточка появляется только после разрешения реального исхода запроса.
4. Открыть список следов; убедиться, что число и расположение взяты из размещений, а не созданы ради картинки.
5. Переключить язык, убедиться в переводе статуса, продолжить игру или открыть Атлас поколений.
6. Открыть игру без сети, оставить след и передать поколение: ожидать **«локально сохранено, сервер не подтвердил»**.
7. Для аккаунтного режима — выполнить реальное создание поколения текущим хранителем, дождаться серверной проверки операции; отклонённая или неопределённая попытка не должна показывать подтверждение.

## Проверки и обратная совместимость

\`\`\`sh
npm run qa:inherit-handoff-moment
npm run qa:inherit-atlas
npm run qa:inherit-world-cycle
npm run qa:inherit-research
npm run qa:inherit-followup
npm run build
\`\`\`

Отдельные Playwright desktop/mobile тесты используют реальные кнопки игры, моки HTTP 201/503/409 (как **тестовые ответы**, никогда не как результаты реальных игроков), проверяют переход в атлас, три языка и неизменность снимка во время просмотра.

Production-выпуск через \`deploy-frontend.yml\` перед SSH активирует QA, затем побайтно сверяет опубликованные \`handoff-moment-core.js\`, \`handoff-moment.js\`, \`handoff-moment.css\` с одним исходным релизом. PWA кеш обновлён до v19.

## Следующее, что нужно доказать реальными людьми

R7 делает критическую часть игры визуально понятнее, но **не доказывает D1/D7/D30, платежеспособность, вовлечённость или коммерческий успех**. Для этого по-прежнему необходимы реальные добровольные участники, удобный способ получения согласованных экспортов и наблюдаемые результаты пилота, описанного в R4/R5.
