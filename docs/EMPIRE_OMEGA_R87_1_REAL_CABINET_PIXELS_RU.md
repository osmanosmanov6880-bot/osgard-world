# EMPIRE Omega R87.1 — исправление измерения настоящих Chromium pixels

Дата 25.10.2026. Повторный R87 Godot native QA #40227582698 SUCCESS. Отдельный PR браузерный R33/34 job #40227582615 FAILED, исходный artifact #12612556895 сохранён.

Оригинальный HTML5 Godot оставался активен, но два подлинных композиторных снимка с одной CSS 1366x768 страницы оказались разного физического размера: первый 1366x768, второй downsampled 960x540. Оба имели правильное соотношение сторон и реальный игровой мир. В original Tab-нажатии золотой заголовок панели обнаруживается в кадре после нажатия (76 золотых выборок из 11000 нормализованных точек против 0 до нажатия), темная левая панель 0.717 против 0.024 до нажатия. Старый тест ошибочно требовал before.width === after.width и before.height === after.height.

R87.1 исправляет не Godot физику и не живые кадры, а критерий CI:
- CSS viewport строго 1366x768 и каждая PNG независимо должна иметь допустимый настоящему Chrome compositor размер и 16:9 пропорции.
- Ровно 110x100 точек внутри одинакового относительного прямоугольника, поэтому размер изображения не может подделать появление золотого текста или тёмного кабинета.
- Сохраняются все настоящие pixel-условия: мир не чёрный, золотой заголовок после реального Tab, реальное увеличение GOLD по сравнению с состоянием до, темная область левого UI, видимость мира справа, ноль ошибок JavaScript. Никаких заглушек canvas.
- Отдельный Node unit test использует ТОЛЬКО синтетические негативные структуры для испытания математики размеров. Реальный браузерный Godot остаётся обязательным; unit test не сертификат игры.

Опубликованный R81 runtime и исходный R84 live Web G0 SUCCESS не меняются этим PR до настоящего будущего экспорта. Полный AAA и коммерческий GO остаётся HOLD до аппаратных и человеческих испытаний.
