# NEBULA R49 — проверяемый порядок выпуска

**Дата:** 2026-11-05. **Статус:** подготовка, NOT RELEASED. Источник: [PR #745](https://github.com/osmanosmanov6880-bot/osgard-world/pull/745). Защита выпуска: [PR #746](https://github.com/osmanosmanov6880-bot/osgard-world/pull/746).

> R48 остаётся утверждённой production-сборкой в `.github/nebula-production-allowlist.json`. Изменение номеров версий или текста страницы само по себе не означает публикацию NEBULA.

- [ ] Все required-checks именно последнего HEAD в PR #745: Godot 4.7.2 GDScript, native smoke, настоящий Chromium WebAssembly flight, мобильный touch в браузере, frontend, визуальные сценарии, launcher safety, payment gate.
- [x] На этапе подготовки добавлены 3 режима ведомых (`follow / attack / defend`), миссия №11 «Тени порта», интерфейс касания и клавиш, три физических терминала, секретный режим без огня союзников, обнаружение лазера и ракеты, проверка прерванного удержания, защита от двойной награды.
- [x] Исправлена навигация автопилота к текущей цели миссии и устаревший тест заголовка World/Portal.
- [ ] Живые физические Android/iPhone, GPU/FPS, перегрев и длительность сессии: **NOT_PERFORMED**. Браузерная эмуляция не является подтверждением реальных устройств.
- [ ] Согласована политика публикации с явно отражённым отсутствием физических тестов; никаких заявлений `hardware_qa_certified=true` без реальных подписанных результатов.

## Порядок продвижения к production (обязательный)

1. Убедиться, что весь GitHub CI PR #745 завершён успешно, и объединить проверенные исходники в `master` без игнорирования обязательных ошибок.
2. Запустить / дождаться штатного `REMIX NEBULA 3D native Web release` на `master`. Он должен собрать `public/games/remix/arena-v2/nebula-3d/index.{html,js,wasm,pck}` из новых исходников и зафиксировать trusted Web export commit; не копировать файлы из неизвестного ZIP или ветки PR.
3. Привязать новый экспорт к проверенным `native_source_commit_sha`, `web_export_commit_sha`, `verification_workflow_run_id`. Рассчитать **Git blob SHA-1**, а не сырой SHA-1, отдельно для всех четырёх файлов, через `git hash-object <file>` или `git rev-parse HEAD:path`. Выписать размеры.
4. В PR #746 заменить только `approved_variant`, `release_status`, `artifacts` и подлинные поля `approval` на проверенные R49, не изменяя политику R40. Если отдельное согласие владельца на выпуск без физического теста не подтверждено, остановиться и не создавать фиктивный `R49_OWNER_DIRECTED_OVERRIDE`.
5. Выполнить `node scripts/test-nebula-production-artifact-guard.mjs` и `node scripts/nebula-production-artifact-guard.mjs`. Проверить отрицательные тесты: байтовая подмена HTML/JS/WASM/PCK, некорректные аттестации, отсутствующее provenance, дополнительный файл.
6. Объединить PR #746 только при полном CI и проверенном происхождении артефактов. Запустить существующую изолированную SSH-публикацию `deploy-remix-arena-static.yml` с предусмотренными rollback/health-check. Неполная публикация => вернуть R48.
7. Отдельным доверенным CI из публичного HTTPS загрузить четыре файла и сверить их Git blob хеши с финальным манифестом R49 (4/4 exact), HTTP статусы и версию allowlist. Записать ссылки на запуски, commit SHA, результат отката и непроверенные физические устройства.

**Условие заявления «R49 опубликована»:** необходимы успешный production SSH, успешная независимая HTTPS 4/4 parity и явно зафиксированная граница mobile/physical QA. Просто зелёный PR, 200 OK или локальный Web экспорт недостаточны.

## Проверка игроком после подтверждённого выпуска

- Купить/выбрать существующих ведомых в гараже, запустить вылет и переключить `C` / экранную кнопку между тремя приказами; сравнить реальные позиции и огонь.
- Убедиться, что отсутствие ведомых скрывает командную кнопку.
- В миссии №11 попробовать подлететь только к старому маяку: не должно засчитать прохождение.
- Найти все три терминала, удержать `T` или кнопку на экране, выйти из радиуса во время удержания и вернуться; прогресс не должен начисляться издалека.
- Выпустить лазер или настоящую ракету в скрытой миссии: провал, без кредитов и XP.
- Полностью завершить расследование: награда однократная; сохранения первых десяти миссий, владение кораблями, баланс и возможность повторного входа сохраняются.
