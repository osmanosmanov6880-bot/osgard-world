# OSGARD NEBULA — R40: аппаратная приёмка без выдуманных FPS

**Статус:** R38 — серверный эталон; R40 — экспериментальная сборка из PR #342.
Этот документ не подтверждает, что испытания телефонов уже выполнены.

## 1. Что именно проверяем

Гипотеза R40: 96 отдельных трёхмерных светильников мостов можно отрисовать
тремя MultiMesh-группами без изменения физики, расположения объектов и их
видимого качества. Снижение числа объектов рендеринга в исходном коде само по
себе **не означает**, что реальный телефон стал быстрее.

## 2. Где взять обе игры

- R38, серверный эталон: `https://osgard.world/games/remix/arena-v2/nebula-3d/`.
- R40, кандидат: PR #342 → Actions → последний **успешный** запуск
  «REMIX NEBULA 3D native Web release» → архив
  `nebula-r40-on-device-candidate`. Не путать с устаревшими архивами:
  новый JSON должен иметь `build_variant=NEBULA_R40_BRIDGE_BATCH_3X32`.
- Локальная лаборатория сравнения: 
  `https://osgard.world/games/remix/arena-v2/nebula-3d/performance-report.html`.

Распакуйте R40 на **доверенном** компьютере и обслуживайте через HTTP(S),
а не `file://`. На закрытой локальной сети (находясь в папке распакованной игры):

```powershell
py -3 -m http.server 8765 --bind 0.0.0.0
```

Откройте с телефона адрес компьютера в этой локальной сети, порт 8765.
Ограничьте доступ межсетевым экраном. Не открывайте публичный доступ к тестовому
серверу без HTTPS и контроля доступа. С телефона обычный `localhost` указывает
на телефон, а не на компьютер.

## 3. План замеров

Используйте минимум 3 физических телефона: 2 Android (один слабее), 1 iPhone.
Для каждого запишите **анонимную** метку `android_low`, `android_mid`,
`iphone_safari`. Не записывайте IMEI, персональные идентификаторы и координаты.

Для каждого телефона:

1. Проверьте управление полётом, коллизии мостов и все светильники на R38 и R40.
2. Сделайте реальные исходные снимки экранов R38/R40 в портретной и альбомной
   ориентациях. Инженер должен проверить, что нет пропавших огней, чёрных
   областей, неверных масштабов и препятствий.
3. В каждой ориентации проверьте MAX, HIGH, ECO. На каждой сборке сделайте
   **не менее 3 отдельных измерений по 20 секунд** с одинаковым маршрутом.
4. Не меняйте разрешение, масштаб интерфейса, энергосбережение и условия
   зарядки между сравниваемыми сериями. Фиксируйте нагрев, прерывания и
   отключение фоновых приложений. Запрещено измерять в AUTO.
5. Экспортируйте оригинальные JSON из игровой панели FPS, не переписывая
   показатели. Сохраните файлы локально.

Минимум: 3 телефона × 2 ориентации × 3 профиля × 2 сборки × 3 повтора =
**108 оригинальных JSON** и **12 настоящих снимков**.

## 4. Автоматическая проверка доказательств

Скопируйте `docs/nebula/R40-DEVICE-FIELD-MANIFEST.example.json` в свою
папку доказательств и назовите `manifest.json`. Заполните пути к исходным
JSON, изображениям, полям `reviewer`, `visual.*.notes` и отметкам
`visual.*.approved` только после реальной ручной проверки.
Поставьте `field_work: true` только после окончания всей кампании.

Из корня проекта выполните:

```powershell
node scripts/nebula-r40-field-release-gate.mjs C:\NEBULA_QA\manifest.json
```

Программа ничего не отправляет на сервер. Она читает только выбранную локальную
папку, проверяет источник сборки, профиль и ориентацию, дубликаты и качество
измерений. При неполных данных или регрессии отказывает с ошибкой
`NEBULA_R40_FIELD_NOT_APPROVED`.

Примерная матрица *не заполнена* и должна проваливать тест:

```powershell
node scripts/nebula-r40-field-release-gate.mjs docs/nebula/R40-DEVICE-FIELD-MANIFEST.example.json
```

## 5. Окончательное решение

Даже успешная локальная автоматическая проверка **не может подтвердить**
подлинность телефона, фотографий и правдивость заполненных показателей.
Требуется ручное заключение инженера с просмотром оригиналов на физических
устройствах. Если хотя бы одна комбинация нестабильна, есть регрессия FPS/P95
или визуальный дефект, PR #342 остаётся вне production.

Не смешивайте тесты Chromium/SwiftShader, синтетические CI-фикстуры и
реальные аппаратные FPS. Хороший релиз должен быть красивым **и** измеренным.
