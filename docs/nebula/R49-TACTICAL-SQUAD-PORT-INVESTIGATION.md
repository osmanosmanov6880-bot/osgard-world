# NEBULA R49 — реализованный кандидат, не production

Дата: 2026-11-05. PR: #745. Ветка: `feature/nebula-r49-wingmen-port-investigation-20261105`.

## Реальный игровой код

- `fleet_combat_r15.gd`: `follow` (построение с пилотом и защитный огонь до 90 м), `attack` (поиск цели до 240 м, ускоренное движение к противнику, стрельба только из реального радиуса), `defend` (кольцо вокруг гражданского конвоя / игрока, огонь в радиусе защиты). Приказы имеют реальное влияние на позиции и получаемый противником урон. Купленные ведомые не создаются без серверного права / кредитной покупки.
- `world.gd`: кнопка «ВЕДОМЫЕ», переключение по `C` на компьютере или касанием, уведомление о приказе. Без купленных ведомых кнопка скрыта. В гараже команды не выдаются.
- `port_investigation_r49.gd`: три настоящие процедурные 3D-панели с самостоятельными радиусами доступа; игрок должен по очереди добраться до каждой и удерживать `T` / кнопку «УДЕРЖИВАТЬ · ВВОД» не менее двух секунд. Дистанционная активация и прохождение по старому маяку запрещены. Выстрел активирует тревогу и провал.
- Новая миссия 11 «Тени порта», награда 3200 CR до модификатора капитана. Отдельные события обнаружения доказательств, HUD, навигация и радар.
- Миссии 1–10 остаются в прежнем порядке с прежними наградами; файл сохранения остаётся `version:1`. Сохранённый `mission=10` теперь открывает новую 11-ю миссию, а `mission=11` завершает актуальную кампанию.
