# NEBULA R46 — реальное сравнение техники и боеготовность

Дата: 2026-11-05. Статус: R46 опубликована и подтверждена публичной сверкой 4/4 игровых файлов 2026-11-05. Физический телефон не проверен.

## Что меняется для игрока
- После выбора NX-08 / NX-12 / NX-21 в ангаре видна краткая **БОЕГОТОВНОСТЬ**: тип оружия, рассчитанный реальный урон, число ракет, количество ведомых из двух разрешённых, уровень двигателя. Всё поступает из действующего Godot `world.gd`, а не из демонстрационных чисел.
- Вместо перегруженного экрана по умолчанию есть одна кнопка **СРАВНИТЬ ТЕХНИКУ**. Она раскрывает строки трёх кораблей, в каждой — корпус, щит, скорость разворота и статус владения. Повторное нажатие скрывает таблицу.
- Недоступный корабль остаётся закрытым в R45. Сравнение никогда не списывает CR, не изменяет права premium, не активирует вылет и не выпускает оружие.

## Единый источник характеристик
`scripts/fleet_combat_r15.gd` содержит `SHIP_PROFILES`. Это тот же словарь, из которого боевой движок берёт `turn_speed`, `ship_hull_cap` и `ship_shield_cap`:
| Корпус | Hull HP | Shield HP | Разворот (рад/с) |
|---|---:|---:|---:|
| NX-08 Scout | 100 | 100 | 1.9 |
| NX-12 Interceptor | 100 | 100 | 2.4 |
| NX-21 Guardian | 160 | 140 | 1.5 |

Здесь **не обещается другая максимальная скорость**, поскольку в текущем `ship.gd` лимит скорости общий для кораблей. Физические коллайдеры остаются одинаковыми после R45 во избежание коллизий в существующем городе.

## Изменения
- `fleet_combat_r15.gd`: одна таблица игровых параметров вместо трёх независимых условных операторов.
- `world.gd`: передаёт UI рассчитанные на текущем корабле показатели вооружения и три профиля.
- `garage_hub_r39.gd`: раскрываемое сравнение + компактная боевая готовность внутри уже существующей карточки техники.
- `tests/runtime_smoke.gd`: строгая проверка реальных данных, скрытия сравнения по умолчанию, отсутствия списания CR/разблокировки кораблей/случайного начала вылета.
