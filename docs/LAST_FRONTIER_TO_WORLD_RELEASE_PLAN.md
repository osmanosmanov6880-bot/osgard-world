## Permanent engineering quality gates for EVERY big block
1. New functionality is integrated into the **real Godot source and playable scene**. Marketing images never count as code.
2. Freeze exact baseline Git SHA, permit narrowly specified changed files, fail on unexpected protected physics/mission edits.
3. Native Godot import + complete old and new unit/scene acceptance; browser actual WASM/PCK + source UI events, no JS fake game mutations.
4. Produce true original stage frames with recorded bytes and SHA-256; inspect 320/390/844 and physical devices when available.
5. Run automatic tests to completion, report actual green/red result and artifact links; leave Draft until gate green.
6. Never claim actual phone testing, paid production AAA art, licensing, human completion or global readiness without appropriate evidence.

## Risks and constraints
- Original technical source baseline is a **working vertical slice**, not proof of a commercial AAA game.
- Large scale game art, level design, audio, rights, performance and playtests will be significant work; there is no credible deadline without budget, team/capacity and supported device targets.
- Automated mission tests may teleport the **unit test player only** to isolate equipment logic. Real game and browser/human E2E acceptance MUST never use that shortcut.
- Keep the original W63–W84 game and live deployment untouched until explicit release approval; review every PR separately.
