# INHERIT — R2: завершение инженерного плана развития мира

Дата: 20.10.2026  
Статус этого документа: релизный чек-лист. Не является свидетельством опубликованного кода или спроса; фактические результаты CI/деплоя см. по конкретному SHA GitHub Actions.

## Что построено

### Игровая глубина
- **16 вариантов событий поколений.** Событие задаётся `generation % 16`, имеет два варианта предмета, реагирует **только на новый реально размещённый объект** в `pending` текущей генерации. До размещения событие не считается выполненным. После завершения поколения эпизод сменяется.
- **Отмеченные последствия.** Новый декоративный эффект появляется в фактических координатах размещённого объекта; событие не выдаёт новых очков, преимуществ, собственности или серверных фактов.
- **4 художественных сезона** (прилив, солнце, ветер, туман), зависящих от номера поколения, а не от реальной погоды.
- **4 стадии острова** (нетронутый, оживающий, связанный, древний). «Древний» требует возраста, подтверждённого снимками прошлых поколений, а не субъективного описания.
- **12 открытий** считаются по подтверждаемым сохранённым объектам и сочетаниям. Нет фиктивного прогресса от чтения подсказок.
- **4 бесплатных визуальных оформления:** ночной берег, изумрудная роща, северное сияние, золотые руины. Три дополнительных варианта разблокируются достижениями; никаких платных преимуществ.

### Возвращения и приватность
- Дневник возвращений **по умолчанию выключен**.
- Активация только после явного нажатия игрока. На устройстве хранятся даты визитов (максимум 30 последних дат) и числовые характеристики местного мира: номер поколения, количество предметов, связей и открытий.
- При возвращении на следующий день сравниваются два местных снимка. Сообщение НЕ утверждает, что предмет добавил другой человек или что изменение произошло именно в течение определённого часа.
- Возможность полностью отключить и удалить дневник одной кнопкой. Нет наказаний за пропущенные дни, скрытых уведомлений, персональных идентификаторов, серверной отправки, подписок или реального денежного оборота.
- При отказе браузера в записи система сообщает, что данные не сохранятся после закрытия вкладки.
- Дневник отключён для аккаунтных миров, чтобы не смешивать чужие сохранения и приватную статистику.

### Инженерная совместимость
- Не меняется JSON-схема сохранений `inherit-world-v1`.
- Не меняются серверные API, SQLite и механизм подтверждения перехода поколения.
- Графика не перехватывает мышь и клавиатуру на игровом острове, учитывает `prefers-reduced-motion` и облегчённый режим.
- Действия без разрешения в account mode остаются недоступны.
- Одинаковое наполнение на русском, английском и упрощённом китайском.
- PWA включает новые файлы в оболочку `inherit-shell-v14`.
- Визуальные украшения, исторические главы и итоги событий явно помечены как художественная интерпретация, **не** как подтверждённые серверные действия.

## Принцип честной аналитики

Этот релиз НЕ создаёт серверную воронку отслеживания и НЕ доказывает D1, D7, D30, CAC, платёжную конверсию или LTV. Имеющиеся локальные игровые метрики не превращать в показатель реальных пользователей. Для дальнейшего исследования интереса нужны добровольные игроки, явное согласие на аналитику и отдельная безопасная инфраструктура.

## Запуск проверок

```sh
npm ci
npm run qa:inherit-world-cycle
npm run qa:inherit-story
npm run qa:inherit-legacy
npm run qa:inherit-i18n
npm run qa:inherit-handoff
npm run qa:inherit-account
npm run qa:game-interface
npm run build
npx playwright test --config playwright.ecosystem.config.mjs scripts/ecosystem-browser.spec.mjs
```

Проверки должны завершиться успешно на конкретном релизном SHA, в том числе Chromium desktop/mobile. На production-деплое использовать обязательные smoke-тесты `deploy-frontend.yml`, не обходя rollback при ошибке.

## Ручное приемочное тестирование

1. Открыть `/games/inherit/`, войти в «Наследие». В начальном поколении 173 событие «Сигнал в тумане».
2. Выбрать фонарь через карточку события; установить его на остров клавишей Enter или мышью. В карточке должно появиться подтверждение, а на острове — световой отпечаток в точке объекта.
3. Переключить RU → EN → 中文; событие, цели и достижения переводятся, объект не пропадает.
4. Завершить поколение штатной кнопкой; старый объект остаётся, событие меняется, старый результат не засчитывается как новый.
5. Проверить мобильную ширину 360–430 px, фокус клавиатуры, отсутствие горизонтального переполнения и «экономный режим».
6. В локальном режиме открыть дневник; до согласия данных нет. После включения увидеть только даты и числа. Проверить сообщение после нового календарного дня. Удалить и убедиться в отсутствии ключа.
7. В account mode без прав хранителя кнопки размещения событий отключены; дневник локального мира недоступен.
8. Визуальные варианты не должны менять бюджет, историю сервера, авторство или игровые права. При отсутствии необходимого достижения вариант заблокирован.
9. Сохранение, экспорт, импорт, восстановление повреждённого архива и отказ LocalStorage должны не блокировать базовую игру.
10. Действия и контент не должны ложно утверждать присутствие игроков или подтверждение событий сервером.

## Что остаётся вне объёма одного инженерного релиза

**Бизнес-гипотезы и реальное удержание.** Отдельный 90-дневный план из `docs/INHERIT_PRODUCT_COMMERCIAL_AUDIT_2026-10-20.md` требует времени, тестов с добровольцами, сравнения цен и анализа реальных метрик. Отметка «код готов» не означает «коммерциализация доказана». Не включать реальные платежи без отдельного платежного дизайна, правовых условий, механизмов возврата и подтверждённого спроса.

**Фотореалистичная AAA 3D-игра.** Текущая INHERIT остаётся стилизованной браузерной игрой. Перевод на Godot/Unreal, производство моделей, анимаций и фотореалистичных локаций — иной по объёму проект; такой результат здесь не заявляется.
