### Условия перехода к следующему этапу

1. Все пять CI-задач интеграционного PR (четыре специализированных и общий набор), а также проверки frontend/release должны завершиться успешно.
2. Независимый reviewer должен проверить реальный контракт `commit_sha`, состав свидетельств и угрозы подмены ссылок. Сегодня unified gate проверяет **форму** JSON и HTTPS-ссылок, не запрашивает GitHub API для аутентификации проверок.
3. Выполнить настоящую копию и восстановление **на отдельном сервере**, подтвердить работоспособность приложения и журнал восстановления. Локальные синтетические тесты этого не заменяют.
4. Выполнить тестовую публикацию по staging URL, проверить основные страницы, 19 игр, ошибки API, скорость загрузки, откат и отсутствие раскрытых ключей.
5. Только после этого согласовать с оператором безопасное слияние и деплой.
