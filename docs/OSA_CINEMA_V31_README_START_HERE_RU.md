# OSA CINEMA V31 — кабинет владельца, приватная приёмка RU/EN

**Эта программа не публикует фильм.** Она проверяет ваши четыре MP4 и четыре WebVTT на компьютере и создаёт технические протоколы. Публичный запуск и оплата остаются заблокированными до настоящих прав, редакторских подписей и production-приёмки.

## Быстрый запуск на Windows

1. Установите Node.js 22 и FFmpeg (включая ffprobe); проверьте команды `node --version`, `ffmpeg -version`, `ffprobe -version`.
2. В отдельной закрытой папке подготовьте `masters/` с четырьмя финальными кандидатами MP4 и `captions/` с четырьмя WebVTT. Точные имена смотрите в `docs/OSA_CINEMA_V31_OWNER_CONTROL_ROOM_RU.md`.
3. Создайте вторую отдельную папку для отчётов (не внутри папки с фильмом).
4. Из корня распакованного пакета запустите `powershell -ExecutionPolicy Bypass -File .\launchers\RUN_PRIVATE_OWNER_CONSOLE.ps1` (если политика безопасности организации разрешает такой запуск). Альтернатива без изменения политики — открыть скрипт и выполнить описанные команды вручную.
5. Введите две локальные папки и новый пароль. Терминал выведет адрес `http://127.0.0.1:PORT`. Откройте его на **том же компьютере**, войдите с паролем, нажмите «Запустить полную проверку» и скачайте отчёты.

Никаких материалов в GitHub/облако программа не загружает. Хеши отчётов запоминаются в работающем процессе; если файл отчёта после завершения изменён, его выдача блокируется. Программа работает только пока открыт терминал. Не выкладывайте PDF-договоры, ключи и исходные MP4 в публичный репозиторий.

## Запуск вручную

```powershell
$env:OSA_CINEMA_OWNER_CONSOLE_PASSWORD = Read-Host 'Новый приватный пароль (16+ символов)'
node scripts/osa-cinema-v31-owner-console.mjs --root 'D:\OSA_PRIVATE\film' --reports-root 'D:\OSA_PRIVATE_REPORTS' --originals 'docs/OSA_CINEMA_V16_WORKPRINT_MANIFEST.json'
```

Проверку восьми подписей можно включить **только после** реального заполнения владельцем реестра прав, заморозки SHA-256 и независимого предоставления публичных ключей. Полная команда и все шесть дополнительных параметров — в `docs/OSA_CINEMA_V31_OWNER_CONTROL_ROOM_RU.md`.

## Проверка инженерного комплекта

```bash
node --test --test-concurrency=1 scripts/*.test.mjs
```

Тесты генерируют **только синтетические** изображения, аудиопотоки и PDF-тексты. Ни один реальный фильм не вложен в пакет. Отдельная GitHub CI запускает также настоящий Chromium на 1440 px и 390 px; её результат нужно подтвердить до слияния кода.
