# INHERIT R6 — Атлас поколений (read-only playable world archaeology)

**Раздел:** /games/inherit/  
**Статус:** исходный код готов к PR/CI; окончательная публикация подтверждается только успешным GitHub production workflow.  
**Назначение:** дать игроку ощутить реальное развитие острова между поколениями, а не только читать абстрактные цифры или обещания других игроков.

## Реализовано

1. **Атлас поколений:** кнопка в интерфейсе игры. Для каждого доступного снимка выводится его настоящий номер поколения и источник («снимок» или «текущее состояние»). Если нет двух различных состояний — объясняется, как получить первый настоящий снимок. Игра не добавляет декоративные «прошлые поколения» для заполнения пустоты.
2. **Пара для сравнения:** игрок выбирает «Было» и «Стало». Можно сравнивать завершённые снимки друг с другом или архивный снимок с текущим миром (включая его незавершённые действия). Сравнение не передаёт поколение автоматически.
3. **Арифметика следов:** точное количество появившихся, исчезнувших и сохранившихся объектов; чистое изменение количества; изменение каждого типа (деревья, тропы, камни и т.д.). Повторяющиеся следы в одинаковой координате учитываются как отдельные экземпляры, а не теряются внутри множества.
4. **Наглядная мини-карта:** отмечает новые (золото), исчезнувшие (коралловый) и сохранившиеся (зелёный) следы. Отображение ограничено 220 точками, чтобы большой остров не перегружал телефон; **итоговые счётчики** вычисляются по всем проверенным объектам, а ограничение визуализации объясняется на экране.
5. **Русский, английский, китайский:** названия предметов, подписи статистики, кнопки, пояснения и пустые состояния. Учитываются переключение языка, клавиатура, Escape и системный режим уменьшения движения.
6. **Полная пассивность:** атлас использует копию \`window.InheritGame.snapshot()\`. Никаких новых покупок, запросов к API, \`localStorage\`, модификаций \`InheritGame.apply\`, \`saveDraft\`, изменения координат, бюджета или прав аккаунта.

## Источники истины и ограничения

Единственный источник — сохранённые \`world.snapshots[].objects\` и \`world.objects\`, а не рассказ сервера об авторе или несуществующем посетителе. Номер поколения — поле сохраняемого мира. Дата и автор не выводятся, поскольку старые локальные снимки могут не иметь проверенной серверной подписи.

Валидируются десять известных типов следов, конечные координаты 0–100 и поколения целых неотрицательных значений. Некорректные/будущие/дублированные снимки не превращаются в новые записи. Предел обработки: 10 000 объектов на кадр и последние 160 архивных кадров. Если архив был урезан, интерфейс сообщает об ограничении; полную историю из него не восстанавливает.

При сравнении используются тип и координаты с точностью до 5 десятичных знаков. Перемещение считается как исчезновение старого и появление нового объекта, **не как доказанное движение**, которого могло и не быть. В реальном игровом мире текущие незавершённые действия ещё не обязательно переданы следующему поколению.

## Как проверить игроку

1. Открыть \`https://osgard.world/games/inherit/\` в локальном мире. Нажать **«Атлас поколений»**.
2. Если сохранённых снимков недостаточно, увидеть правдивое объяснение — без вымышленных прошлых поколений.
3. Выбрать дерево и реально поставить его на остров, затем передать поколение существующей игровой кнопкой.
4. Снова открыть атлас. Сравнить архивный снимок и текущее состояние; проверить числа «Новых», «Исчезло», «Сохранилось» и мини-карту.
5. Закрыть диалог клавишей Escape, переключить язык на английский или китайский, открыть снова.
6. Убедиться, что бюджет и сохранение не меняются **в результате открытия, просмотра или выбора поколений в атласе**. Обычный игровой ход, сделанный в пункте 3, разумеется, сохраняет реальные изменения.

## Инженерные проверки

\`\`\`sh
npm run qa:inherit-atlas
npm run qa:inherit-world-cycle
npm run qa:inherit-research
npm run qa:inherit-pilot-launch
npm run qa:inherit-followup
npm run build
\`\`\`

Playwright дополнительно проверяет настоящий игровой ход, обновление атласа после передачи, его режим без архивов, Escape, отсутствие записи при открытии и RU/EN/ZH. CI требует и существующие бизнес-правила сохранений, а post-deploy проверка сверяет точные байты \`generation-atlas-core.js\`, \`generation-atlas.js\`, \`generation-atlas.css\` с активированным релизом.

## Что остаётся вне R6

Это визуализация уже сохранённых поколений, а не AAA-полноценный движок фотореалистичной 3D-симуляции и не доказательство мультиплеерного авторства. Для таких задач потребуются отдельные ассеты, оптимизированная сцена, рендерер/Godot/WebGL, серверно подтверждённая история действий и их самостоятельные тесты. Также атлас не собирает настоящих участников пилота и не заменяет 90-дневную проверку спроса.

**Следующие продуктовые гипотезы:** показать «момент наследования» в игровом мире при реальной смене поколения, улучшить взаимодействие с объектами и дальнейшую исследовательскую воронку на основании реальных игроков, а не синтетической «активности».
