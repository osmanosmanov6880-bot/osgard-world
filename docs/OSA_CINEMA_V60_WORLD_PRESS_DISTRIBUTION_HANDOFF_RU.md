# OSA CINEMA V60 — WORLD PRESS / DISTRIBUTION INTEGRITY

Дата разработки: **29 октября 2026**. Ветка: `feature/osa-cinema-v60-world-press-distribution-20261029`. Статус: **код-кандидат, не публичная видеопремьера**.

## Система I — международный пресс-центр с работающим интерфейсом

- `/osa-cinema/studio/press`: отдельная премиальная, адаптивная, доступная с клавиатуры страница с переключением RU/EN.
- Три реальные записи исходного редакционного каталога: браузерный интерактив THE NEXT HUMAN; незавершённый фильм ZERO WINDOW (0/13 отснятых сцен); владельческий локальный концепт-превиз THRESHOLD (160 сек).
- У каждой записи есть оригинальный локальный WebP, описание, фактическая стадия, ссылки на производственное досье и источники.
- Сравнение проверяемых этапов: документировано / требует проверки / заблокировано; раскрывающиеся панели с объяснением каждого решения.
- Сборка экспортирует **три настоящих файла** в `dist/osa-cinema/studio/press/`: `press.v1.json`, `press.ru.txt`, `press.en.txt`.
- Генератор `scripts/osa-cinema-v60-press-kit.mjs` читает единый TypeScript-каталог, производственный акт V53 и фиксированные независимые гейты. Изменение ключевых фактов приводит к отказу сборки, а не к публикации ложной информации.
- Пресс-центр включён в публичную sitemap, имеет отдельный статический HTML, canonical, OpenGraph. Персональные данные, доступы, токены, закрытые видеомастера и релиз-энтитлменты туда не попадают.

## Система II — локальный кабинет готовности к дистрибуции

- `/osa-cinema/studio/distribution`: приватная по назначению страница *без серверной авторизации* с прямой загружаемой HTML-оболочкой, `noindex,follow` и отсутствием в sitemap.
- Реальный immutable-сводный статус независимых ворот по двум проектам: 8 по ZERO WINDOW и 5 по THRESHOLD. Факты берутся из V53: 0 снятых актёрских сцен, независимая проверка прав отсутствует, публичное HTTPS-воспроизведение не подтверждено, безопасность не очищена.
- Разрешены только **локальные плановые** отметки: `not_started`, `preparing`, `review_requested`. Последний статус не отправляет письма и не является фактом реальной подачи документа.
- Отдельный безопасный ограниченный JSON-формат резервных копий с версией, идентификатором проекта, размером до 32 KiB, валидацией ISO-времени и строгим отказом в импорте, если файл пытается подменить `releaseAuthorized` или `publicVideoUrl`.
- Локальное хранение и синхронизация между вкладками без сервера. Нельзя использовать для секретов, юридически значимых утверждений или персональных данных.
- Никакие пользовательские отметки не меняют `publicReleaseDecision`, реестр фильма, первичный V53, медиа-гейты V42/V49/V50 и не разрешают показ.

## Система III — реальные автоматические проверки

- `scripts/osa-cinema-v60-world-contract.test.mjs`: проверки правды, приватности и невозможности fake release; строгий press kit и RU/EN текстовые файлы.
- `scripts/osa-cinema-v60-build-preflight.mjs`: проверка реальных `dist` файлов, метаданных, Sitemap и запрета `VideoObject`.
- `scripts/osa-cinema-v60-world.spec.mjs`: Chromium desktop/mobile/320px: навигация из досье, пресс-центр, JSON + TXT скачивание, RU/EN, пользовательские заметки, cross-tab, экспорт/импорт, отклонение forged release, отсутствие горизонтального переполнения.
- Workflow `.github/workflows/osa-cinema-v60-world.yml` защищает TypeScript, сборку, 95 KiB бюджет главной страницы и старые контракты V55–V59, сохраняя снимки настоящего браузера.
- **Не заявлять PASS**, пока exact-head GitHub Actions не завершит проверки.
