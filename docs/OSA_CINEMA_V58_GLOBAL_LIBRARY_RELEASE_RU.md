# OSA CINEMA V58 — WORLD LIBRARY / PUBLIC CATALOGUE
**Дата:** 28 октября 2026. **Статус:** кандидат кода в отдельной ветке до независимых CI и объединения с master.

## Продуктовые возможности, реально добавленные в исходники
- Публичный двуязычный кинокаталог и существующие три страницы проектов V57 сохранены, новый адрес `/osa-cinema/studio/library` создан как самостоятельная тёмная responsive-страница.
- Избранное работает через единый `src/osaCinemaWatchlist.ts`: безопасная нормализация известных slug, синхронизация между вкладками, обработка отсутствующего localStorage, без учётных записей и без отправки данных на сервер.
- В библиотеке реализованы **сохранение, удаление, двухшаговая очистка, локальный экспорт JSON и строгий импорт**. Импорт заменяет старый список только после полной проверки формата, версии, размера 16 KB, идентификаторов и доступности хранилища. Ошибки не стирают текущий список.
- Каталог и страницы фильмов ссылаются на библиотеку. `OSAStudioContinue` продолжает существующую 8-сценную интерактивную историю по реальному сохранённому прогрессу OSA.
- Библиотека персональна, поэтому статическая HTML-оболочка и динамические метаданные маркированы `noindex,follow`. Её нет в публичной sitemap.

## Международный каталог для интеграций
- Сборка сайта генерирует `dist/osa-cinema/studio/catalog.v1.json` **только из типизированного редакционного реестра**, без повторного ручного списка. Языки RU/EN; поля title, description, статус, URL досье и согласованная сводка производственных этапов.
- JSON-каталог публичен по архитектуре; он не является API авторизации, не содержит ни личных списков, ни токенов, ни закрытых медиа и не включает streaming-ссылки.
- Поля `publicVideoAvailable=false`, `publicVideoUrl=null`, `publicPremiereClaimed=false` сохраняют реальный статус незавершённых фильмов.
- `scripts/osa-cinema-v58-public-catalog.test.mjs` и `scripts/osa-cinema-v58-build-preflight.mjs` проверяют целостность, строгие права, реальные файлы и `noindex`.

## Реальная приёмка
- Отдельный workflow `OSA CINEMA V58 Global Library and Public Catalogue` проверяет TS, build, 95 KiB лимит, старые V42/V53/V55 контракты, отсутствие ложной медиапремьеры, восстановление списка и реальные браузерные маршруты на двух размерах.
- Playwright `scripts/osa-cinema-v58-library.spec.mjs`: desktop/mobile, RU/EN, сохранение, удаление, экспорт, импорт, неверный файл, синхронизация соседней вкладки, отсутствие горизонтального переполнения и получение `catalog.v1.json`.
- Результаты тестов и скриншоты считаются проверенными **только после** успешного exact-head GitHub Actions. Не использовать скриншоты предыдущей версии как доказательство V58.

## Незавершённые зависимости
1. PR #641 (V57) — финальный merge после успешных проверок; новая V58 ветка основана на V57 и не должна обходить этот рубеж.
2. PR V58 — отдельная независимая приёмка, затем merge в master.
3. Проект OSA CINEMA в production на HTTPS — отдельно проверить успешный фактический деплой после merge и приложить реальные HTTP-ответы.
4. Видео: ZERO WINDOW не снят; THRESHOLD локальный концепт-превиз. Ни готовый фильм, ни публичные медиаправа не объявляются подтверждёнными. Публикация фильмов остаётся NO_GO.
5. Для глобального масштабирования в дальнейшем потребуются защищённый редакционный backend, разные каналы дистрибуции, законный контент, языковая редактура и нагрузочные испытания. Они НЕ входят в V58.

**Главный принцип:** опубликованный каталог/JSON ≠ публичная премьера/стриминг.
