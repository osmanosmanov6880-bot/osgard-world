# OSA CINEMA V41 — рабочий кинематографический кабинет владельца

Дата: 26 октября 2026. **Статус фильма: NO-GO.**

## Что действительно изменено

V41 — обновление визуального слоя реального V39/V40 локального кабинета, без копии-макета. В `scripts/osa-cinema-v39-owner-desk.mjs` функции экрана входа и основной панели переведены на `scripts/osa-cinema-v41-owner-ui.mjs`. HTTP-сервер, привязка к 127.0.0.1, ограничение Host/Origin, пароль, сессии, CSRF, правила MIME/CSP, тайм-аут, отмена V40 дочернего процесса, белый список статуса и выдача NO-GO отчёта **не изменены**.

Интерфейс предоставляет: брендированный экран входа, адаптивную левую навигацию, графически оформленную головную панель, четыре счётчика реальной технической проверки, запуск существующего V38-аудита, живые состояния idle/running/completed/failed, ссылки на отчёт только после успеха, четыре отдельные версии RU/EN трейлера/полного фильма как **метаданные**, семь внешних блокировок выпуска и кнопку выхода.

Декоративная оптика и визуальные карточки созданы чистым локальным CSS. В реальном коде нет поддельных кадров, постеров, стоковых изображений, скачиваемых шрифтов или новых внешних запросов. Медиапросы: ПК, планшет, телефон, уменьшенные анимации. Якорные разделы работают в браузере, основные кнопки используют прежние защищённые API.

## Запуск

- Windows: из корня актуального репозитория `START_OSA_CINEMA_V41.cmd`.
- macOS/Linux: `sh ./START_OSA_CINEMA_V41.sh`.
- Оба стартовых скрипта проверяют наличие модуля V41, затем передают запуск существующему V40 -> V39 защищённому мастеру; требуется Node.js 22+, FFmpeg и закрытые исходники владельца.
- Страница открывается исключительно на `http://127.0.0.1:<локальный-порт>` по локальному паролю.

## Проверки

1. Профильные тесты V41: статические HTML/CSS/JS контракты, безопасный вход, семантика, responsive, отсутствие внешних медиа и публичного релиза.
2. Регрессия V39: реальная авторизация, CSRF, сессии, закрытие, запрет путей и выдачи MP4, безопасный NO-GO отчёт.
3. Регрессия V40: отмена дочернего процесса, отсутствие передачи пароля, тайм-ауты, запрет позднего успеха.
4. Синтетический интеграционный V29: настоящий FFmpeg и V38 на специально созданных тестовых четырёх MP4 + четырёх WebVTT. Не подменяет настоящую редакционную приёмку.
5. Визуальное QA: скриншоты исходного HTML/CSS, полученного через настоящий локальный сервер и защищённый вход; 1440px, 810px, 390px, без горизонтального переполнения.
