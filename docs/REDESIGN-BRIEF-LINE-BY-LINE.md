## Проверки и артефакты

- `npm run qa:redesign`: модель коллекции, наличие игровых файлов, контракты доступности/движения и серверный рендер новых страниц.
- `npm run qa:redesign-build`: метаданные оболочек, PNG-превью, восемь пар контраста, отсутствие Three.js и старого CSS в графе трёх главных.
- `docs/REDESIGN-BUILD-AUDIT.json`: фактические размеры gzip и графы зависимостей сборки.
- Проверки сохранённого OSA Learning: Академия, лекции, прогресс, проекты, мастерская, эксперименты и медиаплеер.
- Полная Cloudflare-проверка по-прежнему требует отсутствующего Godot-экспорта. Это ограничение пакета, а не повод рисовать неработающую кнопку.

Приёмка остающихся пунктов должна выполняться на настоящем браузере и устройствах. Эти строки не отмечены завершёнными только на основании наличия CSS или успешной сборки.

## Следующий проход: надёжность и передача сборки

| Работа | Результат | Проверка |
|---|---|---|
| Единая резервная копия | `/data`: шесть выбранных разделов, JSON, предпросмотр и восстановление | Положительные и отрицательные тесты формата |
| Отделение пользовательских данных от токенов | Экспорт работает только с разрешённым списком ключей | Тест неизвестного ключа и отсутствия токена в копии |
| Ошибка при восстановлении | Проверка конфликта, попытка отката; отдельное предупреждение при частичном откате | Инъекция отказа записи и отказа отката |
| Настоящие 404 | Отсутствующие страницы, файлы и API больше не получают главную с кодом 200 | HTTP-проверки пяти отрицательных адресов |
| Старые React-маршруты | Дополнительные HTML-оболочки вместо общего fallback | Проверка sitemap и существующих файлов |
| Старые ссылки NULL//SHIFT | Ведут на объяснение недоступности, а не на отсутствующий экспорт | Исходные ссылки и отключённая кнопка |
| Пакет для статического хостинга | Отдельный ZIP с index.html в корне, без исходников | ZIP CRC, наличие файлов и лимиты размера |
| Контроль целостности | release-manifest.json и VERIFY.py | Сравнение SHA-256; это не подпись издателя |
| Явные ограничения выпуска | RELEASE-REPORT.json со статусами браузерной проверки, сервисов и недоступных функций | Проверка отдельного профиля static-redesign-preview |

Этот статический профиль не отменяет первоначальный gate полного игрового выпуска: Godot Web-экспорт по-прежнему отсутствует. Проверка на настоящем браузере, реальные скриншоты и полевые Core Web Vitals остаются открытыми.

## Проход по интерфейсным состояниям

Подробная сверка автоматических и ручных проверок: `REDESIGN-UX-ACCEPTANCE.md`. Браузерные пункты остаются открытыми.

## Продолжение: производительность

Учебный реестр отделён от полных текстов. JavaScript главной OSA: 98 695 → 86 203 байта gzip (−12,7%). Для трёх главных установлен бюджет 95 КиБ gzip и запрет подключения полных уроков/3D. Подробности: `REDESIGN-PERFORMANCE.md`. Браузерные и полевые показатели не измерялись.

## Серверный пилот экосистемы

Добавлен `/workspace` и отдельный запуск Core: аккаунты, роли, версии, учебные отметки, HTML-прототип, очередь проверок, внутренний выпуск, предложения, расходы, наблюдения и шаблоны. Подробная граница реализации — `ECOSYSTEM-PLAN-ACCEPTANCE.md`; запуск и восстановление — `CORE-PILOT.md`. Статический ZIP сервер не включает. Реальная оплата и коммерческий E2E не выполнены.
