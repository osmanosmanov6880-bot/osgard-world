# OSGARD — 5 WAVE интеграционной разработки

**Состояние:** новая кодовая ветка; не означает, что сайт обновлён на production.  
**База:** проверенная шестисекционная версия PR #181, commit `00f0d0a931e6dc0061aef8ef839e6d6f2e1ba25e`.  
**Граница безопасности:** не меняет `master`, Core API, аккаунты, игровые экспорты или данные прогресса.

## WAVE 1 — Единый продуктовый фундамент

Сохранена ранее интегрированная архитектура шести направлений:

- **World:** фото-текстура NASA, 3D-сцена с компактными настройками.
- **Intelligence:** интерактивная проверка утверждений с настоящими источниками NIST, не генератор фальшивых ответов.
- **Academy:** учёба, реальные данные локального прогресса, уроки, упражнения.
- **Play:** каталог 19 миров, полные игровые маршруты и стартующие реальные ассеты.
- **Development:** публичные кейсы TEDES / PHANTOM / MERAKKI / ESSENTIA и действующие статусы.
- **Entertainment:** семь архивных игр RU/EN/AR на `/entertainment/archive/`, основной `/entertainment/` сохраняет Play.

Исходная объединённая версия прошла 5/5 CI и не была выложена на действующий сайт.

## WAVE 2 — Быстрое управление экосистемой

`src/osgardQuickNavData.ts`, `src/OsgardQuickNav.tsx`:

- Двенадцать проверенных внутренних маршрутов; названия, описания и поисковые синонимы заданы вручную.
- Поиск кириллицей и латиницей, нечувствительный к регистру и различию `е/ё`.
- Ctrl/⌘+K открывает навигатор; стрелки, Enter, Escape и Tab доступны без мыши.
- Переходы используют **существующий** SPA-роутер, а не самостоятельную систему истории.
- При незаписанном вводе переход запрещается тем же `hasUnsavedChanges()` что и остальные защищённые маршруты.
- Пять последних выборов живут только в `sessionStorage` этой вкладки; это не телеметрия и не история посещений. Есть явная очистка.

## WAVE 3 — Премиальная доступная оболочка

`src/BrandShell.tsx`, `src/brandSystem.css`, `src/osgardQuickNav.css`:

- Реальная кнопка **«Разделы»** с быстрым поиском в общей шапке. Её размеры заданы в eager CSS, предотвращая скачки при загрузке динамического модуля.
- Диалог загружается по запросу через `React.lazy`, основной bundle не забирает поиск без необходимости.
- Фокус удерживается внутри открытого диалога, возвращается к исходной кнопке при закрытии, а документ снова получает прежнюю прокрутку.
- На телефоне — полноэкранный navigator с кнопками от 44 px; без горизонтальной прокрутки.
- Анимации отключаются при `prefers-reduced-motion` / `data-motion=off`.

## WAVE 4 — Стабильная загрузка маршрутов

`src/OsgardRouteSkeleton.tsx`, `src/osgardRouteSkeleton.css`, `src/main.tsx`:

- Вместо универсальной надписи «Загружаем…» — аккуратная загрузочная композиция, соответствующая World, Intelligence или Play.
- Содержимое имеет `role=status`, `aria-live`, `aria-busy`; декоративные элементы скрыты от экранных читалок.
- Предварительно резервируется высота основного раздела, чтобы динамические импорты не выглядели как пустой экран и не смещали страницу.
- Никаких поддельных метрик, карточек аккаунта или интерактивных кнопок, которые не работают.
- Reduced-motion отключает пульсацию. Существующие URL, SEO, авторизация и механизмы отката не меняются.

## WAVE 5 — Верификация и выпуск

`scripts/osgard-unified-shell-smoke.mjs`, `scripts/osgard-quick-nav.spec.mjs`, `playwright.ecosystem.config.mjs`, `.github/workflows/frontend-check.yml`:

- **Статическая проверка**: точные маршруты и поиск, запрет внешних ссылок, безопасная сессионная история и очистка, lazy-import, guard несохранённых форм, доступный диалог, responsive + reduced motion.
- **Браузерные проверки (desktop 1440 и mobile 390)**: открытия реальной Академии, источника TEDES в Development, полноценного архива 7 игр; клавиатурный поиск и возврат фокуса; отсутствие горизонтального переполнения.
- Обычный frontend CI дополнен скриптом `npm run qa:unified-shell`.
- Основной набор Playwright выполняется с прежними тестами всех игр, OSA, мобильной производительности и маршрутов.

### Прямая проверка

```bash
npm ci
npm run check
npm run qa:unified-shell
npm run build
npx playwright test --config playwright.ecosystem.config.mjs
```

### Release gates

Только после зелёного GitHub Actions **на последнем commit**: frontend/browser, visual OSA, Cloudflare build, REMIX launcher и release-readiness; проверка скриншотов и признаков JavaScript ошибок. При падении любой проверки статус остаётся DRAFT.

CI не доказывает фактическую работу серверной авторизации, Godot WebGL2, онлайн-мультиплеера, платежей или CDN на production. Они требуют post-deploy smoke и живой среды.

Слияние в `master` может автоматически активировать `deploy-frontend.yml`, поэтому это **отдельное действие с оценкой бэкапа и возможности отката**. Ни один из пяти WAVE не является молчаливым разрешением менять действующий сайт.
