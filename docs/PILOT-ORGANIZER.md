# OSA — организация пилота и отчёты

Платежи по указанию пользователя не менялись. Добавлена панель `/learning/organizer`: сводка доступных учебных проектов, очередь сданных работ, назначения проверяющих и отчёты по сохранённым данным.

## Рабочий путь

1. Запустите полный архив через `START-CORE-WINDOWS.bat` и войдите в Core.
2. Откройте `/learning/campus`, выберите проект и перейдите по ссылке «Очередь разборов и отчёты» либо откройте `/learning/organizer`.
3. В очереди выберите новые работы, свои назначения, последние работы с замечаниями или все версии. Поиск учитывает проект, автора и проверяющего.
4. Владелец проекта раскрывает «Назначить проверяющего», выбирает другого участника с правом редактирования, при необходимости задаёт срок в UTC и заметку.
5. Назначение появляется в приложении у проверяющего. Сообщения, письма и приглашения не отправляются.
6. Проверяющий открывает точную сданную версию из очереди. Форма сразу выбирает нужную работу и режим разбора, если у аккаунта есть соответствующее право.
7. После сохранения разбора назначение получает статус «разбор записан». Это не означает принятие работы: оценки ниже 2 по любому критерию сохраняют замечания к этой версии.
8. Автор дорабатывает проект и сдаёт новую версию. Старые разборы остаются в истории; сводные показатели последней работы не наследуют её статус из старой сдачи.
9. Для отчёта выберите проект, нажмите «Собрать текущий отчёт» и скачайте JSON или CSV. Отчёт содержит время формирования и версию проекта, а не постоянно обновляемую подписку.

## Назначения и доступ

Назначать, менять и снимать проверяющего может только владелец проекта. Проверяющий должен быть текущим участником с правом записи и не может быть автором сдачи. Если назначение активно или уже выполнено, новый разбор этой сдачи может записывать назначенный аккаунт. Для другого проверяющего владелец меняет или снимает назначение.

При отсутствии назначения сохраняется прежнее правило: разбор может сделать другой редактор проекта. Самооценку нельзя выдать за разбор другим участником. Наблюдатель только читает.

Срок задаёт человек. Просрочка вычисляется на сервере для открытого назначения. Если проверяющему отозвали доступ или оставили только чтение, владелец видит предупреждение. Отозванный участник не получает через сводку доступ к проекту или его отчёту.

Открытые назначения старых версий остаются видны и помечаются как архивные. Они не теряются из-за появления новой сдачи. Снятие назначения не удаляет сохранённые разборы. Назначения включены в полный экспорт проекта и SQLite-копию; восстановление обычной версии проекта не откатывает их.

## Что означают показатели

| Показатель | Что считается | Чего он не доказывает |
|---|---|---|
| Аккаунтов с доступом | Текущие участники и владелец проекта | Количество реальных учеников |
| Аккаунтов с практиками | Текущие участники с учебными записями | Освоение навыка |
| Восемь актуальных практик | Правильные самопроверки с текстом упражнений по текущим хешам уроков | Качество практики и независимую аттестацию |
| Исторические сдачи | Все сохранённые версии итоговой работы | Число уникальных людей |
| Последние сдачи авторов | Одна последняя сдача на автора, включая исторических авторов проекта | Реальное участие в занятиях |
| Последняя работа с замечаниями | Последний разбор последней сдачи автора требует доработок | Статус более новой ещё не разобранной работы |
| Критерии отмечены участником | Все пять оценок последнего разбора равны 2 | Сертификат, независимый экзамен или квалификацию проверяющего |
| Отметки о проведении | Занятия, вручную отмеченные организатором как проведённые | Фактическое проведение встречи |
| Посещения | Самоотчёты аккаунтов по занятиям | Независимую проверку присутствия |
| Отношение времени | Исходное время / время с инструментом, включая исправления и помощь человека | Причинный эффект обучения и превосходство системы |

При отсутствии измерений отчёт показывает отсутствие данных, а не 0% или достигнутую цель. Отчёт предупреждает о недостатке практик, сдач, измерений, аудитории и проверяющего. В нём нет выручки и подмены черновиков денежными результатами.

Разборы и сдачи, записанные в одну секунду, упорядочиваются по порядку сохранения. В статистику текущей работы входит последняя сдача каждого автора. Участники, потерявшие доступ, не входят в показатели текущего состава, но их исторические записи сохраняются.

## Границы данных

Панель читает не более 200 проектов с текущим доступом и разрешением Learning. Практические тексты и полный проект не копируются в сводку; их смотрят в конкретной работе. Отключение Learning убирает проект из этой панели. Полный собственный экспорт через Core остаётся доступным.

Черновики назначения привязаны к версии проекта на момент начала формы. Обновление сводки не обновляет эту версию незаметно. При изменении проекта форма предлагает сохранить нужный текст и сбросить черновик; сервер отклоняет устаревшую запись. Учебные формы также отправляют версию, с которой началось редактирование.

CSV использует UTF-8 с BOM, кавычки и экранирование значений, которые могут интерпретироваться как формулы. Это проверено программно; импорт в конкретные Excel/Google Sheets в этом проходе не выполнялся. JSON и CSV могут содержать сведения участников и аудитории проекта — экспорт предназначен для его уполномоченного пользователя.

## Проверка

`npm run qa:pilot-reports` проверяет серверный каталог, HTTP/SQLite-сценарии и клиентские функции. Suite включает 28 предыдущих Core/Learning проверок и новые сценарии сводок/назначений. Точный результат — `PILOT-REPORT-TESTS.json`.

Проверены чужой проект, отзыв доступа, права наблюдателя, запрет саморазбора, повтор ключа операции, старая версия, завершение только корректного назначенного разбора, сохранение истории, порядок при одинаковых датах и расчёты без ложных результатов. Клиентские проверки охватывают CSV, фильтры, адреса внутри приложения и серверный рендер целевой формы разбора.

Реальный пилот, работа с учениками и ведущим, браузерная приёмка и нагрузочное тестирование ещё не проведены. Панель помогает их организовать; она не подтверждает их проведение.
