# Производительность: разделение учебных данных

Это сравнение предыдущего этапа. Актуальные размеры после добавления Core приведены в `REDESIGN-BUILD-AUDIT.json`. Core загружается отдельно, по своему маршруту.

Сравнение локальных production-сборок до и после выделения реестра восьми уроков в `osaLessonRegistry.ts`.

| Главная | До, байт gzip JS | После, байт gzip JS | Разница |
|---|---:|---:|---:|
| WorldHome.tsx | 86763 | 86789 | 26 |
| IntelligenceHome.tsx | 98695 | 86203 | -12492 |
| PlayHome.tsx | 87380 | 87406 | 26 |

Главная OSA загружает на 12 492 байта gzip JavaScript меньше (12,7%). Учебные тексты остаются доступны на страницах уроков, программы и проверки знаний. Обратный экспорт из `osaLessonGuides.ts` сохраняет совместимость существующих потребителей.

`qa:redesign-build` проверяет начальный статический граф каждой главной: максимум 95 КиБ gzip JavaScript, отсутствие Three.js, полных руководств/текстов уроков и старых стилей. Динамически загружаемые страницы в этот объём не входят. Размер CSS каждой главной — 6 327 байт gzip. Изменение +26 байт на WORLD/PLAY связано с изменившимися ссылками на чанки.

Это оценка файлов сборки, а не измерение скорости сети или Core Web Vitals. Шрифты, изображения, HTML, HTTP-заголовки и последующие переходы не входят в цифры JavaScript. Браузерная проверка на медленном мобильном соединении и полевые LCP/INP/CLS остаются открытыми.

Проверено: TypeScript, production-сборка, серверный рендер страниц, прогресс и миграции, резервные копии с отказами хранилища, доступность медиа, учебные маршруты, соответствие 16 двуязычных текстов озвучки, статические маршруты и контрольные суммы.
