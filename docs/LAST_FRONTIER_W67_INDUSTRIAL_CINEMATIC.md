# LAST FRONTIER — W67 / INDUSTRIAL CATHEDRAL

28 октября 2026. **Оригинальная Godot-игра. Два настоящих 3D-помещения. Проверки — только по точному текущему Git SHA.**

## Художественное решение

Мы больше не увеличиваем количество золотых полос на маленькой коробке. Референсный принцип — **индустриальный масштаб, архитектура и причинная связь действия с миром**. Ориентир по качеству и эмоции: большие реакторные пространства Dead Space Remake, архитектурная читаемость Control, внутренние приборы Alien: Isolation. Чужие модели, код, персонажи, скриншоты, звук и названия не копируем.

**Система изображения:** монументальные вертикальные опоры, реально высокий 3D-шахтный реактор, надземные промышленные фермы, теплый практический свет, осветлённый шлифованный металл, энергосигналы холодного цвета, металлическая композиция и минимум шумных декоративных интерфейсных рамок.

В старом скриншоте W65 была очевидная слабость: крайне темная небольшая камера с маленькой игрушечной центральной моделью. W67 устраняет инженерную часть причины: прежние материалы были слишком металлическими для отсутствующего отражающего окружения. Для существующего реакторного зала ограничено значение metallic до 0.23, скорректирована roughness и усилен базовый ambient. Это **не гарантия высокого художественного качества** — только осмысленное исправление темноты, нуждающееся в просмотре оригинальных PNG нового билда.

## Контракты, которые сохраняются

- Исходный `A7CascadeCore` неизменен: 6 циклов, 5 действий, два решения на цикл, все оригинальные победные/проигрышные маршруты.
- W63/W64/W65 тесты не редактируются ради прохождения.
- Камера/инспекция управляют только `A7CinematicStage`; никакие `choose()` или сохранение состояния геймплея в навигации не вызываются.
- В режиме ECO скрывается дополнительный плотный декор, но сохраняются **оба реальных помещения**, мост и настоящие игровые приборы.
- `A7IndustrialCathedral` содержит только оригинальные геометрические меши, базовые материалы и `Label3D`. Сетевых вызовов нет; не загружаются фотографии, музыка или 3D-модели из внешних сервисов.
- Браузерная проверка подаёт **настоящие клавиши N/W/A/1/4 в экспортированный Godot WebGL**, читается только пассивная UI-телеметрия. Проверяет разницу настоящих изображений двух разных комнат, реальные изменения после `PUMP` и `SCAN`, мобильные 390 px.
- Новый коммит не наследует результаты W66 автоматически. Признавать код только после успешного CI на точно том же SHA.

## Критерии завершения

1. История строго от W66 `58f331ed1b07b3389acb47646e390218434d4ce5`, нет правок 14 защищенных файлов с исходным геймплеем, старым UI, сценой, экспортом и тестами.
2. Godot 4.4.1 импорт без GDScript parse errors.
3. Настоящие нативные тесты W63 (105 исходных), W64, W65 и **новый W67** выполнены независимо.
4. WebGL действительно экспортирует Godot JS/WASM/PCK, а не HTML-макет.
5. Chromium действительно показывает два разных помещения в 1366×900, принимает навигацию, сохраняет игровые решения и выдаёт оригинальные PNG+SHA.
6. 390×844 не перекрывает 3D-сцену; игры на реальных мобильных устройствах **ещё не проверены**.

После программных PASS нужен **настоящий просмотр исходных кадров человеком**. Если новый зал выглядит плохо, нельзя прикрывать это числом мешей. Следующая итерация: фактурные материалы/свет и полная режиссура 10–15-минутного вертикального среза, затем слепые тесты не менее 12 новичков.
