# OSGARD — манифест происхождения релизных файлов

Этот модуль создаёт детерминированный JSON-манифест готовой папки `dist` со списком путей, размеров и SHA-256 файлов, привязанный к заявленному идентификатору коммита. `verify` повторно хеширует все файлы, обнаруживает новые, удалённые или изменённые файлы и блокирует несоответствия.

```sh
python3 scripts/release-artifact-manifest.py build dist --commit COMMIT_SHA --output /private/artifact-manifest.json
python3 scripts/release-artifact-manifest.py verify dist --manifest /private/artifact-manifest.json
python3 -m unittest discover -s tests -p test_release_artifact_manifest.py -v
```

Манифест намеренно записывается **вне `dist`**, чтобы не менять само содержимое сборки. Его проверяют после упаковки и до передачи релиза. Не публикуйте приватные данные или секреты. Необходимо проверять хеш готового ZIP отдельно, сопоставлять файлы ZIP с содержимым манифеста и подтверждать доверенное происхождение манифеста (например, signed attestation). Текущая привязка к SHA коммита — заявленная строка, не криптографическое доказательство сборки из этого коммита.

Это не инструмент деплоя, оплаты или восстановления сервера. Скрипт сам не обращается в сеть и не модифицирует исходные файлы релиза.
