# EMPIRE Ω R86 — закрытая полевая приёмка без выдуманных доказательств

Статус: дополнительный офлайн-инструмент для независимых испытаний. Он не меняет Godot, Web/PCK/WASM, SSH или сервер.

## Запуск (Python 3.11+)

В корне репозитория, вне него выберите **абсолютную** приватную папку:

```bash
python3 scripts/omega_r86_private_field_kit.py init --root /private/empire-omega-qa-20261025
```

На Windows допустим абсолютный путь вида `C:\PrivateQA\EmpireOmega`. Папку нужно хранить на зашифрованном локальном диске с закрытыми правами и не включать в Git.

Скрипт фиксирует точный source_commit и SHA256 manifest, создаёт закрытые папки `web/`, `campaign/`, `android/`, `ios/`, `players/`, `art/`, `review/`, инструкцию и пустой шаблон для 20 сессий. **Шаблон не является доказательством**. Пустые записи и поддельные фильмы не создаются.

1. В `web/` сохранить оригиналы `live-integrity.json` и `playwright.json` из одного успешного R84. Проверки повторно исполняются штатным R83.
2. В `campaign/` собрать настоящие 40 игровых достижений, одну непрерывную запись, 40 PNG и 3 PNG контроля сохранений, по инструкции `docs/EMPIRE_OMEGA_R73_FIELD_ACCEPTANCE.md`.
3. В `android/` и `ios/` собрать реальные Godot FPS JSON и отдельные непрерывные видео физических телефонов. Сначала R80 готовит **неаттестованный** черновик. Не объявлять эмулятор аппаратной проверкой.
4. Для 20 добровольцев **отдельно получить согласие на запись**, добавить оригинальный MP4/WebM в `players/`. Копировать `players/operator-metadata.template.json` в `players/operator-metadata.json`, внести ровно 20 оригинальных сессий (поля по шаблону R83). Никогда не включать имена, личные данные или видео в публичный GitHub.
5. В `art/` предоставить четыре оригинальных скриншота Godot и независимую лицензионную инвентаризацию по R83.

Когда реальные данные собраны:

```bash
python3 scripts/omega_r86_private_field_kit.py sessions --root /private/empire-omega-qa-20261025
python3 scripts/omega_r86_private_field_kit.py audit --root /private/empire-omega-qa-20261025 --require-ready
```

`sessions` вычисляет SHA-256 исходных видео, проверяет двадцать уникальных участников и все поля штатным R83, записывает `twenty-sessions.json` только при полном успехе и **не перезаписывает** уже существующий файл.

`audit` направляет присутствующие доказательства в исходный единый R83. Без доказательств статус HOLD. Некорректные доказательства указываются в `rejected_evidence`. Даже полный форматно-технический набор даёт максимум `READY_FOR_INDEPENDENT_HUMAN_SIGNOFF`, а `production_go=false`.

**Независимый человек должен проверить реальность телефонных сессий, добровольность участия, содержимое исходных видеозаписей, фактическое прохождение, реальные кадры и права на художественные ассеты.** Отдельное решение о коммерческом выпуске не может быть выдано этим скриптом.

## Границы безопасности

Исходник не делает сетевых вызовов, не загружает файлы в GitHub и не меняет публичную игру. На POSIX новые каталоги закрываются правами 0700, файлы создаются 0600. Оригинальные файлы не пересоздаются и не исправляются. Проверяются символические ссылки на рабочий каталог, исходный manifest и медиа. Данные хранить лишь столько, сколько оправдано согласиями тестировщиков; доступ дать только ответственным QA.

Если опубликованная версия изменится, необходимо создать **новый** частный набор; нельзя прикреплять полевые доказательства прежней игры к новой.
