# OSGARD R135 W25 — реальные Android/iPhone, без поддельной аттестации

## Что создано

Два инструмента проверки **только настоящих аппаратных сессий**:

1. `scripts/r135-w25-physical-browser-capture.js` — измеряет
   исходные кадры видимой игры на телефоне через `requestAnimationFrame`,
   загружает **некэшированный** `release.json`, фиксирует точный commit
   опубликованной версии, частоты p50/p95/p99 и ориентацию экрана,
   локально экспортирует оригинальный JSON. Никуда не отправляет данные.
2. `scripts/r135-w25-physical-evidence.py` — проверяет четыре независимых
   пакета Android portrait / Android landscape / iOS portrait /
   iOS landscape, SHA-256 оригинального JSON, видео и PNG, корректность
   структуры видео, CRC скриншота и пересчёт p95 из самих кадров.
   При чужой SHA, синтетической подмене или утрате кадров выдаёт HOLD.

Все автоматические результаты дают **только проверку целостности**:
`hardware_fps_certified=false` и `production_W28_go=false`.
Нельзя объявлять физический FPS по программному SwiftShader.

## Протокол полевого инженера

- Откройте опубликованную `/games/r135-service/` на настоящем Android
  Chrome или iPhone Safari, удерживайте игру видимой. Используйте
  DevTools с USB-подключением/отладкой, чтобы загрузить исходный скрипт
  и *по действию человека* запустить
  `await OSGARDR135PhoneProbe.run()`. Скрипт не является фоновым
  агентом и не запускается при загрузке.
- Пройдите три учебные неисправности и безопасную сервисную миссию;
  сделайте **непрерывную запись экрана** (MP4/WebM), на которой видно
  реальные клики, ответы, блокировки и финальные результаты.
- Для каждого из четырёх режимов сохраните в отдельную папку
  оригинальный JSON, непрерывное видео и оригинальный PNG:
  `android-portrait`, `android-landscape`, `ios-portrait`,
  `ios-landscape`. Никаких изменённых фото/видео.
- Каждая папка содержит `original-evidence.json` со структурой:

```json
{
  "schema": "osgard-r135-w25-original-evidence-v1",
  "device_claim": "android",
  "orientation": "portrait",
  "timing_file": "original-frames.json",
  "timing_sha256": "64 lowercase hex",
  "video_file": "original-session.mp4",
  "video_sha256": "64 lowercase hex",
  "screenshot_file": "original-screen.png",
  "screenshot_sha256": "64 lowercase hex"
}
```

Это **пример полей, а не готовая действительная запись**.
Нужны фактические хеши исходных файлов и фактический SHA Godot игры.

После сбора кадров:

```bash
python3 scripts/r135-w25-physical-evidence.py \
  --evidence /path/to/four-original-phone-sessions \
  --source EXACT_40_CHAR_SOURCE_SHA
```

## Что действительно требует участия человека

Необходим независимый осмотр физических Android и iPhone,
сопоставление непрерывного видео с указанным аппаратом,
Safari/Chrome, сверка кадров и языка, тест нагрева/термального
троттлинга через 20 минут и запись батареи/памяти. Настоящий
тестировщик подтверждает модель устройства и подлинность записи
в **отдельном** акте. Автоматическое совпадение хешей
никак не доказывает факт использования физического телефона.

До проведения этих испытаний: `HARDWARE_HOLD`; не
объявлять W25 завершённым, W28 production GO или AAA-фотореализм.
