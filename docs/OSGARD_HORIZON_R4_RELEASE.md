# OSGARD HORIZON R4 — Godot 4.4.1

This milestone delivers real source changes in `godot/empire-omega`, not promotional concept images.

**Visual architecture:** the playable coupe uses an original longitudinal swept surface mesh instead of five visible cuboids. Its revised sloped greenhouse, five-spoke alloy wheel details, metallic paint, drift and suspension dynamics are fully integrated into the existing game vehicle, garage and save system.

**City:** GPU-instanced shrubs, flower heads, safety guardrails, reflectors and geometric road signs supplement the existing city. Scenic details have no collision bodies and do not change mission logic.

**Quality gates:** native Godot tests, 1600×900 and 1366×768 live scene capture plus 1600×900 real Godot close-up, checked HTML5 export manifest, direct SSH activation with server SHA verification and public WASM HTTP check.

This build is a stylized procedural driving simulation. It is not photorealistic Forza Horizon 5 and includes no proprietary third-party assets.
