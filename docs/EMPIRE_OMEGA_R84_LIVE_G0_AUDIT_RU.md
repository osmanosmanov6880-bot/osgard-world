# EMPIRE Ω R84 — независимый выпускной аудит реальной Web-игры

**Дата:** 25 октября 2026. **Режим:** Web Tech Preview готова к независимой проверке; полноценный AAA/коммерческий релиз требует отдельной полевой приёмки.

## Что допускается доказать автоматически

R84 повторно проверяет настоящую опубликованную Godot 4.4.1 сборку, а не только синтетические тесты. Из исходного release.json берётся точный игровой source_commit. Затем проверяются:

1. Свежесть исходного игрового коммита относительно репозитория.
2. Семь оригинальных бинарников/ассетов в checkout, SHA-256 каждого файла.
3. Семь HTTP-публичных файлов по адресу /games/omega-3d-preview, независимое скачивание и SHA-256.
4. Настоящий desktop Chromium с Mesa/OpenGL, реальный кадр города после загрузки, управление клавиатурой, не заставка Godot.
5. Настоящий Chromium touch с сенсорным управлением. Это эмуляция, **не физический Android/iPhone**.
6. Единый R83, которому передаются оригинальные HTTP и Playwright JSON из ЭТОГО запуска. Без данных людей/устройств итог обязан быть technical_web_ready=true, status=HOLD, production_go=false.

Синтетические медиа и просто зелёный статус сборки не принимаются за доказательство выпуска.

## Как запустить

После объединения проверенного PR с workflow на master проверка выполняется один раз автоматически, потому что изменился сам файл workflow. Затем для повторной проверки:

- Откройте GitHub Actions → EMPIRE Omega R84 real published G0 evidence and full AAA release HOLD.
- Выберите Run workflow с веткой master. Сценарий из PR/произвольной ветки не вправе аттестовать публичную игру.
- При успехе скачайте архив omega-r84-real-g0-evidence-<run_id> с live-integrity.json, playwright.json, r83-real-public-verdict.json, настоящими PNG/trace и кратким отчётом.

GitHub хранит архив только **14 дней**. Перенос в защищённый внутренний QA-архив — отдельное действие владельца. Приватные видео игроков и сведения устройств в GitHub не размещать.

## Строгая граница релиза

Успешный R84 означает проверяемый PLAYABLE WEB TECH PREVIEW. Он НЕ заменяет:

- Человеческое непрерывное прохождение 40 миссий и контроль сохранений (R73/R75).
- Физический Android, оригинальные измерения Godot и видео (R80).
- Физический iPhone, оригинальные измерения Godot и видео (R80).
- 20 добровольных игровых сессий разных людей с согласием и отзывами (R83).
- Независимую художественную экспертизу настоящих игровых кадров и лицензионных источников ассетов (R83).

Даже когда все форматы представлены, R83 допускает только READY_FOR_INDEPENDENT_HUMAN_SIGNOFF; сам он никогда не выдаёт production_go=true. Последнее решение принимает независимый ответственный за выпуск после проверки оригинальных материалов.

**Безопасность:** R84 читает только публичные игровые файлы и проверяет браузер; не содержит SSH-ключей, не активирует WASM/PCK, не затрагивает сервер, не запускает платежи. При сбое сохраняет безопасные диагностические материалы и завершает CI ошибкой.
