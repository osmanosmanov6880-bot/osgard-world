# OSA CINEMA V55 — WORLD STUDIO / TECHNICAL HANDOFF
**Дата:** 28 октября 2026 · **статус:** исходный код готов к CI-приёмке, не заявлять публичный деплой до проверок.

## Что теперь действительно существует в коде
1. Отдельный редакционный портал `/osa-cinema/studio` с оригинальной обсидиановой палитрой, золотой типографикой и визуальными композициями средствами CSS. Использует только уже имеющиеся локальные WebP-референсы, никаких внешних запросов к декоративным изображениям.
2. Каталог из **трёх подтверждённых производственных записей**: доступная браузерная история `THE NEXT HUMAN`, не снятый короткометражный фильм `ZERO WINDOW` и локальный концепт-превиз `THRESHOLD`. Ложных доступных MP4 не создаём.
3. RU/EN, фильтры по типу, строка поиска, категория «Избранное», локальный персональный список, модальное окно с Escape/Tab-ловушкой фокуса и возвратом к кнопке.
4. Три адресные двуязычные страницы `/osa-cinema/studio/films/{id}`, настоящий навигационный 404 для неизвестных ID, локальное избранное, копирование текущего адреса, карточки следующих фильмов, публичные ссылки на исходные производственные акты.
5. Единый типизированный `src/osaCinemaStudioRegistry.ts` для каталога и карточек. Правило `isPublicVideoAvailable` закрыто по умолчанию: это **не** механизм выдачи прав или публикации MP4.
6. Метаданные для отдельных адресов в `src/routeSeo.ts`: корректные заголовки, описания и `CreativeWork` JSON-LD, а не вымышленный `VideoObject`. Добавлены четыре адреса в sitemap.
7. Отдельная строгая GitHub Actions приёмка `.github/workflows/osa-cinema-v55-studio.yml`: Node-контракты, TypeScript, production build, существующий медиа-гейт; Chromium desktop/mobile Playwright и скриншоты артефактов.

## Как проверить выпуск
1. `npm ci`
2. `node --test scripts/osa-cinema-v55-studio-contract.test.mjs`
3. `node --test scripts/osa-cinema-v53-evidence.test.mjs`
4. `npm run check && npm run build`
5. `npx playwright test --config playwright.osa-cinema-v55.config.mjs` при установленном Chromium.
6. Проверить прямой заход на все три URL и 404; корректность RU/EN, избранного после перезагрузки, отсутствия ложного `<video>`, отсутствие горизонтального переполнения на мобильной ширине, права и существующий кинозал.
7. Лишь после успешных exact-head CI и ревизии диффа — merge и подтверждённый production deployment.
8. По публичному адресу после деплоя проверить HTTP 200, `Content-Type`, canonical и фактическую загрузку CSS/изображений, сделать скриншоты desktop/mobile с реального сайта.

## Истина о релизе
Сборка сайта **не равна** выпуску кино. Публичный URL платформы **не равен** публичной премьере. Для фильма нужны проверенные видеофайлы, права и фактическое воспроизведение; до того UI явно показывает состояние производства.

## V55.1 — продолжение истории и синхронизация вкладок
- Новый компонент `src/OSAStudioContinue.tsx` читает строго существующий `getOSALearningProgress`, показывает реальную сохранённую сцену и позволяет продолжить тот же интерактивный опыт с выбранным языком. Кнопка не означает, что опубликованы внешние фильмы или медиаплеер.
- Избранное отслеживает событие `storage` из соседних вкладок, не требует аккаунта и не делает внешних запросов. Ни одно значение локального прогресса не считается подтверждением оплаты, сертификации или права доступа.
- Контрактный и реальный Playwright-сценарий проверяют точный deep link `?lang=en&scene=4` и восстановление истории.
