# INHERIT — READABLE EDITION (21 октября 2026)

## Референс и дизайн

**Референс:** *Journey × Monument Valley 2 × Townscaper*. Не копирование чужих моделей или интерфейса: от Journey — чувство тихого путешествия, от Monument Valley — крупные понятные формы, от Townscaper — мгновенная связь между нажатием и появившимся предметом. Собственная палитра: глубокое море #071b26, ночной бирюзовый #102f32, тёплое золото #f5d99f, почти белые буквы #f3f4eb.

**Что было трудно:** множество ключевых подсказок и кнопок оставались в 9–12 px при большом декоративном фоне; перечень функций был визуально важнее игрового действия. Игра должна объяснять себе саму за 5 секунд.

**Иерархия нового экрана:**

1. Крупное название INHERIT и отдельная кнопка **«А+ Ещё крупнее»** (доступна на всех трёх языках).
2. Одна крупная фраза о мире; три понятных действия **«Выбери предмет → Поставь на остров → Передай поколение»** с подсветкой текущего шага.
3. Настоящий остров остаётся главным арт-объектом; надписи на фоне получают тёмные контрастные подложки.
4. Большие кнопки инструментов (не менее 16 px), золотая основная кнопка передачи (18 px и не менее 60 px высоты), дополнительные функции — в отдельном меню, не конкурируют с основным действием.
5. Исследование, атлас, история, экспедиции, сохранения и настройки остаются на своих местах и работают прежними функциями; в них также увеличены подписи и размеры элементов.

## Типографика

| Элемент | Минимальная цель |
|---|---:|
| Основные действия и названия предметов | 16 px |
| Золотая кнопка передачи | 18 px, 60 px высоты |
| Основное пояснение о мире | 19 px |
| Подписи активного шага | 17 px; вспомогательная строка 14 px |
| Строки правил, карточек и диалогов | 16 px |
| Заголовок истории/диалогов | 29 px и более |
| «А+ Ещё крупнее» | +18% к указанным текстовым шкалам |
| Интерактивные области | обычно от 48 px |

Шрифт крупнее **по умолчанию**, настройка A+ опциональна, сохраняется только на устройстве в \`inherit:text-preference:v1\`, не регистрирует события и не отправляет запросов.

## Достоверность подсказок

Полоса трёх шагов читает \`InheritGame.snapshot()\` и текущий выбор инструмента: если в \`pending/changes\` есть реальные изменения — подсвечивается шаг передачи. После настоящей смены номера поколения возвращается первый шаг. Ни один шаг не создаёт предметов и не завершает поколение автоматически. В режиме \`?mode=account\` полоса скрыта, чтобы не обещать возможность редактирования без прав. Кнопка A+ остаётся доступной даже для просмотра.

## Тесты

\`\`\`sh
npm run qa:inherit-readability
npm run qa:inherit-i18n
npm run qa:inherit-world-cycle
npm run qa:inherit-account
npm run build
\`\`\`

Playwright desktop/mobile проверяет реальные вычисленные размеры шрифтов, реальную геометрию основного действия, отсутствие горизонтального переполнения, переключение RU/EN/中文, сохранение A+ после перезагрузки и отсутствие изменений игрового сохранения от настройки. Дополнительно проверяется весь цикл «Выбери → Поставь → Передай» по фактическим игровым данным.

## Выпуск

Изолировано в \`public/games/inherit/readable-ui.css\` и \`readable-ui.js\`, загружается после существующих стилей и движков. PWA \`inherit-shell-v25\` обновляет офлайн-ресурсы. Для публикации обязательны все PR-проверки, затем существующий SSH-деплой с проверкой побайтового совпадения новых файлов. Нет изменений Core API, сохранений, авторства, аккаунтных прав или платежей.

**Граница:** это настоящий UI/UX-редизайн существующей браузерной игры. Он не заявляет о создании AAA 3D-движка, новой 3D-геометрии или о реальных результатах рынка.
