The 1K albedo, OpenGL normal and roughness maps are acquired once into the
repository by a bounded branch-only GitHub Action, with SHA-256 lock. No
network or live API calls occur in the distributed game. The original
procedural materials remain the low/standard and offline fallback.

The assets improve only physical asphalt reflectance/detail; they do not
transform the rest of the low-poly city into photoreal AAA geometry. The
approved images remain visual targets, never backgrounds used to fake QA.
Commercial AAA production GO remains HOLD until authored 3D assets,
physical-device profiling, user testing and art/licence review.
