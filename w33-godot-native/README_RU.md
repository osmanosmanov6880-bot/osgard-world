# OSGARD FIELD LAB W33 — шесть миссий и разбор действий

**Что создано:** рабочая автономная браузерная игра W33 и отдельный исходный проект Godot 4.4.1 с теми же игровыми механизмами плюс новым разбором попыток. Это **два разных исполняемых пути**. Браузерный путь проверен в Chromium; Godot-проект **ещё не запускался в движке**.

## Играть прямо сейчас

Откройте `playable_w33/OSGARD_FIELD_LAB_PLAY.html` (готовый одностраничный HTML, все сценарии и оформление внутри; не требует сети или внешних файлов). Это самостоятельная браузерная игра, а не экспорт из Godot. На ней можно выполнять шесть миссий:

- 01 оптика, 02 охлаждение, 03 контакты люка: остановить ротор → дождаться безопасной скорости → открыть люк → выбрать нужную камеру и откалибровать два регулятора → выдержать стабильность 0,45 с → сканировать → закрыть люк → запустить привод.
- 04–06: после освоения базового кейса открывается аварийная смена. Действительное событие изменяет параметры датчиков; нужно настроить их заново и удержать стабильность 1,25 с.

Нажмите **ПОКАЗАТЬ ДЕЙСТВИЯ**, чтобы увидеть фактические события и причины ошибки. После закрытия миссии показываются исходный игровой балл, пять реально пройденных этапов, время и оценка оператора; кнопка **ПОВТОРИТЬ МИССИЮ** запускает настоящий сценарий без сброса предыдущего рекорда. Есть RU/EN, мышь/клавиатура/сенсорные регуляторы, HERO/ECO, необязательный звук, субтитры и удаление данных. Вся игра является **учебной симуляцией**.

**Приватность:** история действий не передаётся в сеть, хранится только в оперативной памяти и имеет жёсткий лимит 96 событий. Локальные рекорды сохраняются, но журнал попытки не сохраняется. Статистика включается только с согласия пользователя; полное удаление данных доступно в настройках.

## Что перенесено в настоящий Godot

Откройте `godot/project.godot` через Project Manager **Godot 4.4.1 (standard, не .NET)**, затем `godot/Main.tscn`.

| Файл | Реальный исходный код |
|---|---|
| `godot/scripts/OSGARDCore.gd` | Шесть миссий, формулы, блокировки, аварийные события, рекорды, память событий и оценка |
| `godot/scripts/OSGARDMain.gd` | Нативные Control-кнопки, регуляторы, RU/EN, разбор, повтор, ConfirmationDialog перед удалением |
| `godot/scripts/OSGARDRig.gd` | 3D-ротор, люк, камеры и десятисегментный индикатор стабильности в одном MultiMesh |
| `godot/scripts/OSGARDText.gd` | Объяснения и локализация |
| `godot/tests/test_*.gd` | Три настоящих Godot SceneTree-теста для импорта и запуска |
| `godot/export_presets.cfg` | Предварительный Web export preset, **экспорт не выполнялся** |

## Проверить без Godot

Из корня распакованного комплекта:

```bash
sh qa/run_offline_checks.sh
python3 playable_w33/tests/browser_acceptance.py
```

Нужны Python, Node.js и Chromium с Playwright для второй команды. В проведённой среде: **68 статических проверок GDScript**, **58 исходных тестов W31**, **10 тестов W33 event review** и **50 тестов целостности/экспорта/установщика** — успешно. Пять обычных сценариев W33 в реальном Chromium также пройдены: ошибка и повтор на ПК, сенсорный кейс, два размера экрана и явное удаление данных. Реальная аварийная смена люка отдельно прошла в новом Chromium-процессе. Продолжительная стресс-проверка всех шести миссий в одном экземпляре программного Chromium упиралась в ограничение производительности этой среды и **не считается успешной полной серийной приёмкой**. Дополнительные независимые пары можно запустить так:

```bash
python3 playable_w33/tests/browser_acceptance.py --one-pair 0
python3 playable_w33/tests/browser_acceptance.py --one-pair 1
python3 playable_w33/tests/browser_acceptance.py --one-pair 2
```

Браузерная проверка выполнялась через загрузку исходного HTML в Chromium; обычный двойной щелчок `file://` **не подтверждён в заблокированной политикой тестовой среде**. Настоящая игра сохраняется как самодостаточный файл.


## Безопасное подключение к старому проекту

Из чистой ветки `feat/...` локального `osmanosmanov6880-bot/osgard-world` выполните:

```bash
sh install/install_to_osgard_feature_branch.sh /path/to/local/osgard-world
```

Скрипт копирует проект только в **`w33-godot-native/`** и отдельный GitHub Actions workflow. Не меняет старые исходники R135, активный release selector, SSH-ключи, файлы сайта, ветку master и не делает коммитов. CI-джоб блокируется, если Godot-проект не импортируется/не проходит три нативных теста и действительный Web export.

**Статус публичного релиза W33: NO-GO.** Реальная Godot-интеграция с прежним производственным проектом, нативный WebGL, внешняя приёмка на физических устройствах, подпись реального архива и защищённый SSH остаются незавершёнными. Уже опубликованный сайт не менялся.
