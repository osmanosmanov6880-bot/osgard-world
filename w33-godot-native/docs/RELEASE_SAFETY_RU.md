# Блокировка преждевременного релиза OSGARD

**Текущая публичная игра сохраняется без изменений.** W32 — отдельный Godot-проект, не существующий R135 production branch. Нельзя загружать W32 в директорию производства или изменять `r135-active-release.json` до прохождения всех критериев.

1. Исполнить native QA на Godot 4.4.1: импорт проекта, 6-миссионный тест и настоящий тест 3D/GUI.
2. Проверить ручную игру: все 6 миссий на ПК, восстановление сохранений, безопасный перезапуск после отказа от статистики, RU/EN.
3. Создать WebGL экспорт из Godot с официальными 4.4.1 экспортными шаблонами. Только тогда — Chromium real desktop/mobile smoke, контроль оригинальных кадров, анализ FPS программного рендерера.
4. Проанализировать 16 случаев на реальных iOS/Android. Никакие программные показатели SwiftShader не подтверждают температуру, GPU, 8K или AAA.
5. Отдельный PR с источником и точным Godot/WebGL SHA. Независимый инженерный обзор миграции в настоящий `godot/osgard-r135-standalone` с сохранением старых безопасных блокировок и сохранений.
6. Только после независимого pin и полного успешного gate — защищённое SSH-развёртывание, HTTP-проверка манифеста, SHA, WASM, PCK, диапазона HTTP206 и проверка настоящего отката.

**До выполнения всё остаётся NO-GO на публичный релиз.**
