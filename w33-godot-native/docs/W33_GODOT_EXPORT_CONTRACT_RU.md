# Истинная Godot WebGL-сборка (не HTML прототип)

Файл `godot/export_presets.cfg` — предварительный профиль Web. Запуск GitHub Actions `ci/r135-w33-operator-debrief-native-qa.yml` должен сначала импортировать Godot 4.4.1 и выполнить три нативных теста: шесть миссий, настоящие 3D-контролы и W33 Session Debrief. Только после зелёных тестов Godot CLI создаёт `.html`, `.js`, `.wasm`, `.pck` в `build/web`. `qa/verify_web_export.py` проверяет настоящие байты, размеры и SHA, а не только имена файлов. Workflow не имеет права на SSH и не меняет публичную версию.

В текущем автономном комплекте **эти настоящие Godot-артефакты отсутствуют**. Положительные и отрицательные Python-тесты экспортера используют синтетические fixtures, а не подтверждают фактическую WebGL-сборку.
