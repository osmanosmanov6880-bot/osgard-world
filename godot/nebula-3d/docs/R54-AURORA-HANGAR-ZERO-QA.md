# NEBULA R54 — AURORA HANGAR ZERO: настоящий ангар, магазин и академия

**Статус:** feature-кандидат, НЕ production. Исходный `master` и публичный release allowlist не меняются. Реальные Android/iPhone: **NOT_PERFORMED**.

## Изменения в реальном коде

1. **Закрытый 3D-ангар:** новый `scripts/hangar_environment_r54.gd` создаёт собственные пол и техническую платформу, бронированную заднюю стену с дверями, боковые стены, потолочные опорные фермы, платформы и поручни, сервисные машины с колёсами, электрические кабели, цветные осветительные панели и анимируемую кран-балку. Отдельный ограниченный shadow-casting SpotLight3D. Все элементы находятся внутри изолированного `SubViewport` World3D и не влияют на полёт.
2. **Камера и чёткость:** существующая импортированная игровая 3D-модель и фактические R45-корпуса сохранены, ручное вращение и touch остаются. Вместо заявленного фиксированного 640×350: `stretch = true` у `SubViewportContainer` уже автоматически соответствует пиксельным размерам контейнера, вручную менять `SubViewport.size` нельзя (документация Godot). Поэтому новый код убирает сбивающую с толку фиксацию, задаёт `stretch_shrink = 1`, 4× MSAA для desktop / 2× для компактного экрана, увеличивает модель в кадре (FOV 40°), добавляет колесо мыши и две явные кнопки масштаба. Compatibility renderer не поддерживает FXAA/TAA; они не заявлены и не включены.
3. **Основное меню без когнитивной перегрузки:** постоянный живой баланс CR/XP и видимая кнопка `МАГАЗИН` в шапке; три явные вкладки `ФЛОТ`, `ПИЛОТЫ`, `МИССИИ` с показом только нужного блока. Кнопка вылета закреплена. Основная 3D-сцена занимает больше ширины. На мобильных экранах используется прежняя безопасная компоновка; все покупки защищены от фальшивого начисления.
4. **Настоящая экономика и обучение:** прежние товары, цены NX-12 = 1700 CR, NX-21 = 4200 CR и право собственности сохранены. В разделе ФЛОТ есть прямые кнопки реальных `_upgrade_docked(0/1)` с текущей стоимостью (600 CR + 500 за уже установленный ранг), ограничением ранга 4 и автопересчётом баланса. В разделе ПИЛОТЫ отдельное обучение для Ады/Кая/Леи за 650/1100/1800 CR, ранги 0–3. Ада снижает входящий урон дополнительно на 3% за ранг, Кай даёт +4% тяги за ранг, Лея — +4% от базовой награды миссии за ранг. Бонусы применяются на настоящем вылете/при победе, не при выборе пилота. Обучение сохраняется как необязательное дополнительное поле старого JSON-сохранения версии 1; допускаются только 3 ID пилотов и ранги в диапазоне 0–3.

## Приёмочные проверки

`tests/runtime_smoke.gd` содержит проверки физических 3D-мешей ангара (порог 80), дверей, крановой балки, источника теней, 1:1 разрешения, колесика/кнопок изменения масштаба без разблокировки корабля, независимости мира предпросмотра. Проверяет три UI-вкладки, видимую валюту, доступность настоящего магазина без прокрутки, выход назад без начислений, списание 600 CR при настоящем улучшении двигателя, списание 650 CR при обучении, загрузку ранга и кошелька из v1-сохранения, запрет неизвестных ID/некорректных рангов и применение 0,87 множителя урона Ады на настоящем вылете.

Перед merge требуются `check_source.py`, native Godot 4.7.2 parse/runtime, WebAssembly export, Chromium flight, mobile touch emulation, frontend и launcher safety, все на актуальном commit SHA. **Без успешных CI не объявлять готовым.** Выпуск в production требует отдельного разрешения 4 точных хешей, доверенной сборки, SSH с rollback и независимого публичного HTTPS 4/4 parity; действующая R51 остаётся прежней.

## Что сознательно не обещаем

Это реальное исходное 3D-окружение, но ещё не готовые кинематографические фотореалистичные ассеты с hi-poly скульптингом, текстурными наборами 4K/8K и полноценными NPC. Каждый из трёх корпусов по-прежнему использует общий импортированный NX-08 core с физическими R45-обвесами. Режим Godot Web GL Compatibility ограничивает ряд эффектов. Остаётся улучшить собственные уникальные PBR-корпуса, анимацию технического персонала, полноценное древо экипажа и аппаратные замеры, не подменяя требования красивыми словами.
