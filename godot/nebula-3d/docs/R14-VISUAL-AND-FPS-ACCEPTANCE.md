# NEBULA R14 — визуальная приёмка и реальная производительность

R14 — исходный код и настоящая процедурная геометрия в Godot 4.7.2,
развивающие опубликованную R12: шесть новых кинематографических стартовых портов,
объёмные PBR-площадки, механические конструкции и новая детализация NX-08.
Ресурсы R13 из отдельного offline-архива **не включены** в этот GitHub-релиз
и не должны ошибочно считаться установленными.

## Проверка изображения

1. Откройте https://osgard.world/games/remix/arena-v2/nebula-3d/?r14=1
   и выполните Ctrl+Shift+R, если браузер кэширует старую игру.
2. Посмотрите на первый экран в АВРОРЕ: под кораблём видна объёмная
   металлическая стартовая площадка; по бокам — две укреплённые башни.
   Линия полёта вперёд должна оставаться свободной.
3. Убедитесь, что над стартовым коридором виден высокий конструкционный мост,
   а вблизи различимы фермы, крепёж, утопленные окна и подвижные грузовые узлы.
4. Подлетите к станции, затем отдалитесь, проверьте переход на простые
   дальние силуэты и отсутствие резких пропаданий сооружений.
5. Нажмите **F2** для смены камер, **F3** для MAX/HIGH/ECO,
   **F4** для скрытия HUD, **F8** для сравнения постобработки,
   **F12** для сравнения стального сумрака и рассвета.
6. Проверьте NX-08 вблизи: три профилированных двигателя, крылья с
   накладными панелями, крепления и меняющееся вращение механики на скорости.
7. **F10** запросит сохранение PNG текущего реального кадра браузера.
   Это самый ценный визуальный артефакт для последующего исправления.

## Физическое оборудование — честный FPS, а не расчёты из количества полигонов

- **F6:** монитор FPS/времени кадра/draw calls.
- **F7:** 2 секунды прогрева + 20 секунд реального замера.
- **F9:** скопировать JSON; браузер может обезличить название GPU.
- **F11:** автоматическое качество, выключено по умолчанию. Перед
  сравнительными F7-тестами его лучше выключить.

Выполните три замера (MAX, HIGH, ECO) на **физическом** устройстве по одному
маршруту, без переключения качества в течение теста. Запишите ОС, браузер,
разрешение, известный графический адаптер и результаты в JSON.

| Цель, не результат | Средний FPS | P95 |
| --- | ---: | ---: |
| Настольная видеокарта / MAX | >= 60 | <= 20 мс |
| Встроенная GPU / HIGH | >= 40 | <= 30 мс |
| Слабый WebGL / ECO | >= 30 | <= 35 мс |

Превышение времени кадра или несовпадение нормалей/освещения требует
исправления, прежде чем говорить о финальном качестве.

## Что автоматизировано

- Статическая проверка новых GDScript, наличия архитектуры и PBR.
- Native Godot editor import и полная игровая smoke-регрессия.
- Геометрическая проверка: 6 стартовых сцен, 6 скульптурных платформ,
  12 манипуляторов, 12 бронепанелей NX-08, 3 двигателя, GPU fasteners.
- Проверка сохранения, миссий, столкновений и переключения LOD через F3.
- WebAssembly-экспорт и отдельный SSH-деплой **только после успешного CI**.

GitHub Actions и software SwiftShader не равны реальным испытаниям видеокарты.
R14 повышает детализацию, но не является подтверждённой AAA-фотореалистичной
версией без визуальной приёмки, физического FPS и профессиональных ассетов.
