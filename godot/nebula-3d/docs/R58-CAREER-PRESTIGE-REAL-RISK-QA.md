# NEBULA R58 — репутация пилота, настоящие сложные контракты и рост наград

**Состояние:** source-кандидат; НЕ production и НЕ подтверждённая приёмка. Зависимость: принятие R57 PR #760, затем отдельная проверка всех шести статусов на последнем SHA. Физические Android/iPhone: **NOT_PERFORMED**.

## Почему это не косметика

Игрок уже может получать CR повторными рейсами R57; теперь R58 даёт измеримую карьерную прогрессию и игровой риск. Репутация **НЕ покупается** и вычисляется из количества успешно завершённых физических контрактов в старом локальном сохранении. Переключение класса риска не начисляет награды. В следующих классах реально появляются дополнительные маяки, а время уменьшается: игроку нужно совершить больше действий и лететь точнее.

| Репутация | Сколько настоящих успешных вылетов | Открыто |
|---|---:|---|
| Новичок | 0–2 | Стандартный контракт |
| Штурман | 3–8 | Ускоренный |
| Ас | 9–23 | Элитный |
| Легенда | 24 и более | Все рейсы, высший карьерный ранг |

| Класс риска | Количество 3D-точек | Время | Базовая награда CR | XP |
|---|---|---:|---:|---:|
| Стандарт | исходный маршрут | 100% | 100% | 100% |
| Ускоренный | исходный + 1 возвратный маяк | 85% | 135% | 130% |
| Элитный | исходный + 2 возвратных маяка | 70% | 175% | 165% |

Пример на контракте «Обход Авроры»: 3 маяка / 7 минут / 380 CR базово → 4 маяка / 5 минут 57 секунд / 513 CR в «Ускоренном» → 5 маяков / 4 минуты 54 секунды / 665 CR в «Элитном». Это суммы до действующих бонусов оплаченного обучения пилота (например, Лея), начисляемых только при полной успешной сдаче.

## Пять настоящих блоков разработки

1. **Заслуженные звания.** `career_prestige_r58.gd`: вычисление 0–3 карьерного ранга по ограниченным счётчикам R57, проверка доступа к риску, безопасный `safe_selected_tier`, каталог конкретных наград, времени и 3D-маршрутов. Не использовать XP, премиум-оплаты и вводимые кнопкой значения вместо завершённых контрактов.
2. **Физическая сложность.** В `patrol_contracts_r57.gd` появились собственный список точек рейса, время и зафиксированный уровень риска. Ускоренный/элитный полёт принимает только точный базовый маршрут плюс обратные узлы, соответствующий лимит и настройку ДО первого кадра физики; изменить параметры посреди вылета нельзя. Сохранены реальные ограничения R57: радиус 54 м, удержание 1,50 с, фатальный тайм-аут, без подарков за открытие маршрута.
3. **Настоящая экономика.** `world.gd` связывает rank/tier и реальные исходящие CR/XP; расчёт происходит ТОЛЬКО внутри проверки `r57_patrol.finished`/success + `r57_reward_committed`. Бонус академии пилотов применяется к итоговому базовому CR соответствующего класса риска, а не дважды. Новый необязательный ключ `r58_risk_tier` дополняет существующий `version: 1` JSON. Если подставить в файл «элитный» без 9 подтверждённых счётчиков, он понижается до стандартного.
4. **Удобный мобильный ангар.** В разделе «МИССИИ» после завершения 14 сюжетных операций — реальная репутация, число успешных рейсов, остаток до нового звания, три кнопки выбора сложности с 44px целями для пальца, недоступность закрытого класса, точный CR/XP/срок/число новых физических маяков. Во время вылета HUD показывает риск и настоящий таймер.
5. **Независимая приёмка.** `runtime_smoke.gd` и `check_source.py` проверяют пороги 3/9/24, фальсификацию риска, отличие настоящих координат, отказ от изменения уже идущего маршрута, поштучное посещение дополнительных точек, цены, однократное начисление CR/XP, сохранение и загрузку, блокировку начисления с незавершённым полётом. Прежние R57 smoke-test сценарии обязаны оставаться зелёными.

## Честные границы качества

Это **локальная игровая экономика** с данными `user://nebula_3d_save.json`. Человек может изменить локальный файл; это не античит на сервере и не коммерческая валюта. Никаких новых реальных платёжных функций, сетевой игры, обязательного подключения к интернету или подтверждённого телефонного GPU-тестирования в R58 нет.

**Условия выпуска:** R57 сначала должен пройти собственные 6/6, быть объединён без обхода защиты; затем R58 повторяет native Godot 4.7.2 + Chromium desktop/mobile + WebAssembly + security + frontend + launcher readiness на последнем SHA; далее доверенный экспорт из master, отдельный PIN для `index.html`, `index.js`, `index.wasm`, `index.pck`, SSH-откат и независимая публичная **HTTPS 4/4**. FPS, нагрев, автономность и реальные касания на физическом iPhone/Android остаются **NOT_PERFORMED**.
