Новый кандидат поверх `f7c67a16b4627e9d444f03f27c723b975cc761c4`, пересобран из апробированного R57 motion-probe PR#409, **не** замена старого проекта и не подмена pixel evidence.

4. Артефакты: before/after PNG, JSON движения для desktop и touch, SHA всех семи файлов, trace и console. Любая неудача оставляет CI красным.
5. Это измерение **опубликованной** версии, не подмена виртуального телефона физическим iPhone/Android, не аттестация AAA, не ручной полный проход 40 миссий.
