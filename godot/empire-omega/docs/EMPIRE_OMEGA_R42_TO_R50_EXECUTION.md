# EMPIRE Ω — крупноблочная дорожная карта R42.1–R50
Дата редакции: 2026-10-25. Этот документ задаёт проверяемые критерии, а не рекламный статус AAA.
Единица результата: **конкретный исходный SHA → настоящий Godot WASM/PCK → живой игровой сценарий → публикация → SHA-256 7/7 + независимая приёмка**.

## Система приоритетов
1. Оставить онлайн последнюю подтверждённую версию (R43) до успешного нового релиза.
2. Изолировать необкатанную физику и новые графические подсистемы в отдельных PR.
3. Не объединять несколько рискованных подсистем без отдельных A/B испытаний.
4. Скорость рендера в SwiftShader не выдавать за Android/iPhone FPS.
5. Не путать merge-коммит с исходным SHA экспортированного Godot Web пакета.

## Блок А — R42.1: исправление выпуска и SHA-подтверждение
**Реализовано в PR #374:** ограниченный 110-секундный бюджет только для реального R40 калибровочного теста; все прочие тесты остаются обязательными и имеют прежний лимит.
**Слияние:** 44ca3aa7bd183305108be53283fdffe98e74e5cd.
**Для выпуска:** успешный production export Godot 4.4.1; корректные wasm/pck; source_commit в release.json; защищённая SSH-активация; сверка **всех семи** публичных файлов SHA-256; отдельный Chromium-проезд именно опубликованной игры на desktop и телефоне. До этого production остаётся предыдущим проверенным релизом.

## Блок B — R44: настоящий ночной город
**Предложено в PR #373:** 162 instanced декоративных фонаря, но не более четырёх реальных повторно используемых OmniLight3D; ночные режимы 2/4 светильника; нулевые дополнительные источники при LOW/днём; радиус 13 м; без новых коллизий/теневых карт.
**Гейты:** нативный Godot v65, реальные город/погода/движение, Chromium 4 viewports, независимый кадр именно ночного режима (не дневная дымка), GPU профиль на физическом оборудовании перед оценкой визуального качества. Провал теста блокирует слияние и деплой.

## Блок C — R45: узнаваемая архитектура, детализация без лишних draw calls
**Кандидат:** один настоящий многоугольный beveled ArrayMesh для профилированных каменных карнизов; четыре балки на здание через один MultiMesh; 52 треугольника на балку, максимум 1024 балки / 53 248 треугольников. Три детерминированных оттенка камня; корректные нормали и PBR без fake-glow; LOW скрывает пакет, CINEMATIC показывает. Изменения производятся в существующем игровом генераторе через script horizon_architecture_trim.gd, без HTML-подмены.
**Дальше:** раздельные планы фасадов районов, осмысленные входы, PBR материалы с подтверждённой текстурной лицензией, LOD и разбор screenshots под повторяющийся силуэт.
**Гейты:** v66 нативная геометрия/нормали, R25/R35/R37 регрессии, настоящий WebGL, четыре экрана и визуальное сравнение одной и той же камеры. Скриншоты Chromium не доказывают уровень AAA.

## Блок D — R46: калибровка автомобильной физики, не вслепую
**Целевые сценарии:** парковка/покой, разгон по сухому и мокрому, 100→0 торможение, поворот и слалом, порог сцепления, кочка и возврат подвески, перенос массы, контролируемое столкновение, стабильность управления двух касаний.
**А/B:** старый CharacterBody3D как базовая линия против R24/R40 RigidBody3D; одинаковый маршрут, масса, переменные состояния, seed и timestep; сравнивать путь, yaw, боковое ускорение, контакт четырёх колёс, тормозной путь, jitter и долю успешных заездов.
**Интеграция только после parity:** без телепорта и выпадения колёс, нет NaN/бесконтрольных импульсов, управление на клавиатуре и тач. Лабораторная модель не заменяет живую без числами подтверждённого улучшения.

## Блок E — R47: город, люди, движение
**Игровые системы:** маршрутные транспортные агенты с ограничениями скорости и соблюдением светофора, предсказуемое уступание пешеходам, переходы, независимые события кварталов, экономические последствия решений, наблюдаемое изменение состояний.
**Гейты:** >100 повторяемых симуляционных столкновений/пересечений на нескольких seed без проскальзывания через геометрию; изолированные regression cases; полное управление игроком и совместимость сохранений; на физическом телефоне лимиты CPU.

## Блок F — R48: работающая адаптивная производительность
**Метрики:** p50/p95/p99 времени кадра; время CPU/GPU, draw calls, инстансы, VRAM, RAM, время загрузки, касание→действие, отсутствие перегрева/троттлинга.
**Платформы:** desktop Chromium/WebGL, Android Chrome, iOS Safari — физические устройства; LOW/STANDARD/CINEMATIC с одинаковыми правилами.
**Цели-кандидаты, не доказательства:** desktop 60 FPS, типовой midrange smartphone ≥30 FPS после 10 минут игры без троттлинга и без провала управления. Фактические бюджеты корректируются по замерам, а не заявляются успешными по headless CI.

## Блок G — R49: законченный игровой вертикальный срез
**Сценарии:** onboarding → посадка → маршрут → миссия → результат → награда → сохранение → восстановление; не менее трёх законченных миссий разной механики и английская/русская локализация. Проверить паузу, audio, accessibility, reduced motion, изменения погоды и время суток.
**Приёмка:** новая игровая сессия и старый save воспроизводимо проходят весь цикл; нет критических багов в UI/управлении; запись настоящего игрового прохождения.

## Блок H — R50: независимый релиз, не только номер
**Проверки:** четыре разрешения Chromium; реальный Android/iPhone; полный проход на клавиатуре, тач и геймпаде (где поддерживается); backward compatibility сохранений; security/CDN; нет ошибок JS/Godot; SHA манифест и независимый серверный hash-аудит 7/7; protected deployment и испытанный rollback.
**Вердикт:** RELEASE только при всех обязательных зелёных гейтах, иначе HOLD. Не объявлять настоящий AAA-фотореализм без качественных ассетов, capture comparison и аппаратных измерений.
