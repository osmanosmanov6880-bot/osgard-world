# EMPIRE Ω R48 — пиковые задержки кадров, не рекламные FPS

Реализовано непосредственно в текущем Godot Web игровом цикле.
- Прежний переключатель качества R15 учитывал только средний `Engine.get_frames_per_second()` — при 65 FPS по среднему игра могла дёргаться из-за каждого пятого кадра длительностью 50 ms.
- `horizon_frame_metrics.gd` уже получает настоящие дельты с игрового `_process`. R48 передаёт его p95 и количество квалифицированных кадров в `adaptive_graphics.observe_frame_pacing`.
- На мобильном, после шести секунд прогрева, устойчивые 40ms+ p95 запускают прежний четырёхсекундный двухступенчатый downgrade. Восстановление возможно лишь после 12 секунд действительно ровных кадров; пользовательская настройка — потолок, а не перезаписывается.
- Фоновая вкладка не ухудшает картинку, неподтверждённые 3 кадра нельзя считать базой для решения.
- Расширен добровольный 20-секундный JSON замер: число кадров вне бюджетов 30/60 fps, худший кадр и отношение замедлений, p95-FPS эквивалент. Эти поля рассчитываются только по реально записанным кадрам после прогрева, а не изображают аппаратную проверку.
- Новое поведение **не меняет физику, законы города, сохранения или управление**. Снижает только графическую нагрузку через уже существующие уровни LOW/STANDARD/CINEMATIC.
