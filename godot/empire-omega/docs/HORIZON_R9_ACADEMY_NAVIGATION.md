# HORIZON R9 — автошкола: направление, контрольные точки и время

## Реализовано в игре, без фиктивных побед

Реальная система `driving_trials.gd` уже управляет маршрутом, физическими контрольными точками, временем, повреждениями, наградами и сохранениями. R9 не создаёт второй контроллер и не начисляет деньги — он делает существующую автошколу понятной непосредственно из машины.

- `horizon_race_navigator.gd` получает официальные `checkpoints`, `step` и `elapsed` из GameState. По координатам машины и реальному yaw вычисляет направление до следующих ворот: прямо, налево, направо, разворот или точка достигнута.
- Основной HUD показывает локализованное RU/EN/ZH название задания, количество пройденных точек, расстояние в метрах и оставшиеся секунды. На узком экране название сокращается без потери счётчика.
- После окончания гонки интерфейс возвращает прежнюю цель кампании.
- Визуальный компонент не меняет данные гонки и награды. Механические ворота и античит-проверки пробега остаются первичными.
- Нативный Godot QA `v31_academy_navigation.gd` сверяет реальные маршруты, геометрию, направление, таймер, прогоны, отсутствие мутаций и привязку к актуальным `main.gd`/`hud.gd`.
- Отдельный workflow R9 повторяет все V21, V25, V27, V28, V29, V30 и V31.

**Зависимость:** код R9 основан на PR #266 (R8) и должен объединяться только после него. R9 не означает, что графика уже фотореалистична или есть сетевые гонки. После merge обязательны Godot Web экспорт и публичная проверка.
