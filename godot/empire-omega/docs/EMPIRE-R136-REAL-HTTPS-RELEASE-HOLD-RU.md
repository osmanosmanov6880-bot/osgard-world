## Что теперь действительно реализовано

- `scripts/omega-r136-live-r87-https.py` делает настоящие **GET** к единственному разрешённому `https://osgard.world/games/omega-3d-preview/`: `release.json` и ровно семь оригинальных файлов Godot 4.4.1; не делает POST/PUT/DELETE, SSH, API release или изменения production.
- Источник ожидается точно `43ae041e8df52418ca74c02405de9c196b59bd37`; сверяется существующим immutable R128 валидатором со всеми семью настоящими SHA-256 из `master` R87. Файлы скачиваются потоково с ограничениями размеров, проверяются HTTP 200, сертификат TLS, отсутствие редиректов и компрессии, WASM `\\x00asm` и Godot PCK `GDPC`. Сохраняются только хеши, размеры, статус и разрешённые URL, без копирования производственных бинарных данных в публичные артефакты.
- Самотесты намеренно используют **синтетические** in-memory байты для проверки недопустимости редиректов, стороннего хоста, HTTP, поддельного manifest/source SHA, отсутствующего файла, gzip-трансформации и подмены PCK. Они выдают `0 live claims`, а не фиктивный proof.
- Отдельный workflow `omega-r136-live-r87-https-qa.yml`: immutable PR-head, Python strict selftest, затем настоящий read-only HTTPS запрос с **FAIL** при любом недоступном/подменённом файле, только JSON-артефакт. Разрешения Actions `contents: read` и `persist-credentials: false`. Он не меняет `master` и не публикует игру.
- Запрещено делать утверждение `7/7 HTTPS PASS` до фактического SUCCESS именно live job и архива результата. Проверка настоящего публичного URL не доказывает реальный origin/VPS, staged HTTPS nginx rollback или продакшн безопасность.
