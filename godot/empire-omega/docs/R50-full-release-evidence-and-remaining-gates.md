# EMPIRE Ω R50 — независимая приёмка, аппаратные измерения и честный статус релиза
Разделяет **рабочую опубликованную Godot Web игру** и полную художественно-аппаратную сертификацию.

## Сборка и публичное подтверждение
- Требуется исходный `source_commit` именно из `public/games/omega-3d-preview/release.json`, а не merge SHA другой ветки.
- `scripts/omega-r50-release-gate.py` сверяет **ровно семь** контрольных сумм локальных настоящих файлов включая index.wasm и index.pck. При несовпадении или подмене возвращает ошибку.
- `omega-live-integrity.py` независимо скачивает публичные файлы и сравнивает SHA-256; итог R50 принимает только `verified_files=7` и те же имена файлов.
- После подтверждённого защищённого SSH-деплоя **новый** workflow выполняет настоящий Playwright против `https://osgard.world`: `desktop-chromium` 1366×768 + `touch-phone-chromium` 390×844, реальные исходные тесты игрового WebGL и управления.
- Reporter JSON проверяется на два проекта, успешный финальный статус и отсутствие неожиданных провалов. Все следы сохраняются как GitHub artifact.
- QA выполняет source freshness, чтобы старый экспорт не объявлялся текущим при более новом исходном дереве игры.

## Аппаратная приёмка
Два **физических**, не эмулированных устройства: Android Chrome и iOS Safari. Для каждого нужен человеческий оператор, точные модель, OS, браузер, source SHA, время, 2 сек прогрева, 20 сек измерения, число кадров, p95/p99, видеозапись исходной поездки и совпадающий SHA файла записи.
Любое отсутствие, несовпадение или `physical_device=false` даёт статус `HOLD`. Даже два заполненных отчёта дают только `MANUAL_RELEASE_REVIEW_REQUIRED`, а **не автоматический AAA RELEASE**. Машинная проверка не является независимой экспертизой художественного качества, источника устройства или лицензий.
Скриншоты Chromium/SwiftShader не являются доказательством аппаратного Android/iPhone FPS.

## Уровни допуска
1. **CANDIDATE:** исходные Godot PR, нативный CI и настоящий WebGL в четырех размерах.
2. **ONLINE VERIFIED:** защищённая публикация, сохранён исходный SHA, независимый 7/7 byte audit, desktop и мобильная WebGL-поездка.
3. **HARDWARE REVIEW:** оригинальные отчёты двух физических устройств + подтверждённая видеозапись, ручной разбор кадров и вводов.
4. **RELEASE:** отдельное человеческое решение о gameplay, сохранениях, стабильности, художественных ассетах, лицензиях, рентабельности и управляемом rollback.

## Откат и безопасность
Последняя доказанная версия должна оставаться активной, пока следующий кандидат не выдержит весь pipeline; не отключать проверки ради зелёного CI. Существующий `deploy-omega-native-remote.sh` обеспечивает защищённую публикацию и rollback. Новый R50 workflow ничего самостоятельно не загружает на сервер, не меняет секреты, не отчитывается о hardware pass и сохраняет доказательства отдельно.
