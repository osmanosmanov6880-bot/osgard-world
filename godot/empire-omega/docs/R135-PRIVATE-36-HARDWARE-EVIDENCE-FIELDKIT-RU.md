# EMPIRE Ω R135 — реальная аппаратная приёмка: приватный комплект на 36 испытаний

**Реальный статус:** программная проверка source SHA и сборки R90 пройдена, но **никаких физических GPU/FPS/видео 36/36 мы не заявляем**. Нативные тесты GitHub Actions и Mesa/SwiftShader нельзя выдавать за измерения на iPhone, Android или дискретной GPU. **Production HOLD.**

## Что теперь работает

Скрипт `scripts/omega-r135-physical-fieldkit.py` создаёт приватный пакет, жёстко связанный с конкретным **40-значным SHA исходника игры**, не с SHA публичного `master` и не с хешем ZIP. Он готовит ровно 36 исходных ячеек: настоящий ПК / Android / физический iPhone × `drive_city`, `live_cabinet`, `night_rain`, `save_reload` × три независимых повтора.

Пакет **сразу создаётся пустым**: счётчик реальных видео 0/36, `production_authorized=false`. Даже прогон его self-test не создаёт ни одного результата FPS. Приложение `add` принимает только оригинальные файлы видео MP4/MOV/WebM (заголовок и ограниченный физический размер), original Godot R36 `complete` JSON, реальную модель устройства, GPU, версию браузера, имя/код независимого наблюдателя и явные подтверждения физического устройства/двух пальцев на телефонах. Каждый файл копируется **байт-в-байт** в приватную папку, получает SHA-256 и отдельный уникальный device/scenario/iteration. Замена существующих записей или подмена ролика другим повтором блокируется.

`audit` использует **существующий** `scripts/omega-r127-physical-device-gate.py`, а не новый облегчённый валидатор: проверяет 36 разных видео/SHA, полный исходный SHA, настоящее schema Godot R36, минимум 19 сек. и 100 кадров, реальные p50/p95/p99, аппаратный GPU (не Mesa/SwiftShader), двухпальцевое управление и ограничения для desktop/mobile. При отсутствии хоть одного испытания возвращает **HOLD / exit 1**, а не ложный PASS. Даже собранные реальные 36 отчётов потребуют отдельной человеческой проверки оригиналов и арт-референсов.

## Команды без заглушек и выдуманных данных

На своём ПК с Python 3 создайте **приватную папку вне GitHub и проекта**:

```bash
python3 scripts/omega-r135-physical-fieldkit.py init \
  --root /ABSOLUTE/PRIVATE/empire-omega-field \
  --sha <ТОЧНЫЙ_40_СИМВОЛЬНЫЙ_SHA_ИСПЫТЫВАЕМОЙ_ИГРЫ>
```

Запустите настоящую неизменённую проверяемую игру на устройстве, запишите непрерывное видео, получите исходный Godot R36 JSON. Только после живой записи:

```bash
python3 scripts/omega-r135-physical-fieldkit.py add \
  --root /ABSOLUTE/PRIVATE/empire-omega-field \
  --device android --scenario drive_city --iteration 1 \
  --model "Реальная модель устройства" \
  --gpu "Реальный GPU renderer" --browser "Версия Chrome" \
  --operator "Код независимого оператора" \
  --witnessed-live --two-finger-observed \
  --video /PRIVATE/ORIGINAL_RECORDING.mp4 \
  --frame-report /PRIVATE/ORIGINAL_GODOT_R36.json
python3 scripts/omega-r135-physical-fieldkit.py audit \
  --root /ABSOLUTE/PRIVATE/empire-omega-field
```

Не загружайте реальные видео/имена в публичный GitHub Actions, чат, PR или репозиторий. Все доказательства остаются локально с правами 0700/0600; при необходимости передавайте их независимому эксперту по защищённому частному каналу. Публичный CI проверяет **только пустую матрицу и запрет ложной готовности**.

## Критерии B5 и граница выпуска

- 36 оригинальных независимых запусков с соответствующим SHA **и** действительным Godot render-frame JSON; baseline desktop target: p95≤16.7мс, p99≤33.3мс; phone LOW: p95≤33.3мс, p99≤50мс.
- Никаких подмен физического GPU или приёма пустых медиа/повторных видео. Суммы хешей из файла, а не записанные на словах.
- Отдельно исполнить **Блок I:** 3 независимых 15–20-минутных человеческих прохождения и все 40 миссий; **Блок II:** исходные два референса side-by-side с подписями ревьюера; **Блок IV:** реальные публичные HTTPS байты и независимая репетиция rollback на изолированном реальном сервере. R134 уже подтвердил 7/7 и восстановление в CI, но **не** на production VPS.
- Единственный окончательный GO: независимая человеческая проверка всех исходников видео/арта/аппаратуры и отдельное разрешение на релиз. До этого [PR #500](https://github.com/osmanosmanov6880-bot/osgard-world/pull/500) остаётся DRAFT, `master` и опубликованная R87 не меняются.
