Измеримые результаты.

Локальная лаборатория FPS для нескольких телефонов. Сравнивайте отчёты, полученные внутри настоящей игры. Никакой отправки файлов на сервер — весь анализ выполняется в браузере.

Как собрать результаты

  1. Откройте NEBULA 3D на настоящем телефоне и нажмите FPS.
  2. Если в игре уже доступен мобильный переключатель R38, выберите в панели FPS MAX, HIGH или ECO (не АВТО). Нажмите 20 С, пролетите одинаковый маршрут и сохраните JSON.
  3. Для каждого профиля и ориентации проведите три отдельных замера на настоящем телефоне. Вернитесь сюда и загрузите файлы одним набором для каждого устройства.

Требование к мобильной версии: если в панели FPS нет кнопки MAX/HIGH/ECO, R38 на вашем устройстве ещё не опубликован. До его появления невозможно корректно сравнить фиксированные графические профили с телефона; не считайте АВТО-отчёт измерением MAX/HIGH/ECO.

Введите свою метку перед выбором файлов. Она нужна только для группировки; по умолчанию каждая загрузка получает отдельный номер партии. Не указывайте личные данные.

    R40 / сравнение до и после оптимизации

    Для одного физического телефона используйте одну метку устройства, одинаковый размер экрана и один ручной профиль. Загружайте три или более независимых отчёта для R38 и для кандидата R40, меняя «Версия измерения» перед каждой загрузкой. Таблица сравнивает медианы. Кандидат R40 обязан содержать метку NEBULA_R40_BRIDGE_BATCH_3X32, которую записывает сама игра; R38 такой метки не содержит. Старые R40-архивы без метки потребуется пересобрать. Проверка метки предотвращает случайную путаницу сборок, но не является цифровой подписью или аппаратной сертификацией. *Снижение draw calls — расчёт по счётчику игрового движка, а не фактическим GPU-командам драйвера; отсутствие показателя отмечается прочерком.
