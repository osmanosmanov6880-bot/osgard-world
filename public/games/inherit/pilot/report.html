ОТЧЁТ О ПИЛОТЕ · ТОЛЬКО НА ЭТОМ УСТРОЙСТВЕ

Исследуй реальные результаты. Без загрузки данных на сервер.

Выберите JSON-файлы, которые участники добровольно экспортировали из INHERIT и отдельно передали вам с осознанным согласием. Анализ выполняется прямо в браузере. Исходные файлы, псевдонимные коды и данные участников не отправляются сайту и не показываются в сводке.

01 · Данные исследования

Работает только с добровольными отчётами вида inherit-pilot-*.json. Не выбирайте игровые сохранения, архивы аккаунтов, приватные документы и личные данные. Пустой отчёт не означает отсутствие игроков.

Отчёт ещё не построен. Никакие файлы не отправлены.

БЕЗОПАСНЫЙ ПРОЦЕСС

Используй сводку ответственно.

01

Получить согласие

Участники добровольно экспортируют файлы и сами решают, передавать ли их организатору. Из игры нет автоматической отправки.

02

Проверить выборку

Повторные экспорты исключаются по псевдонимному коду. Для D1 и D7 учитываются только те участники, для которых прошёл необходимый срок.

03

Удалить исходники

Публично делиться можно только агрегатами, без кодов участников. Исходные файлы удаляют по заранее согласованным правилам.
