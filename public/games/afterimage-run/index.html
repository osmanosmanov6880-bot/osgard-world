02 / PROTOCOL

Почувствуй ритм.

  • Пробел / ↑ / тап по арене — прыгнуть.
  • Shift / кнопка PHASE DASH — пройти сквозь опасную зону, если заряд готов.
  • Собирай осколки: последовательные сборы увеличивают комбо и итоговый счёт.
  • После столкновения забег заканчивается. Перезапуск мгновенный.
  • Личный призрак сохраняется только на этом устройстве.

Ежедневный seed закреплён по UTC. Челлендж-ссылка передаёт дату и результат; серверных рекордов нет.

Клавиши: Space/↑ — прыжок, Shift — рывок, P — пауза, R — сброс после финиша, Esc — пауза.
