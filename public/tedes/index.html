02 / PRODUCT THINKING

Не только красивый каталог.

Интерфейс строится вокруг следующего действия проектировщика: определить позицию, сравнить параметры и передать согласованную ведомость дальше.

01

Зонная конфигурация

Отдельные параметры для входной группы, кабинетов, санузлов и других зон в одном проекте.

02

Проект можно перенести

Экспортируйте JSON для резервной копии и импорта проекта, CSV для работы в таблицах или печатную ведомость для сохранения в PDF через браузер.

03

Честная инженерная граница

Проектные значения отделены от подтверждённых характеристик: интерфейс не подменяет техническую экспертизу.
