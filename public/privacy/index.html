OSGARD WORLD / GAMES

Конфиденциальность
по умолчанию.

Дата редакции: 13 октября 2026 года

Главное: каталог не подключает рекламную сеть и не отправляет аналитику по умолчанию. Избранное и история хранятся локально в браузере.

1. Область действия

Документ описывает каталог osgard.world/games/. У отдельных игр могут быть собственные API, сохранения и условия. INHERIT хранит состояние локально, сетевые режимы SWARM и REMIX зависят от своих серверов.

2. Локальное хранение

Каталог использует localStorage: osgard.games.favorites.v1 (избранное), osgard.games.recent.v1 (последние игры) и osgard.games.analytics-consent.v1 (выбор аналитики). Каталог сам по себе не отправляет эти значения серверу. Их можно очистить в браузере.

3. Необязательная аналитика

Необязательная аналитика выключена по умолчанию. Если вы явно разрешили её, настроенный Commerce API OSGARD может получать ограниченный список событий: просмотр каталога/страницы Premium/партнёрской страницы, запуск и завершение игровой сессии, переход по промо-ссылке и событие отправки заявки. Передаются случайный идентификатор события для защиты от повторной записи, псевдонимный идентификатор сессии, идентификатор игры, источник, путь страницы без query-параметров и длительность. Поля заявки, email, телефон и токен входа не входят в записи этой таблицы событий. Отдельные авторизованные игровые события могут отправляться в /api/v1/player/events с токеном учётной записи — это другой поток данных.

События Commerce API удаляются через 90 дней по умолчанию после получения; оператор может настроить срок от 30 до 365 дней переменной ANALYTICS_RETENTION_DAYS. Очистка запускается при старте API и затем каждые шесть часов, если база данных доступна. Эти правила вступают в силу на развёрнутом и настроенном сервере; при отсутствии рабочей базы события не сохраняются. Если API временно недоступен, уже согласованные события могут ожидать отправки в локальной очереди браузера: максимум 100 событий и срок не более 7 дней. При восстановлении соединения каталог повторяет отправку; сервер использует ID события для защиты от повторной записи. При отзыве согласия очередь удаляется. Если хранилище браузера недоступно, события не накапливаются. Каталог не подключает рекламные пиксели, сторонние аналитические скрипты или внешние шрифтовые CDN. UTM-параметры на исходящих ссылках обозначают источник перехода, но не подтверждают конверсию на сайте назначения.

4. Заявки

При явном согласии и доступном API форма передаёт тип проекта, необязательный бюджет, предоставленный контакт и описание задачи серверу OSGARD для ответа на обращение. Если в ссылке присутствуют UTM-метки, код игры или формат приглашения, безопасные значения сохраняются со заявкой для учёта источника обращения; полный URL и произвольные query-параметры не сохраняются в этих полях. Метки источника не подтверждают продажу или факт публикации в соцсети. Если API недоступен, форма предлагает подготовленный текст WhatsApp; он не отправляется автоматически, и вы сами решаете, отправлять ли его. Переписка по email/WhatsApp обрабатывается соответствующими сервисами.

5. Реклама и покупки

Рекламная сеть и вознаграждаемая реклама не подключены. Код платёжного checkout существует, но обработка платежей доступна только после настройки серверных ключей, цен, вебхука и базы; live-платежи и продажа подписки по умолчанию выключены.

6. Хранение и контакт

Избранное и история игр остаются в localStorage до очистки браузера. Для согласованных событий Commerce API используется срок хранения, описанный выше; иные игровые API и инфраструктурные журналы могут иметь собственные настройки и сроки. Контакт: osman.osmanov0099@gmail.com.

Перед коммерческим запуском оператор должен проверить применимое право, указать юридические реквизиты и проверить все сроки хранения, потоки данных и механизмы отзыва согласия.

7. Заявки, покупки и платёжный провайдер

Если вы отмечаете согласие и отправляете заявку, на настроенный сервер OSGARD могут передаваться тип проекта, необязательный бюджет, предоставленный контакт и описание задачи для ответа на обращение. Если API недоступен, форма предлагает подготовленный текст WhatsApp, который вы отправляете сами.

При доступном checkout сведения о заказе (email, товар, идентификатор платёжной сессии, статус и суммы) обрабатываются сервером OSGARD. Интеграция передаёт необходимые сведения платёжному провайдеру. Реквизиты карты и CVC вводятся на стороне платёжного провайдера; OSGARD не предназначен для их сбора или хранения. Фактическая обработка зависит от конфигурации активного сервиса.

Необязательная аналитика отправляется только после явного согласия. Она ограничена именем события, псевдонимным идентификатором сессии, игрой, источником, путём страницы и длительностью. Согласие можно отозвать в настройке аналитики каталога. Рекламная сеть пока не подключена. Перед коммерческим запуском оператор должен опубликовать юридические реквизиты, сроки хранения и контакт по вопросам данных.
